## 摘要
在非对称先验旅行商问题（具有独立激活概率）中，我们给定一个非对称旅行商问题的实例，以及每个顶点的激活概率。任务是计算一条游览路线，使得在短路到随机采样的活跃顶点集合后，期望长度最小。我们证明了非对称先验旅行商问题的自适应间隙具有多项式下界。此外，我们表明，通过拟多项式运行时间的随机算法，可以实现多对数近似比，从而获得低于自适应间隙的近似比。为实现这一目标，我们提供了一系列多项式时间归约。首先，我们归约到一个新颖的非对称旅行商问题的推广，称为Hop-ATSP。接下来，我们使用有向低直径分解来获得结构化实例，然后为这些实例提供到覆盖问题的归约。最终，我们获得了非对称先验旅行商问题到在一个无环有向图中寻找最小化特定目标函数的路径问题的多项式时间归约，并为此给出了一个拟多项式时间内的O(log n)近似算法。

## Abstract
In Asymmetric A Priori TSP (with independent activation probabilities) we are given an instance of the Asymmetric Traveling Salesman Problem together with an activation probability for each vertex. The task is to compute a tour that minimizes the expected length after short-cutting to the randomly sampled set of active vertices. We prove a polynomial lower bound on the adaptivity gap for Asymmetric A Priori TSP. Moreover, we show that a poly-logarithmic approximation ratio, and hence an approximation ratio below the adaptivity gap, can be achieved by a randomized algorithm with quasi-polynomial running time. To achieve this, we provide a series of polynomial-time reductions. First we reduce to a novel generalization of the Asymmetric Traveling Salesman Problem, called Hop-ATSP. Next, we use directed low-diameter decompositions to obtain structured instances, for which we then provide a reduction to a covering problem. Eventually, we obtain a polynomial-time reduction of Asymmetric A Priori TSP to a problem of finding a path in an acyclic digraph minimizing a particular objective function, for which we give an O(log n)-approximation algorithm in quasi-polynomial time.

## 1. 核心问题与整体含义

**研究背景与动机：**
- 旅行商问题（TSP）是组合优化与理论计算机科学中最著名的问题之一。非对称TSP（ATSP）中，顶点间距离不满足对称性，即 c(x,y) ≠ c(y,x)。
- 本文研究的是**非对称先验TSP（Asymmetric A Priori TSP）**：给定一个ATSP实例，每个顶点 v 有独立的激活概率 p(v)，目标是预先计算一条游览路线 T，使得在随机采样活跃顶点集 A 后，将 T 短路（short-cut）到 A 上所得的期望长度最小。
- 对称情形下的先验TSP已有常数近似算法（如Shmoys-Talwar的4-近似等），但**非对称情形此前没有任何非平凡近似算法**——任意环游都是一个 n-近似。
- 自适应间隙（adaptivity gap）定义为最优先验游览的期望成本与最优后验游览（即知道活跃集后再优化的期望成本）之比。若算法仅以后验最优为基准分析，则无法突破该间隙。

**核心问题：**
1. 非对称先验TSP的自适应间隙有多大？
2. 能否设计出近似比**低于自适应间隙**的算法？

**主要贡献：**
- 证明自适应间隙存在**多项式下界** Ω(n^{1/4} · log⁻¹n)。
- 给出确定性多项式时间 O(√n)-近似算法（与后验最优比较），从而给出自适应间隙的 O(√n) 上界。
- 核心成果：**拟多项式时间（n^{O(log n)}）随机算法，实现 O(log⁸n) 近似比**，该近似比低于自适应间隙——这是该问题首次实现低于自适应间隙的近似。

## 2. 方法论

### 2.1 整体技术路线

论文采用**一系列多项式时间归约**，将非对称先验TSP逐步转化为更易处理的问题：

```
非对称先验TSP

          → 拟多项式时间 O(log n)-近似算法
```

### 2.2 归约到 Hop-ATSP

**Hop-ATSP 定义：** 给定顶点集 V、满足三角不等式的成本函数 c、跳数 k，任务是找一条游览 T 最小化 k跳成本：
c^(k)(T) = Σ_{Δ=1}^{k} Σ_{i=1}^{r} c(vᵢ, vᵢ₊Δ)

**关键归约步骤：**
1. **引入仓库（depot）**：证明可假设存在一个始终活跃的顶点 d（p(d)=1），损失常数因子。
2. **处理低概率顶点**：将激活概率小于 1/n 的顶点单独处理（直接连到仓库），损失常数因子。
3. **均匀化激活概率**：通过复制顶点（co-located copies）将非均匀激活概率转化为均匀概率 δ，损失常数因子。
4. **核心观察**：当所有顶点激活概率均为 δ 且 k = ⌊1/δ⌋ 时，先验TSP的期望成本与 δ²·c^(k)(T) 相差常数因子（定理4.16）。证明依赖于对长跳边（Δ>k）的三角形不等式路径分解（引理4.15）。
5. **良缩放（well-scaled）**：将成本取整为 {0,1,...,2n³} 内的整数，且保证 OPT ≥ n²。

### 2.3 归约到层次有序实例

**层次有序实例定义：** 具有层次划分 H₁={V} ⊂ H₂ ⊂ ... ⊂ H_L={单点集}，每个 H_ℓ 中的集合在总序 ≺ 中连续。边 e=(v,w) 的 level(e) 定义为包含两端点的最细划分层级。前向边（v≺w）成本 ≤ D_level(e)，后向边成本 = D_level(e)，且 D_ℓ ≥ 2·D_{ℓ+1}。

**关键技术：有向低直径分解（Directed Low-Diameter Decomposition）**
- 使用 [BFHL25] 的结果：损失 O(log n · log log n) 的有向低直径分解可在多项式时间内计算。
- 递归应用该分解：从 H₁={V} 开始，对每个集合 H ∈ H_{ℓ-1} 应用低直径分解，将其强连通分量作为 H_ℓ 的元素。
- 通过随机采样分解中的边集 F，控制后向边的出现概率，从而保证期望最优值损失为 O(log n · log log n) 因子（定理2.3）。

### 2.4 归约到路径覆盖问题

**路径覆盖问题（Path Covering）：** 给定层次有序实例，找一组"路径-层级对"(P,ℓ) 的集合 P，满足：
- (a) 每个顶点 v 至少被一条路径覆盖；
- (b) 对每个层级 ℓ 和每个集合 H ∈ H_ℓ：要么 H 中所有顶点被更低层级的路径覆盖，要么存在更低层级的路径 P 使得 |V(P)∩H| ≥ k（即 P 对 H "负责"）。

最小化权重 w(P) = Σ_{(P,ℓ)∈P} [c^(k)(P) + k²·D_ℓ]。

**关键论证：**
- **覆盖解 → 游览**（引理6.4）：通过构造分支结构（branching），利用引理6.3（插入子路径的成本上界）将覆盖解合并为游览，成本不超过 2·w(P)。
- **游览 → 覆盖解**（引理6.8）：对非退化实例（non-degenerate），任何游览 T 可转化为覆盖解 P 且 w(P) ≤ O(L³)·c^(k)(T)。核心是处理后向边：
  - 先通过重排序将后向边"隔离"为跳跃段（jump segments）；
  - 对每个跳跃段，根据其是否"分裂"（splitting）采取不同处理：分裂段直接拆分（利用其高成本支付固定费用），非分裂段通过移除部分顶点（放入余集 R）并做 ℓ-细化（ℓ-refinement）消除后向边；
  - 最后将移除的顶点重新插入单调路径，每个顶点成本 ≤ 2k·D_ℓ。
- **退化实例处理**（引理6.7）：通过归纳法处理，损失 O(L) 因子。

### 2.5 求解路径覆盖问题

**贪心集合覆盖框架：**
- 将路径覆盖视为集合覆盖实例（引理6.2），宇宙 U = V × [L]。
- 贪心算法每轮选择最小化 w(P,ℓ)/|新覆盖元素数| 的路径-层级对。
- 若每轮有 α-近似，则整体近似比为 α·O(log n)。

**核心子问题：** 找单调路径 P 最小化 w(P)/Λ(P)，其中 Λ(P) 是 P 新覆盖的元素数。

**权重界（Weight Bound）技术：**
- 对每个偏移 q ∈ {0,...,k'}，定义权重上界 w_q(P) ≥ w(P)（引理7.3，利用三角形不等式）。
- 存在 q 使得 w_q(P) = O(log k)·w(P)（引理7.5，随机偏移的平均论证）。
- 关键：w_q(P) 的结构允许用**动态规划**在拟多项式时间内优化。

**动态规划细节：**
- 将路径分解为块（blocks），每块大小 k' = 2^Γ - 1（引理7.7：权重可分解为块权重之和）。
- 引入**覆盖剖面（covering profile）** 概念，编码路径的覆盖信息，支持块的独立优化与组合（引理7.10、7.11）。
- 构造辅助图，顶点为 (v, Φ)（顶点+覆盖剖面），边对应块的最优实现（引理7.13）。
- 块的最优实现通过**树解（tree solution）动态规划**求解：将块视为满二叉树，自底向上合并子树解（引理7.18）。
- 总运行时间 n^{O(log n)}。

## 6. 主要结论与发现

1. **自适应间隙下界**（定理1.2）：非对称先验TSP的自适应间隙为 Ω(n^{1/4}·log⁻¹n)。这意味着仅与后验最优比较的算法无法获得次多项式近似比。

2. **自适应间隙上界**（定理1.1）：存在确定性多项式时间 O(√n)-近似算法（与后验最优比较），因此自适应间隙为 O(√n)。

3. **主定理**（定理1.3）：存在随机算法，运行时间 n^{O(log n)}，对任何非对称先验TSP实例计算游览 T，使得 E[c(T[A])] ≤ O(log⁸n)·OPT。这是**首次**实现低于自适应间隙的近似比。
