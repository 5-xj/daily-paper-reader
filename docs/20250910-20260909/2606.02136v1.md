## 摘要
神经非对称路由模型日益通过矩阵表示和非对称感知注意力来编码方向性。然而，最终的路由动作并非孤立的节点，而是在当前部分路由下选择的定向转移。这造成了表示与决策之间的不匹配：成对成本信息可能在上游被编码，而最终的候选对数几率在很大程度上仍被参数化为上下文-节点兼容性。我们提出了一种用于神经非对称路由的解码器设计原则：最终得分应明确暴露由问题的成本到目标结构所提示的转移级数量。我们通过一个边感知解码器实例化这一原则，该解码器为当前定向边、返回起点的闭合以及静态轻量级前瞻添加了候选特定项，同时保持表示主干不变。在受控的SVD/Sinkhorn非对称主干上，当在ATSP-100上训练并在ATSP-100/200/500/1000上零样本评估时，该解码器优于RADAR参考，将ATSP-1000的差距从4.13%降至2.73%。在ACVRP上，相同的得分级修改在更丰富的路由状态下显示出相同的定性趋势。ATSP消融和定向转移诊断使机制更加清晰：最强证据涉及对当前定向边的敏感性，而闭合和静态前瞻则作为启发式延续线索。结果支持一项机制研究：神经非对称路由中一个关键的解码器侧信号是决策时暴露转移级边信息。

## Abstract
Neural asymmetric routing models increasingly encode directionality through matrix representations and asymmetry-aware attention. The final routing action, however, is not a node in isolation but a directed transition chosen under the current partial route. This creates a representation--decision mismatch: pairwise cost information may be encoded upstream while the final candidate logit is still largely parameterized as context--node compatibility. We propose a decoder-design principle for neural asymmetric routing: the final score should explicitly expose transition-level quantities suggested by the problem's cost-to-go structure. We instantiate this principle with an edge-aware decoder that adds candidate-specific terms for the current directed edge, return-to-start closure, and static lightweight lookahead, while keeping the representation backbone fixed. On a controlled SVD/Sinkhorn asymmetric backbone, the decoder improves over the RADAR reference when trained on ATSP-100 and evaluated zero-shot on ATSP-100/200/500/1000, reducing the ATSP-1000 gap from $4.13\%$ to $2.73\%$. On ACVRP, the same score-level modification shows the same qualitative trend under a richer routing state. ATSP ablations and directed-transition diagnostics sharpen the mechanism: the strongest evidence concerns sensitivity to the current directed edge, while closure and static lookahead act as heuristic continuation cues. The results support a mechanism study: a key decoder-side signal in neural asymmetric routing is decision-time exposure of transition-level edge information.

# 论文详细中文总结

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 非对称路由问题（如ATSP）中，旅行成本具有方向性，i→j 与 j→i 的成本不同，且相关方向随构造状态变化。
- 现有神经求解器（如MatNet、RADAR）主要从**表示侧**解决非对称性：通过矩阵编码、SVD初始化、Sinkhorn归一化注意力等方式让编码器感知方向性。
- 然而，论文指出了一个关键矛盾——**表示-决策不匹配（representation–decision mismatch）**：即使编码器充分编码了有向成本矩阵信息，最终的解码器评分仍然主要是“上下文-节点兼容性”（context–node compatibility），而非显式的“转移级”（transition-level）评分。
- 在非对称路由中，动作本质上是**当前部分路由下的有向转移**（directed transition），而非孤立的节点选择。根据Bellman方程，选择候选节点 j 的质量应等于**当前有向边成本 + 后续最优成本**，但现有解码器未能显式暴露这些转移级信息。

**核心问题：** 如何让解码器在最终评分阶段显式利用转移级边信息，从而弥合表示与决策之间的鸿沟？

## 2. 论文提出的方法论

**核心思想：** 提出一个解码器设计原则——最终评分应显式暴露由问题成本-到-目标（cost-to-go）结构所提示的转移级数量。具体实例化为**边感知解码器（Edge-aware Decoder）**。

**关键技术细节：**

1. **Bellman形式的动机：**
   - 最优动作价值满足：Q*(j|s_t) = D_{ct,j} + V*(j, U_t \ {j})
   - 终止条件：V*(i, ∅) = D_{i,s_start}
   - 因此解码器应依赖：(i) 当前转移 c_t→j 的立即成本；(ii) 返回起点边界 j→s_start；(iii) 后续价值的替代量。

2. **基线解码器的问题：**
   - 基线评分 s_base_t(j) = z_t^T k_j / √d 本质上是上下文-节点兼容性，有向边 c_t→j 不是函数的显式参数。
   - 嵌入中的隐式边估计在跨规模泛化时会产生分布偏移误差 ε_j(n)，导致排序能力退化。

3. **边感知偏置（Edge-aware Bias）：**
   - 构造转移描述符 φ_t(j)，包含三组特征：
     - **局部边（Local edge）**：D̂_{ct,j}、D̂_{j,ct}、D̂_{ct,j} − D̂_{j,ct}（当前有向成本及反向对比）
     - **闭合（Closure）**：D̂_{j,s_start}（返回起点的边界条件）
     - **静态前瞻（Static lookahead）**：min_{ℓ≠j} D̂_{jℓ}、min_{ℓ≠j} D̂_{ℓj}（粗粒度的延续成本估计）
   - 通过小型MLP生成偏置：b_t(j) = MLP_edge(φ_t(j))
   - 最终得分：s̃_t(j) = s_base_t(j) + b_t(j)
   - 保持SVD/Sinkhorn非对称表示骨干网络固定不变，仅修改解码器评分。

4. **尺度鲁棒性机制：**
   - 显式的 −αD̂_{ct,j} 项直接抵消隐式估计中的嵌入误差，使候选排序对噪声更鲁棒。
   - 闭合和前瞻特征是成本矩阵的确定性函数，提供跨规模不变的直接通路。

5. **ACVRP扩展：** 将闭合项替换为候选到仓库的成本 D̂_{j,0}，其余不变。

## 6. 论文的主要结论与发现

1. **表示-决策不匹配是神经非对称路由的解码器侧瓶颈**：有向成本信息虽被编码，但最终评分未显式暴露转移级信息。
2. **边感知解码器有效提升性能**：在ATSP-1000上，最优间隙从RADAR的4.13%降至2.73%；在ACVRP-1000上从0.96%降至−13.33%（相对LKH-10000参考）。
3. **局部有向边是最关键的特征**：移除局部边后，即使保留闭合和前瞻，ATSP-1000间隙反而恶化至5.04%（差于RADAR基线）。
4. **闭合和静态前瞻作为启发式延续线索**：移除闭合使ATSP-1000间隙从2.73%升至3.82%；移除前瞻使间隙升至3.03%。
5. **诊断实验证实机制**：边感知解码对当前有向边扰动和反对称扰动的响应更强，而对反向边控制保持接近随机水平。
6. **解码器设计原则的推广**：构造性求解器不应仅依赖节点兼容性，还应暴露反映立即成本和未来成本到目标的动作级数量。
