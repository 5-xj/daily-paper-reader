## 摘要
我们为加法幂等半环上的排列问题提供了改进的空间-时间权衡。特别是，对于旅行商问题，存在一种算法，使用空间S和时间T解决N个顶点的实例，其中S·T ≤ 3.1861^N。这改进了Koivisto和Parviainen [SODA'10]的先前工作，其中S·T ≤ 3.9271^N，并克服了他们识别出的障碍，因为他们的界限在其框架内被证明是最优的。为了获得我们的结果，我们引入了一个集合系统的新参数，称为链效率。它将集合系统中包含的最大链数量与系统的基数联系起来。我们表明，高效率的集合系统意味着排列问题的高效空间-时间权衡，并给出了具有高链效率的集合系统的构造，反驳了Johnson、Leader和Russel [Comb. Probab. Comput.'15]的一个猜想。

## Abstract
We provide improved space-time tradeoffs for permutation problems over additively idempotent semi-rings. In particular, there is an algorithm for the Traveling Salesperson Problem that solves $N$-vertex instances using space $S$ and time $T$ where $S\cdot T \leq 3.1861^{N}$. This improves a previous work by Koivisto and Parviainen [SODA'10] where $S\cdot T \leq 3.9271^N$, and overcomes a barrier they identified, as their bound was shown to be optimal within their framework. To get our results, we introduce a new parameter of a set system that we call the chain efficiency. This relates the number of maximal chains contained in the set system with the cardinality of the system. We show that set systems of high efficiency imply efficient space-time tradeoffs for permutation problems, and give constructions of set systems with high chain efficiency, disproving a conjecture by Johnson, Leader and Russel [Comb. Probab. Comput.'15].
