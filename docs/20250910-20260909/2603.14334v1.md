## 摘要
我们将非对称旅行商问题的近似比改进至小于15。我们还为无权有向图的特殊情形以及要求给定（不同）端点的最小成本环游的推广情形获得了改进的比率。此外，我们证明了自然线性规划松弛的整数性间隙的更好上界。

## Abstract
We improve the approximation ratio for the Asymmetric TSP to less than 15. We also obtain improved ratios for the special case of unweighted digraphs and the generalization where we ask for a minimum-cost tour with given (distinct) endpoints. Moreover, we prove better upper bounds on the integrality ratios of the natural LP relaxations.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

非对称旅行商问题（Asymmetric Traveling Salesman Problem, ATSP）是组合优化领域最著名的问题之一，在车辆路径规划等领域有广泛应用。给定一个强连通有向图 G=(V,E) 及非负边成本 c:E→R≥0，目标是寻找一个最小总成本的环游（即一个连通且欧拉的多重边集）。

ATSP的近似算法研究经历了重要进展：
- 不到十年前，Svensson、Tarnawski 和 Végh（2020）首次发现了常数因子近似算法，近似比为 506
- Traub 和 Vygen（2022）将其改进至 22+ε
- Traub 和 Vygen（2025）进一步改进至 17+ε

**本文的核心贡献：** 将ATSP的近似比进一步改进至 **小于15**，同时改进了无权有向图（Asymmetric Graph TSP）特殊情形以及固定端点路径版本（Asymmetric Path TSP）的近似比，并证明了自然LP松弛的整数性间隙的更好上界。

## 2. 论文提出的方法论

### 2.1 核心思想

本文的方法基于 **Svensson 算法的改进**。Svensson 算法是一种迭代算法，在每轮迭代中计算一个子环覆盖（subtour cover），该覆盖要么用于计算更好的初始化以允许重启，要么用于扩展当前部分解。

**关键创新点：** 作者引入了**新的更好初始化机会**，从而能够证明扩展部分解所用边总成本的更好上界。

### 2.2 关键技术细节

**（1）强层状实例归约：**

论文利用 Svensson、Tarnawski 和 Végh（2020）以及 Traub 和 Vygen（2022）的归约方法，将一般ATSP实例归约为具有特定结构的强层状实例（strongly laminar instance），其中：
- 给定一个层状族 L 及权重 y
- 每条边 e 的成本可表示为 c(e) = Σ_{L∈L: e∈δ(L)} y_L
- 给定最优LP解 x，满足 x(δ(L)) = 2 对所有 L∈L

**（2）脊椎对（Vertebrate Pairs）方法：**

- 定义**骨架（backbone）** B 为连通欧拉多子图，满足 V(B)∩L≠∅ 对所有 L∈L≥2
- 核心定理（Theorem 2）：若存在算法对任意强层状实例和骨架 B 计算边集 H，使得 E(B)∪H 是环游且 c(H) ≤ 2·LP + η·Σ_{v∈V\V(B)} 2y_v，则存在一般ATSP的 (8+η)·LP 近似算法

**（3）顶点预算（Vertex Budgets）：**

- 定义预算函数 ℓ: V\V(B) → R>0 用于支付局部边
- 对一般ATSP：ℓ(v) = max{γ·2y_v, (ε/n)·Σ_{w∈V\V(B)} 2y_w}
- 关键参数选择：γ = 1+√2，ε = min{1/10, (α-3-2√2)/6}

**（4）新的初始化引理（Lemma 5）：**

这是本文的核心新贡献。若存在局部回路 C 满足：
- V(C)\˜W_ind(C) ≠ ∅
- c(E(C)) > (1 + 1/(γ(1-ε)-1)) · Σ_{v∈V(C)∩˜W_ind(C)} 2y_v

则可以计算出一个显著更好的初始化。

**（5）新的 Step 2 算法：**

在 Svensson 算法的每轮迭代中，新增以下步骤：
1. 将子环覆盖 F 分解为回路
2. 移除完全包含在 (V\V(B), H) 的连通分量中的回路
3. 检查每个回路 C 是否满足条件 (6)，若满足则通过 Lemma 5 获得更好初始化并重启
4. 检查每个回路 C 是否满足条件 (7)，若满足则通过 Lemma 6 获得更好初始化并重启

**（6）关键定理（Theorem 8）：**

除非上述步骤导致显著更好的初始化，否则对每个回路 C∈F 有：
- slack(V(C), E(C)) ≤ slack(˜W_ind(C), ˜H) + ε·ℓ(V(C))
- c(F_i) ≤ 2(1-ε)/(γ(1-ε)-1) · ℓ(˜W_i)

**（7）最终成本分析（Lemma 10）：**

F-边总成本上界为：
- 若 B=∅：2(1-ε)/(γ(1-ε)-1) · ℓ(V)
- 否则：2·LP + Σ_{v∈V\V(B)} 2y_v + 2(1-ε)/(γ(1-ε)-1) · ℓ(V\V(B))

**（8）参数选择与最终结果：**

设置 γ = 1+√2 和 ε = min{1/10, (α-3-2√2)/6}，使得：
(1 + 2(1-ε)/(γ(1-ε)-1)) · (γ+ε) ≤ α

其中 α > 3+2√2 ≈ 5.828，从而得到近似比 9+α < 15。
