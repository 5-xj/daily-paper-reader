## 摘要
符号回归（SR）旨在从观测数据中发现简洁的数学定律，然而传统方法在处理物理上有意义的表达式的巨大组合搜索空间时往往面临困难。我们提出了InsightSR，一个将大型语言模型（LLMs）作为引导层嵌入PySR遗传编程引擎的框架。InsightSR不依赖于LLM直接生成表达式，而是通过两条互补路径逐步转换搜索空间本身：语义种子路径（Semantic Seed Pathway）提出量纲一致的功能骨架，结构特征路径（Structural Feature Pathway）推荐非线性特征变换。这些变换在迭代中不断累积，拓宽输入空间，并将符号搜索从基于原始变量构建深层表达式树转变为在丰富且语义信息丰富的特征集上组装浅层树。后生成反馈循环评估候选解，根据经验效用对特征进行分类，并为下一次迭代优化引导，将发现过程从开放式生成转变为迭代、自校正的优化过程。在三个基准测试中，InsightSR在费曼基准上实现了95%的精确恢复率，在LLM-SRBench LSR-Transform任务上达到了80.18%的准确率，大幅超越了最先进的遗传编程和神经符号方法，同时在真实世界数据集上保持了强大的分布外泛化能力。

## Abstract
Symbolic regression (SR) seeks to discover parsimonious mathematical laws from observational data, yet conventional approaches often struggle with the vast combinatorial search space of physically meaningful expressions. We present InsightSR, a framework that embeds Large Language Models (LLMs) as a guiding layer around the PySR genetic programming engine. Rather than relying on LLMs to generate expressions directly, InsightSR uses LLMs to progressively transform the search space itself through two complementary pathways: a Semantic Seed Pathway that proposes dimensionally consistent functional skeletons, and a Structural Feature Pathway that recommends nonlinear feature transformations. These transformations accumulate over iterations, broadening the input space and shifting the symbolic search from constructing deep expression trees over raw variables to assembling shallow trees over a rich, semantically informed feature set. A post-generation feedback loop evaluates candidates, categorizes features by their empirical utility, and refines the guidance for the next iteration, transforming the discovery process from open-ended generation into iterative, self-correcting refinement. Across three benchmarks, InsightSR achieves a 95% exact recovery rate on the Feynman benchmark and 80.18% accuracy on the LLM-SRBench LSR-Transform task, substantially outperforming state-of-the-art genetic programming and neural-symbolic methods while maintaining strong out-of-distribution generalization on real-world datasets.

## 1. 研究的核心问题与整体含义

符号回归（Symbolic Regression, SR）旨在从观测数据中自动发现简洁、可解释的数学定律，是自动化科学发现的核心技术之一。该问题面临两大根本性挑战：

- **组合爆炸**：候选表达式空间随表达式复杂度呈指数增长，而 SR 已被证明是 NP-hard 问题。
- **物理一致性缺失**：纯数据驱动的 SR 方法常生成数值精度高但物理意义缺失（如量纲不一致）的表达式，无法满足科学解释需求。

该论文的总体含义在于：将 LLM 的领域知识作为**引导层**而非直接解答者，嵌入到遗传编程引擎（PySR）外围，将无方向的随机搜索逐步转换为受物理先验和实证反馈约束的**迭代自校正搜索**，从而缓解上述两大问题，提升表达式恢复的准确性、物理有效性与泛化能力。

## 2. 提出的方法论

### 核心思想

InsightSR 不依赖 LLM 直接生成最终表达式，而是让 LLM 通过两条互补路径**渐进式改造搜索空间本身**：

- **自上而下的语义种子路径**（Semantic Seed Pathway）：基于物理量纲约束，提出物理上合理、量纲一致的函数骨架作为热启动种子。
- **自下而上的结构特征路径**（Structural Feature Pathway）：推荐非线性特征变换（如幂律项、三角函数），逐步拓宽输入特征空间，使搜索从深树构造转向浅层特征组合。

### 关键技术细节

**搜索目标**：

损失函数平衡数值精度与结构复杂度：
`L(f, D) = MSE(y, f(X)) + λ · C(f)`

其中 `C(f)` 为表达式结构复杂度（表达式树节点数），`λ` 为简约性惩罚系数。

**四阶段迭代循环**（每代执行，共 G 代）：

1. **上下文初始化与单位合成（Contextual Initialization & Unit Synthesis）**
   - 从数据元数据与问题描述中提取量纲信息；单位不明确时，LLM 基于物理语义推断。
   - 量纲约束持续贯穿整个搜索，保证候选表达式物理一致性。

2. **并行引导策略（Parallel Guidance Strategy）**
   - **语义种子路径**：LLM 生成量纲一致的函数骨架，审计后注入初始种群；并提供**算子复杂度偏置** `ωo`，调整复杂度计算：`C′(f) = Σ(co + ωo)`，即推荐算子获得负偏置、实现复杂度折扣；物理上不合理的算子被正偏置惩罚。
   - **结构特征路径**：LLM 推荐特征变换并累积至输入空间：`Xaug = [x1,...,xd, ϕ1(x),...,ϕk(x)]`，使搜索在信息更丰富的特征基上组装浅层表达式。

3. **PySR 引导搜索（Search with PySR）**
   - 将语义种子、算子偏好和增强特征矩阵传入修改后的 PySR 引擎。
   - 采用**热启动机制**，保留上代最优个体为精英，保证渐进收敛。

4. **多维评估与策略反馈（Multi-dimensional Evaluation & Strategic Feedback）**
   - LLM 对 Pareto 最优候选进行多维评估（数值精度、物理可解释性、变量完备性）。
   - 对特征空间诊断分类（有效/无效），结果累积至知识库，用于更新语义种子、复杂度偏置和特征推荐优先级，形成闭环自校正。

**伪代码流程**（Algorithm 1）：
