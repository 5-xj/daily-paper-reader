## 摘要
表格数据作为机器学习中的核心数据格式，由于特征信息不足，往往缺乏高性能建模所需的判别能力。自动特征工程（AutoFE）通过自动化特征生成和选择来解决这一问题，确保模型性能和操作效率。然而，传统的AutoFE由于依赖盲目的数学变换，往往产生可解释性较差的特征，而基于大型语言模型（LLM）的AutoFE则面临挑战，需要昂贵的多轮迭代来生成高实用性的特征以有效提升模型性能，同时还存在固有的偏差和幻觉风险。在本文中，我们将符号回归与LLM相结合用于特征工程（SymboLLM-FE），以解决这些挑战。我们通过符号回归提取与目标强相关的数学表达公式，这些公式可以提升模型性能，然后利用具有丰富先验知识的LLM对其进行优化，以确保可解释性。在六个真实世界数据集和四个Kaggle竞赛上的实验结果表明，SymboLLM-FE优于现有的AutoFE。SymboLLM-FE还通过采用基于统计先验的LLM优化机制和个位数次LLM调用，解决了可解释性差和迭代次数多这双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

## 2. 论文提出的方法论：SymboLLM-FE

- **核心思想**：将**符号回归**与**大语言模型（LLM）**协同使用：
  - 符号回归负责高效发现与目标强相关、数学表达明确且可提升性能的候选公式。
  - LLM 基于统计先验和领域知识对公式进行精炼，将其转化为语义可解释、符合业务逻辑的可执行代码。
- **两阶段流水线**：
  1. **公式构建（Formula Construction by Symbolic Regression）**
     - 先使用 **Spearman 相关系数**对特征进行重要性评估和排序，选择该指标是因为其能更稳健地捕捉非线性依赖关系，且与多种特征重要性指标一致性较高（Kendall's τ=0.65）。
     - 提出 **“扩展-滑动窗口”特征子集采样**策略：窗口大小从 ⌊n/2⌋ 动态增大至 n，并对每个窗口大小向右滑动生成多个连续子集，将候选子集数量从指数级 O(2^n) 降至多项式级 O(n²)。
     - 对每个特征子集分别训练符号回归模型，生成形如 `add(mul(c1,c2),c3)` 的数学表达式，并构建“特征子集—回归性能—公式”三元组仓库 R。
     - 符号回归使用遗传编程实现（gplearn），操作符集包含算术、三角函数、对数、分段函数等共 14 种保护算子，并引入精简惩罚（parsimony penalty）防止过拟合。
  2. **基于 LLM 的特征生成（Feature Generation via LLMs）**
     - 将仓库中的公式转换为自然语言描述，并附加数据集背景信息和代码生成提示，输入 LLM。
     - LLM 通过 **链式推理（Chain-of-Thought）** 生成 Pandas 形式的可执行特征工程代码。
     - 执行代码得到新特征集，合并到原始数据后训练**下游预测器**，获得验证集性能。
     - 将预测器性能、特征及生成代码反馈给 LLM，进行**迭代优化**，直至预测性能接近最优。
- **质量保障机制**：
  - 通过性能反馈**动态剪枝**低效用特征，控制特征预算，避免维度灾难。
  - 通过提示约束让 LLM 识别符号回归公式与原始特征之间的数学等价性，进行去冗余（消除多重共线性）。
  - 引入精简惩罚和严格限制 LLM 在统计有效子空间内操作，降低幻觉和噪声干扰。
- **数据集划分**：严格遵循交叉验证的分折协议，训练集仅用于符号回归公式构建，验证集用于 LLM 特征生成与超参选择，测试集仅用于最终评估，防止数据泄漏。
