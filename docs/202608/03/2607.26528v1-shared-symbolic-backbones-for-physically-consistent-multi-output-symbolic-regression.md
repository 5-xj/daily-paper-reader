## 摘要
符号回归提供解析表达式，但通常一次只应用于一个输出。这在过程系统中受到限制，因为状态变量通常通过共享的物理参数耦合。独立的符号回归可以得到精确的单个方程，但难以解释为一个整体模型。我们提出了一种用于耦合多输出系统的神经进化符号回归方法。该方法搜索一个共享的符号骨干：一组潜在符号单元，一旦发现，就被多个输出通过稀疏的加法或乘法读出重用。离散的模型结构通过变异和交叉进化，而连续参数通过梯度下降调整并由后代继承。该方法在一组已知真实基准和 hydrothermal 液化产率案例上进行了评估。结果表明，耦合并非通向更低预测误差的通用途径。其主要贡献在于，当物理共享因子嵌入潜在表达式且从数据中弱可识别时，强制和诊断跨输出一致性。这发生在 Langmuir-Hinshelwood 和位点覆盖分母上，对于这些情况，独立的 PySR 无法缩小一致性差距或恢复相同的共享形式。相反，当每个输出已经可识别时，如 Van de Vusse 基准，独立的符号回归匹配或改进了耦合模型。所提出的框架，而非通用预测器，是一种结构化的共享机制提取器。当目标结构稀疏、共享、弱可识别或受封闭性约束时，其价值最高。

## Abstract
Symbolic regression provides analytical expressions, but it is usually applied one output at a time. This is limiting in process systems, where state variables are often coupled through shared physical parameters. Independent symbolic regression can give accurate individual equations that are difficult to interpret as one model. We present a neuro-evolutionary symbolic regression method for coupled multi-output systems. The method searches for a shared symbolic backbone: a set of latent symbolic units that is discovered once and reused by several outputs through sparse additive or multiplicative read-outs. The discrete model structure is evolved by mutation and crossover, whereas the continuous parameters are tuned by gradient descent and inherited by the offspring. The method is assessed on a set of benchmarks with known ground truth and on a hydrothermal liquefaction yield case. The results show that coupling is not a general route to lower prediction error. Its main contribution is the enforcement and diagnosis of cross-output consistency when a physically shared factor is embedded in a latent expression and is weakly identifiable from the data. This occurs for Langmuir-Hinshelwood and site-coverage denominators, for which independent PySR does not close the consistency gap or recover the same shared form. Conversely, when each output is already identifiable, as in the Van de Vusse benchmark, independent symbolic regression matches or improves the coupled model. The proposed framework, rather than a general purpose predictor, is a structured shared-mechanism extractor. Its value is highest when the target structure is sparse, shared, weakly identifiable or constrained by closure.

## 1. 核心问题与研究动机

过程系统中的输出变量（如反应速率、产物产率）往往不是独立产生的，而是通过共享的物理参数或机制相互耦合：

- 多个反应速率可能共享同一个 Arrhenius 温度因子、吸附分母或抑制项；
- 产物产率之间受质量守恒约束；
- 动态状态变量通过化学计量关系和守恒律耦合。

然而，传统符号回归（Symbolic Regression, SR）通常一次只拟合一个输出。这种“独立逐输出”的做法虽然简化了拟合，但会产生如下问题：

- 各输出单独拟合时误差都很小，但放在一起读时不具有物理一致性；
- 本应共享同一温度依赖的两个速率，可能被拟合出不同的表观活化能；
- 本应满足闭合关系的多个产率拟合式，联合评估时却违反闭合约束。

因此，论文提出的问题不是“如何降低预测误差”，而是：**如何在多输出符号回归中强制并诊断跨输出的物理一致性，使共享物理因子被表示一次、重复使用，并可以被检查、简化和验证。**

## 2. 提出的方法论

论文提出了一种多输出共享骨干神经进化符号回归方法（Multi-Output Shared-Backbone Neuro-Evolutionary Symbolic Regression, MO-SB-NESR）。

### 2.1 核心思想

- 搜索一个**共享符号骨干（shared symbolic backbone）**：一组可复用的潜在符号单元（latent units）；
- 每个输出通过**稀疏的加法或乘法读出（read-out）** 选择并使用这些潜在单元；
- 离散模型结构由进化算法（变异 + 交叉）搜索；
- 连续参数由梯度下降优化，并通过**拉马克式继承（Lamarckian inheritance）** 传递给后代；
- 最终模型即为打印出的可读公式，而非黑箱网络。

### 2.2 架构组成

1. **特征库（Feature bank）**：对输入进行扩展，例如 [x, 1/x, log x, …]。
2. **符号骨干（Symbolic backbone）**：由 H 个潜在单元组成，每个单元包含一个离散算子 σ（如 exp、(·)²、id、1/(·)、log(1+·)、sin、√·）、一个二进制输入掩码 s_h，以及连续参数 (w_h, b_h)，形式为：

   z_h = σ_h(w_h^T (s_h ⊙ φ(x)) + b_h)

3. **读出（Read-outs）**：每个输出 o 有二进制模式（加法或乘法）和稀疏读出掩码 M_o，组合潜在单元：

   - 乘法形式（类幂律速率）： y_o = k_o ∏_{h} z_h^{e_{oh} M_{oh}}
   - 加法形式（类物料平衡）： y_o = κ_o + ∑_{h} c_{oh} M_{oh} z_h

共享是字面意义上的：一个潜在单元被多个输出共同引用，但每个输出可有自己的指数或系数（例如同一个 Arrhenius 潜在单元 exp(−1/T) 被三个输出以指数 1、2.5、1 使用，表示三个不同的活化能）。

### 2.3 训练流程

- 维护 P 个候选个体的种群，进化 G 代；
- 每一代：评估，选择，变异（翻转算子、改变输入掩码、切换输出模式），交叉（交换整个潜在单元）；
- 连续参数用 Adam 优化，损失为归一化逐输出均方误差：

  L = (1/n) ∑ (ŷ_o(x_i) − y_{io})² / σ_o²，其中 σ_o² = Var_i(y_{io})

- 后代继承父代已调好的连续参数，而非重新随机初始化。

### 2.4 评估方式

适应度函数包含拟合损失和三项结构稀疏性惩罚：

F = log L + λ_row ∑_{o,h} M_{oh} + λ_lat ∑_h 1[∃o: M_{oh}=1] + λ_in ∑_{h active} ‖s_h‖₁

- 第一项惩罚读出连接数（促进可解耦性）；
- 第二项惩罚使用过的潜在单元总数；
- 第三项惩罚每个潜在单元的输入数量。

最终模型选择采用无惩罚的验证集误差和简单复杂度计数，在误差允许范围内选最简模型。

### 2.5 领域先验与三臂协议（three-arm protocol）

为了区分“从数据中真发现”和“人为硬灌”，论文设计了三种先验注入方式：

- **无约束（unconstrained）**：无任何先验，纯盲搜索；
- **软先验（soft）**：将已知结构种子加入初始种群，但进化可自由保留或丢弃；
- **硬先验（hard）**：固定算子和输入集，只拟合常数。

通过对比三臂结果可得到四种诊断结论：

- **all-agree**：三臂都恢复形式，说明数据本身支持；
- **soft-recovers**：无约束不恢复，但软先验能恢复并保留，说明“可到达性缺口”；
- **hard-only**：只有硬先验可以，说明数据不可识别，需要更多数据而非更广搜索；
- **disagree**：三臂形式互斥但误差相近，说明先验与数据冲突。

## 6. 主要结论与发现

1. **耦合并不普遍降低预测误差**。论文明确否认“多输出耦合一定更准”的假设。

2. **耦合真正的价值在于跨输出一致性**。当共享物理因子嵌入潜在表达式且从单个输出中弱可识别时，共享骨干能强制一致性；独立 PySR 无法闭合一致性缺口，也恢复不出共享形式。

3. **判据不是“非可分离性”，而是“每个输出单独弱可识别性”**：
   - B1/B5/B6：输出本身可识别，独立 SR 匹配或优于耦合；
   - B2/B7：共享分母弱可识别，共享骨干具有结构性优势。

4. **共享常量的位置影响一致性**：常数若作为独立读出的输出系数，在噪声下会漂移不一致；若编码进共享潜在单元内部，则一致性是结构性的。

5. **领域先验需要一个受控的审计协议**：三臂协议（无约束/软/硬）能区分“数据支持”“先验辅助可达”“先验强制”和“先验冲突”，避免把硬先验的成功误认为发现。

6. **算子库和特征库需要刻意裁剪**：扩大库会稀释搜索并导致性能下降；面向领域的算子配置、物理感知采样和结构化稀疏是方法的一部分，而非可有可无的实现细节。

7. **它是一个结构化共享机制提取器，而非通用预测器**：HTL 案例中方法产出“闭合一致、紧凑、可解释”的共享温度驱动表达式，但不适合用作高维组成-产率的稠密预测模型。

## 7. 优点
