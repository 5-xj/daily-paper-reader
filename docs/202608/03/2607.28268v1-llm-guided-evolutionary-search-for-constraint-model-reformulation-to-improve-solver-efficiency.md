## 摘要
组合问题出现在众多工业应用中。一种常见的方法是将这些问题建模为声明式约束模型，随后可将其编译并由一系列后端求解器求解。最近的研究表明，大语言模型（LLMs）可以从自然语言生成正确的模型，但即使是正确的模型也可能求解成本高昂，因为性能对建模选择仍然敏感。在这项工作中，我们研究LLMs能否自动化面向性能的模型重构。受自动启发式设计（AHD）的启发，我们使用一个进化框架，其中LLM提出候选重构，这些重构经过验证并与用户定义的基线模型进行基准测试。我们比较了适应AHD的搜索策略，这些策略控制哪些先前的尝试、指令和测量反馈进入每个提示。现有的保留策略优先考虑近期性或性能，但并未显式多样化上下文。为弥补这一空白，我们引入了档案多样化保留（PDR），它将最大边际相关性（MMR）应用于实例级运行时向量，以保留行为多样化的尝试。我们使用基于验证的最终模型选择，在八个CSPLib问题上系统评估这些策略。结果表明：（i）迭代重构可以产生显著的留出加速；（ii）保持保留上下文多样化的策略优于仅保留最近或最快尝试的策略；（iii）基于验证的选择提高了每种策略的留出加速。

## Abstract
Combinatorial problems appear in numerous industrial applications. A common approach is to formulate these problems as declarative constraint models that can subsequently be compiled to and solved by a range of back-end solvers. Recent work shows that Large Language Models (LLMs) can produce correct models from natural language, but even a correct model can be expensive to solve because performance remains sensitive to modelling choices. In this work, we investigate whether LLMs can automate performance-oriented model reformulation. Inspired by Automatic Heuristic Design (AHD), we use an evolutionary framework in which an LLM proposes candidate reformulations that are verified and benchmarked against the user-defined baseline model. We compare AHD-adapted search strategies that control which prior attempts, instructions, and measured feedback enter each prompt. Existing retention strategies prioritize recency or performance, but do not explicitly diversify the context. To cover this gap, we introduce Profile-Diverse Retention (PDR), which applies Maximal Marginal Relevance (MMR) to instance-level runtime vectors to retain behaviourally diverse attempts. We systematically evaluate the strategies on eight CSPLib problems using validation-based final model selection. The results show that: (i) iterative reformulation can produce substantial held-out speedups; (ii) strategies that keep the retained context diverse outperform those that retain only recent or the fastest attempts; and (iii) validation-based selection improves the held-out speedup of every strategy.

## 1. 核心问题与整体含义

- **研究背景**：组合问题在调度、排程、配置等工业场景中广泛应用。标准流程是建模者将问题编码为声明式约束模型，再交由后端求解器求解。尽管大语言模型（LLM）已能根据自然语言生成可执行且正确的约束模型，但“正确”的模型未必高效——求解性能对建模选择（变量视角、约束编码、全局约束使用等）高度敏感。
- **核心问题**：能否利用 LLM 自动完成**面向性能的约束模型重构**（Model Reformulation），而不是仅生成正确模型？即让 LLM 迭代地修改模型，使求解器在相同语义下运行更快。
- **整体思路**：借鉴自动启发式设计（Automatic Heuristic Design, AHD）中的进化搜索范式，构建一个“LLM 提议 – 自动评估 – 反馈进化”的闭环。同时重点研究**如何选择历史尝试进入提示上下文**，并为此提出行为多样性保留策略 PDR（Profile-Diverse Retention）。

## 2. 方法论

### 2.1 核心思想

- 将 LLM 视为黑盒生成器：每次迭代输入包含基础指令、基线模型、历史尝试及反馈的提示，LLM 输出“理由 + 新的可执行模型”。
- 自动评估器对候选模型进行**实例级验证和基准测试**：检查返回答案相对基线的有效性（Definition 1 的 Solution Validity），并记录每个训练实例的求解时间。
- 搜索策略决定从历史中选择哪些尝试（及反馈）放入下一轮提示，从而影响 LLM 后续生成方向。

### 2.2 关键技术细节

- **问题形式化**：  
  模型 \(m\) 对实例 \(d\) 构建一个 CSP，并给出答案映射 \(\text{Ans}_m(d)\)。候选模型必须通过解级验证（将候选答案固定回基线模型，若仍有解则有效）。
- **优化目标**：最小化测试集上的总求解时间，同时满足所有测试实例的解有效性。
- **评估指标**：使用 PAR2（超时计为两倍时限）计算几何平均加速比。

### 2.3 搜索策略

- **Sampling**：无历史上下文，独立重复采样。
- **Full-history**：保留全部历史，超出上下文窗口时丢弃最旧条目。
- **Last-k**：仅保留最近 \(k\) 次尝试。
- **Top-k**：仅保留训练时间最短的 \(k\) 个有效模型。
- **Hybrid-(k,ℓ)**：同时保留最近 \(k\) 个和最快 \(\ell\) 个。
- **EoH（Evolution of Heuristics）**：维护最多 \(K\) 个模型的种群，用四个算子（完全不同方法、组合父母、局部结构修改、组件修改）生成新候选，并按时间适应度概率采样父母。
- **PDR（Profile-Diverse Retention）**：  
  - 将每个模型表示为一个 **实例级运行时归一化向量**（log 缩放 + 逐实例 min-max 归一化）；  
  - 用 RMS 距离度量两个模型行为差异；  
  - 质量分数为总运行时的归一化值；  
  - 使用 **最大边际相关性（MMR）** 迭代选择：先选最快模型，再逐步加入 \( \arg\max [\lambda \cdot \text{quality} + (1-\lambda)\cdot \min_{u\in R_t} d(m,u)] \)，直到达到 \(k\) 个，\(\lambda=0.5\)。

### 2.4 算法流程（文字说明）

1. 测量基线模型在训练实例上的运行时间，初始化空历史。
2. 对每次迭代 \(t\)：
   - 策略从历史中选择上下文和操作指令；
   - 构建提示（基础指令 + 基线信息 + 保留尝试 + 反馈）；
   - LLM 生成理由和候选模型；
   - 评估器运行候选模型，验证解有效性并记录运行时间；
   - 更新历史；若当前候选有效且训练总时间优于当前最优，则加入候选集合。
3. 搜索结束后，将所有候选模型在**验证集**上重新评估，选择验证总时间最低且有效的模型作为最终模型。
4. 最终模型在**测试集**上评估报告加速比。

## 6. 主要结论与发现

1. **迭代重构显著有效**：240 次运行中，144 次返回测试集上更快的模型；67 次返回基线（验证不符或没提升）；29 次训练更快但测试未提升。所有策略的 GM 加速比均在 1.55×–2.26× 之间。
2. **多样性上下文优于近期或最优保留**：PDR 取得最高 GM 加速比 2.26×，EoH+feedback 为 2.04×，Sampling 为 1.99×；PDR 较单纯质量保留 Top-5 提升 1.30×。
3. **验证集选择一致有效**：对每种策略，基于验证集的最终模型选择都优于直接选择训练最优模型，能有效过滤过拟合候选。
4. **整模型重构优于仅加约束**：对比 StreamLLM-single（仅附加 streamliner）GM 加速比 1.02×，PDR 与 EoH+feedback 分别为 2.26× 和 2.04×。
5. **成本差异**：PDR 在取得最高 GM 的同时比 Sampling 便宜约 27%（$0.12 vs $0.17/run）。
6. **生成的模型模式可解释**：成功模型普遍使用视角转换、布尔变量编码、隐含约束、表约束（tabulation）、对称性破缺等经典建模技术。
7. **失败模式明确**：如 BIBD 中大量超时（76% 候选超时）；覆盖数组训练实例过小导致验证/测试超时；过度添加大规模对称约束会增加传播开销。

## 7. 优点

- **问题新颖**：将 AHD 的 LLM 进化搜索首次系统应用于**声明式约束模型的性能重构**，并允许改变视角/编码而不只是追加约束。
- **策略设计有洞察**：提出 PDR，将行为多样性（实例级运行时向量 + MMR）引入上下文保留，抓住了“多样化上下文”在进化搜索中的关键作用。
- **评估严谨**：
  - 使用解级验证保证等价性；
