## 摘要
我们研究了智能体人工智能是否可以通过引入一个使用大型语言模型推理和检索增强生成的智能体框架，来自动化遗传编程系统设计过程中的部分环节。以符号回归为测试平台，我们首先对四种大型语言模型进行消融研究，以评估智能体推理和检索对生成算法类别、有效性、实现相似性和下游性能的影响。结果表明，这些组件显著影响生成的算法类型，但其下游性能在很大程度上取决于底层的大型语言模型。最强的配置，即完整的智能体设置与5 mini（5 mini--AR），在保持竞争性下游性能的同时，持续生成成熟的ε-lexicase实现。然后，我们将此配置与锦标赛选择和半动态MAD ε-lexicase的固定实现进行基准测试。在六个符号回归问题上，5 mini--AR的表现与ε-lexicase相似，同时普遍优于锦标赛选择。这些发现证明了智能体AI在将领域知识转化为生成可执行组件方面的潜力，为进化系统的自动化配置和设计迈出了一步。

## Abstract
We investigate whether agentic artificial intelligence can automate parts of the process of designing genetic programming systems by introducing an agentic framework that identifies and implements parent selection algorithms using large language model (LLM) reasoning and retrieval-augmented generation. Using symbolic regression as a test bed, we first conduct an ablation study across four LLM types to evaluate the effects of agentic reasoning and retrieval on generated algorithm categories, validity, implementation similarity, and downstream performance. Results show that these components substantially influence the types of algorithms generated, but their downstream performance largely depends on the underlying LLM. The strongest configuration, the full agentic setup with 5 mini (5 mini--AR), consistently generated established $ε$-lexicase implementations while maintaining competitive downstream performance. We then benchmark this configuration against fixed implementations of tournament selection and semi-dynamic MAD $ε$-lexicase. Across six symbolic regression problems, 5 mini--AR performed similarly to $ε$-lexicase while generally outperforming tournament selection. These findings demonstrate the potential of agentic AI to translate domain knowledge into generating executable components, providing a step toward automated configuration and design of evolutionary systems.

### 3. 实验二（基准评估）
- 将最强的配置 **5 mini–AR** 与两个固定参考实现比较：锦标赛选择（size=3）和半动态MAD ε-lexicase。

## 六、论文的主要结论与发现

1. **RAG模块显著影响算法家族选择**：除5 mini外，所有模型的LLM和ANR配置均100%生成锦标赛选择；加入RAG（AR）后，各模型的ε-lexicase生成比例大幅提升（oss 20b: 44.4%、4o: 76.2%、4.1 mini: 98.4%、5 mini: 100%）。

2. **下游性能强烈依赖底层LLM**：
   - 对oss 20b，RAG虽改变算法类型但未带来性能差异（其ε-lexicase实现83.9%使用未归类的方法，零MAD实现）。
   - 对4o和4.1 mini，AR配置生成的ε-lexicase虽多，但阈值参数化不良（固定值过小或方法不符合文献），导致性能反而显著下降。
   - 对5 mini，AR配置最稳定地生成符合文献的MAD阈值、半动态/动态ε-lexicase，性能与LLM/ANR相当且略微占优。

3. **分类成功 ≠ 执行成功 ≠ 性能成功**：识别出正确的算法家族≠实现正确；实现正确≠参数化正确；参数化正确≠性能优越。

4. **5 mini–AR 的基准结果**：在六个SR问题上与固定semi-dynamic MAD ε-lexicase实现性能**无显著差异**，且在5个问题上显著优于锦标赛选择（p<0.05或p<0.001），验证了自动化生成的可行性。

5. **智能体AI的潜力**：该研究提供了证据，表明智能体LLM能够将领域知识（通过RAG获得的文献）转化为有效的可执行算法组件。

1. **问题选择具有战略意义**：父代选择是GP中核心且设计空间较大的组件，以此作为智能体自动设计的首个测试点是理想选择。

## 八、不足与局限

1. **领域覆盖局限**：仅评估了符号回归一个任务域和6个数据集，结论向其他GP应用领域（如程序合成、多目标优化）的泛化缺乏依据。
2. **组件覆盖局限**：仅针对父代选择一个组件进行自动生成，GP中的表示、变异算子、适应度评估等仍未被纳入智能体自动设计；多个组件的交互效应未被考察。
3. **LLM依赖风险**：结果对底层LLM的选择高度敏感，4o和4.1 mini在AR下性能反而下降，表明该框架在不同模型间的可靠性差异大。且仅测试了OpenAI模型，覆盖面有限。
4. **RAG语料规模小且固定**：仅9篇论文、top-k固定为4、单一嵌入模型，未探讨语料组成、检索策略对生成质量的影响。
5. **缺少反馈验证闭环**：框架仅单向前向生成算法，没有根据生成算法在下游GP中的表现来指导重新生成或优化，属于开环而非闭环设计。实验二中个别复现出现极端MSE也印证了这一点。
6. **成功标准的严格性**：分类成功需同时匹配算法家族+变体+阈值方法，要求虽高但合理；然而对“成功”的判定本质上依赖人工专家的主观分类，存在一定的标签噪音风险。
7. **计算资源信息不足**：未报告生成算法所需的LLM调用量、token消耗等经济成本信息，限制了实际部署可行性的评估。
