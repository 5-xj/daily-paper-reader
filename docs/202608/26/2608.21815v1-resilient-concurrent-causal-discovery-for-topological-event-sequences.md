## 摘要
拓扑事件序列上的因果发现对于确保网络的可靠性至关重要。然而，现有方法难以捕捉由并发事件产生的复杂因果关系，并且对不完整事件序列缺乏鲁棒性。为解决这些问题，我们提出了一种弹性并发因果发现方法，称为RCCD，能够从拓扑事件序列中鲁棒地学习因果图。具体而言，我们首先引入了一种影响感知的超边因果注意力机制，该机制将事件持续时间纳入嵌入表示，通过超边因果卷积聚合并发事件特征，并注入网络先验知识以捕捉复杂的多对一因果交互。此外，我们设计了一个基于掩码的交替因果优化框架，通过自监督掩码重建迫使模型基于上下文恢复被掩码的事件类型，从而增强预测器对缺失数据的弹性。为验证我们方法的有效性，我们在模拟和真实电信网络数据集上进行了广泛实验。实验结果表明，所提方法在准确性和鲁棒性上均显著优于现有最先进方法，使其更适合真实的电信网络环境。

## Abstract
Causal discovery on topological event sequences is crucial for ensuring the reliability of networks. However, existing methods struggle to capture the complex causal relationships arising from concurrent events and lack robustness to incomplete event sequences. To address these issues, we propose a resilient concurrent causal discovery method, termed RCCD, enabling robust learning of causal graphs from topological event sequences. Specifically, we first introduce an influence-aware hyperedge causal attention mechanism, which incorporates event duration into the embedding representation, aggregates concurrent event features via hyperedge causal convolution, and injects network prior knowledge to capture the complex many-to-one causal interactions. Furthermore, we design a masked-based alternating causal optimization framework, which forces the model to recover masked event types based on context through self-supervised mask reconstruction, thereby enhancing the resilience of the predictor to missing data. To validate the effectiveness of our method, we conduct extensive experiments on both simulated and real-world telecommunication network datasets. Experimental results demonstrate that the proposed method significantly outperforms existing state-of-the-art methods in both accuracy and robustness, making it more suitable for real-world telecommunication network environments.

## 1. 论文的核心问题与整体含义

- **背景与动机**：电信网络中的异常事件（如设备故障）会产生大量按时间顺序记录的告警事件序列。因果发现方法能够从这些序列中识别事件类型之间的因果关系，帮助运维人员定位根因、阻断故障传播，是保障网络可靠性的关键。
- **核心挑战**：现有方法在两类问题上存在明显不足：
  - **并发事件复杂性**：真实网络中多个告警可能同时发生，且事件持续时间会影响故障传播强度，形成多对一的复杂因果交互。现有基于多层感知机或标准自注意力的方法难以捕捉这类并发协作效应。
  - **不完整观测鲁棒性**：网络拥塞、日志解析错误等会导致事件序列缺失，而现有统计点过程方法和神经点过程方法普遍假设序列完整，对缺失数据缺乏抵抗力。
- **总体含义**：论文提出 RCCD（Resilient Concurrent Causal Discovery）方法，旨在从拓扑约束下的不完全事件序列中鲁棒地学习有向无环因果图，从而提高因果发现在真实电信环境中的准确性与可靠性。

## 2. 论文提出的方法论

RCCD 由两个核心组件构成：**影响感知超边因果注意力机制（IHCA）** 和 **基于掩码的交替因果优化框架（MACO）**。

- **IHCA：影响感知超边因果注意力机制**
  - **事件影响感知编码**：将事件持续时间 \(d_i\) 通过可学习非线性映射 \(F(\cdot)\) 编码为嵌入，并用指示函数 \(\Pi\{d_i>0\}\) 做门控，使瞬时事件（持续时间为 0）不产生额外噪声。最终嵌入由事件类型嵌入、时间编码和持续时间嵌入三部分相加构成。
  - **超边因果注意力分数**：在标准注意力基础上，对 Key 和 Value 分别应用深度可分离因果卷积 \(\Psi(\cdot)\)，并加入残差连接，将局部时间窗口内的连续事件聚合为“超边”表示，从而让 Query 能直接与超边交互，模拟多个原因事件共同导致一个效果事件的多对一因果关系。
  - **拓扑约束的因果注意力**：引入可学习的因果概率矩阵 \(\tilde A\)（经 Gumbel-Softmax 采样），以及基于 \(k\)-hop 邻接矩阵和可学习拓扑衰减系数 \(\phi\) 的衰减项 \(\delta_{j,i+1}\)，将注意力分数乘以因果权重和拓扑衰减，使得只有被因果图允许且拓扑距离较近的事件对才能保留有效注意力权重。
  - 多头的输出拼接后经线性变换，配合残差连接、层归一化和前馈网络，以自回归方式预测下一个事件，并端到端优化因果图和拓扑衰减参数。

- **MACO：基于掩码的交替因果优化框架**
  - **掩码生成策略**：在训练中按概率 \(p\) 随机掩码部分事件类型，使用特殊掩码 token 替换，同时避免掩码填充位置和预测目标位置。被掩码的事件需通过上下文重建。
  - **E 步（预测器训练）**：固定因果权重和拓扑衰减参数，输入掩码后的序列，预测下一事件类型、时间间隔以及被掩码位置的事件类型。总损失由四部分组成：
    - 事件强度似然损失 \(L_H\)（基于 Hawkes 过程强度函数）；
    - 事件类型预测损失 \(L_V\)（交叉熵）；
    - 时间间隔预测损失 \(L_T\)（均方误差）；
    - 掩码重构损失 \(L_R\)（对掩码位置的负对数似然）。
  - **M 步（因果学习）**：固定预测器参数，使用未掩码的原始序列优化因果权重和拓扑衰减参数，损失中加入稀疏正则项 \(\sigma_1\|\omega(\tilde A)\|_1\) 和来自 NOTEARS 的有向无环性惩罚 \(\sigma_2 h(\omega(\tilde A))\)，保证学习到的因果图稀疏且无环。
  - **因果判定**：训练完成后，对每个事件类型对，若因果概率 \(\omega(\tilde A_{i,j})\) 超过预设阈值 \(\rho\)，则判定存在因果边，最终输出二值因果矩阵 \(A\)。

## 6. 论文的主要结论与发现

- 在稳定数据集上，RCCD 在 F1 分数上全面领先：合成数据集上 F1 达 0.8421 和 0.8750，远高于 CausalNET（0.6364、0.6341）和 THPs（0.6429、0.8649）；真实数据集上也取得最佳 F1（0.5313、0.4967）。

- 消融实验表明，IHCA 主要提升 F1 和召回率，MACO 在缺失场景下维持结构准确性，两者结合能达到最佳性能。
- 超参数敏感性低，σ1 和 σ2 在 0.1~0.3 范围内变化对结果影响很小，说明方法易于使用。

## 7. 优点

- **问题新颖**：首次针对拓扑事件序列在“不完整观测”条件下的因果发现进行建模，切入点贴近真实网络运维场景。
- **方法设计有针对性**：
  - 将事件持续时间引入注意力机制，通过门控减少瞬时事件噪声；
  - 用深度可分离因果卷积构造超边，显式建模并发事件的多对一因果；

- **鲁棒性机制合理**：掩码重构损失迫使预测器不依赖完整输入，自监督训练方式无需额外标注，简洁有效。
- **实验丰富**：覆盖合成与真实数据、多种缺失率、超参数敏感性、消融以及 LLM 对比，验证较为全面。
