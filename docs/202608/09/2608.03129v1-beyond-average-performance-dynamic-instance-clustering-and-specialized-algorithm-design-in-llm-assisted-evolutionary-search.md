## 摘要
大型语言模型辅助进化搜索（LES）已成为自动化算法设计的一种强大范式。然而，现有LES方法主要优化平均性能，本质上将搜索工作导向对平均性能贡献最大的实例，而其他实例则得不到良好覆盖，导致尾部鲁棒性薄弱，实际可靠性受限。为解决这一局限，我们提出动态实例聚类与专用算法设计（DyCA），一种在异构实例分布下构建可靠算法组合的LES框架，其机制无需特征、基于结构感知。DyCA将实例聚类视为搜索过程中的一个共同演化组件，复用累积的评估数据作为无特征信号，逐步将具有相似算法响应模式的实例进行划分。所发现的聚类将混合目标分解为一组结构感知的子目标，从而为专用算法设计提供更细粒度、更具适应性的指导。在四个具有异构实例的算法设计任务上的实验结果表明，DyCA优于最先进的LES基线，平均尾部鲁棒性提升15.2%，整体性能提升7.1%，同时保持有竞争力的头部性能。

## Abstract
Large Language Model-assisted Evolutionary Search (LES) has emerged as a powerful paradigm for automated algorithm design. However, existing LES methods primarily optimize for average performance, inherently directing search effort toward instances that contribute most to this metric while leaving others poorly served, resulting in weak tail robustness and limited real-world reliability. To address this limitation, we propose Dynamic Instance Clustering and Specialized Algorithm Design (DyCA), an LES framework with a feature-free, structure-aware mechanism for constructing reliable algorithm portfolios under heterogeneous instance distributions. DyCA treats instance clustering as a co-evolving component within the search process, reusing accumulated evaluation data as feature-free signals to progressively partition instances with similar algorithmic response patterns. The uncovered clusters decompose the mixed objective into a set of structure-aware sub-objectives, thereby enabling finer-grained and more adaptive guidance for specialized algorithm design. Experimental results across four algorithm design tasks with heterogeneous instances demonstrate that DyCA outperforms state-of-the-art LES baselines, improving tail robustness by an average of 15.2\% and overall performance by 7.1\% while maintaining competitive head performance.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型辅助进化搜索（LLM-assisted Evolutionary Search，LES）已成为自动算法设计（Automated Algorithm Design）的重要范式，在组合优化、符号回归、机器学习等领域取得显著成果。
- **核心问题**：现有 LES 方法普遍以`平均性能`作为优化目标。在实际中，实例分布往往是高度异构的（heterogeneous），优化平均值会诱发**多数主导偏向（majority-dominance bias）**，即搜索过程倾向于改善在多数/简单实例上的表现，而忽视少数/困难实例，导致算法组合在“尾部”（worst-case）性能上鲁棒性差，难以满足关键任务对可靠性、最坏情况性能的要求。
- **矛盾与挑战**：缓解该偏差需要对实例空间有结构性理解；但经典实例空间分析（Instance Space Analysis, ISA）依赖预先定义的、领域特定的实例特征，而 LES 常应用于新领域或黑盒问题，此类特征难以获取，导致传统 ISA 不适用。由此引发核心研究问题：*在无预定义实例特征的情况下，如何让 LES 在异构实例上生成具有强尾部鲁棒性的算法？*
- **本文回应**：提出 **DyCA（Dynamic Instance Clustering and Specialized Algorithm Design）**，一种无特征、行为驱动、动态在线实例空间分析的 LES 框架。DyCA 将实例聚类作为搜索过程中的共演化组件，复用演算中自然累积的“算法–实例”评估数据，将实例按算法响应模式动态分组，从而实现偏差感知的专用算法设计。

## 2. 论文提出的方法论

### 2.1 核心思想

- **行为即特征**：将算法视作实例空间的“探针”，实例的内在难度与可解性可由它在多样算法集合下的性能响应向量表征。两个实例行为相似，则它们对多种算法的性能响应模式相似。
- **数据复用**：不需要任何领域特征，只使用 LES 过程中已经产生的算法–实例表现矩阵 X∈R^{M×n}。
- **动态在线分析**：实例结构不是预先固定的，而是在进化过程中随锚定算法集合的更新而不断细化和校准。

### 2.2 关键技术组成部分

#### (1) 行为驱动的动态实例空间分析（B-DISA）

- **锚定算法选择（Anchor Selection）**：当算法档案 n 很大时，直接用全响应向量聚类不可行。B-DISA 从当前算法集中选出一小组“锚定算法” Z⊂A（|Z|≪n），构成低维但具有判别力的响应矩阵 X̄∈R^{M×|Z|}。
- **自然断点离散化预处理（Natural Break Discretization）**：对每个实例的响应向量进行一维聚类，将连续性能值映射为分层的“行为层级”，以消除不同实例绝对评分范围差异造成的偏差。
- **贪心前向选择 + 反向剪枝**：选择能最大化唯一响应模式数的锚定算法，再剔除冗余锚点，保持紧凑的同时维持判别力。
- **聚类与簇数确定**：在锚定诱导响应矩阵行上使用 k-means 聚类，簇数 K 由肘部法则（elbow method）自适应确定。
- **动态重校准（Dynamic Recalibration）**：每 100 次 LLM 查询重新执行锚点更新与实例重聚类；增量式更新使判别力单调不减，保证早期不准确结构可被纠正。

#### (2) 偏差感知的进化搜索循环

DyCA 将 B-DISA 与 LES 紧密耦合，循环执行以下步骤：
1. **初始化**：多次提示 LLM 生成初始算法池，获得初始行为证据。
2. **动态实例结构学习**：更新锚点集合与实例簇。
3. **偏差感知进化搜索**：
   - 使用**加权的互补池管理（W-CPM）** 代替原 CPM：对每个实例按簇大小赋予权重 1/|C_k|，使各簇对选择目标的贡献均衡，避免大簇或“容易得分”实例主导搜索压力。
   - 为每个簇维护**专用算法池（Specialist Pool）**，专注于该簇的局部目标；并利用实例结构进行**偏差感知的 LLM 推理预算分配**（见公式与策略）。
   - 支持跨池知识共享，并可在专用池停滞时引入其他池的算法以跳出局部最优。

### 2.3 关键公式

- **加权互补性能指标（W-CPM）**：

  \[
  \Delta CPI_w(\tilde{a}\mid P_t)=
  \sum_{k=1}^{K}\sum_{i_m\in C_k}
  \frac{1}{|C_k|}\max\big(f_m^*(P_t)-f_m(\tilde{a}), 0\big)
  \]

- **资源分配权重**：

  \[
  W_k =
  \begin{cases}
  +\infty, & \text{冷启动时}\\
  \Delta_k \cdot \max(\gamma_{\min},\alpha^{\eta_k}), & \text{其他情况}
  \end{cases}
  \]
  其中 Δ_k 为簇 k 的剩余改进潜力，η_k 为连续未改进代数，α 为衰减率，γ_min 为最小权重下限。

- **选择概率**：
  \[
  P(k)=\frac{W_k}{\sum_{j=1}^{K}W_j}
  \]
  从而实现关注困难簇、自动抑制停滞簇的“断路器”机制。

## 6. 论文的主要结论与发现

1. **DyCA 在所有四个任务上平均性能和尾部性能均优于所有基线**。
   - 相比标准 LES 方法，平均性能提升 33.2%；相比可靠性增强 LES 基线，平均性能提升 7.1%。
   - 尾部（最差 10%）性能相对 InstSpecHH 与 EoH-S 平均提升 15.2%，相对标准 LES 方法提升 53.1%。
2. **尾部提升不牺牲头部性能**：DyCA 在头部性能上仍保持前两名水平，尾部大幅压缩，性能分布整体更集中、更可靠。
3. **LLC 任务上，DyCA 是唯一尾部平均分超过 200 的方法**，即在最困难条件下仍能成功着陆，说明可靠性的实际价值。
4. **公共基准上的泛化能力**：不微调直接迁移到 CVRPLib/TSPLib/BPPLib，DyCA 均优于既有 LES 方法，表明结构信息有助于跨分布稳健性。
5. **B-DISA 无监督地发现真实语义结构**：在 OBP 中自动划分出均匀/威布尔/双峰分布，并在威布尔内部进一步细分；在 CVRP 中识别出重需求、聚类客户、高容量等类别。这些聚类虽不经任何标签训练，却与领域知识高度一致。
6. **消融实验量化组件贡献**：
   - 无聚类导致 12.46% 退化；
   - 随机聚类导致 9.89% 退化；
   - 特征聚类（Oracle）与 DyCA 几乎持平（DyCA 略好，0.35% 差异），说明行为特征足够替代专家特征；
   - 去加权机制导致 5.55% 退化；
   - 去自适应分配导致 7.25% 退化；
   - 去专用进化导致 8.06% 退化；
   - 去知识共享导致 5.35% 退化。

## 7. 优点

- **新颖且原理清晰**：将实例空间分析从“静态、特征依赖”转向“动态、行为驱动”，直接攻击平均性能优化的根本局限。
- **框架通用性强**：B-DISA 完全任务无关，不依赖任何领域特征；DyCA 可与任意 LES 机制集成，仅需算法与实例的评估数据。
- **计算开销低**：结构学习基于演化过程中已自然产生的数据，锚点选择与聚类很轻量（<2 秒），相对于 LLM 查询和评估成本可忽略。
- **方法论严谨**：W-CPM 被证明保持非负性、可加性与子模性，因而保留贪心选择的近似保证，同时修正分布不均衡问题。
- **实验验证充分**：
  - 覆盖多任务、多分布、多规模；
  - 包含标准 LES 基线和可靠性增强 LES 基线；
  - 提供统计检验（置信区间 + 非参数配对检验）；
  - 消融实验细致，包含 Oracle 对照；
  - 公共基准验证泛化性。
- **讨论深入**：论文承认响应指标稳定性的限制、推理成本权衡，并展望超快推理（如特征匹配器），展现出客观的学术态度。

## 8. 不足与局限

- **对响应指标稳定性要求高**：B-DISA 依赖同一算法在实例上的可重复响应。若响应度量易受环境干扰（例如运行时间），聚类结果将被噪声扭曲。论文明确指出应将解决方案质量、规范化目标等稳定指标作为响应。
- **运行次数偏少**：每个任务仅 3 次独立运行，虽然方差较低，但仍难完全覆盖 LLM 随机性导致的分布尾概率。
- **未报告完整算力指标**：未给出 API 调用成本总额、总运行时间，也未说明 GPU 使用情况；尽管实验为 CPU + API 模式，但缺乏可复现的算力衡量。
- **头部性能轻微损失**：在部分任务上，DyCA 的头部性能略差于 EoH-S（例如 CVRP 上 0.0219 vs 0.0144），虽然尾部收益远超此损失，但若应用场景对“最好性能”极度敏感，需权衡。
- **推理阶段开销增加**：与单算法方法相比，DyCA 输出的组合（portfolio）需要对新实例选择合适的算法，额外增加推理成本；论文将其视为透明权衡而非缺陷，但在低延迟场景可能受限。
- **仅测试 GPT-4o-mini**：未验证不同 LLM 能力层级的鲁棒性，也未测试更大模型或更小模型能否保持相对优势。
- **合成实例集与真实分布仍有差距**：虽然训练集刻意引入多种分布，但真实部署时的分布漂移可能更严重；公共基准实验提供了部分补偿，但未做分布漂移强度的逐步分析。
- **簇数量自适应方法的广泛性**：k-means + 肘部法则简单有效，但在边界簇或重叠分布场景下可能产生不稳定分组；论文未测试其他聚类算法（如 DBSCAN、谱聚类）。
