## 摘要
检索系统通过提供相关文档帮助深度研究智能体生成高质量答案。然而，现有的检索器通常通过相关性匹配来选择文档，而个别匹配良好的前k篇文档可能无法形成一个满足智能体查询复杂信息需求的文档集合（例如，多样化、简洁且权威的文档）。在本文中，我们提出了面向搜索的准则，这些准则显式定义了对于每个智能体查询，高质量文档集合应满足的要求。我们的搜索准则被组织为层级结构，并使用强大的大语言模型进行综合。基于这些搜索准则，我们进一步训练了一个文档重排器RubricRanker，以从检索到的文档中选择高质量的子集。我们设计了一个两阶段训练框架，包括准则引导的监督微调和基于准则的强化学习。大量实验表明，RubricRanker在四个深度研究基准上比最强基线高出2.6个百分点，并在五个RAG基准上表现良好。

## Abstract
Retrieval systems help deep research agents generate high-quality answers by providing relevant documents. However, existing retrievers typically select documents through relevance matching, while individually well-matched top-$k$ documents may not form a \textit{set} that satisfies the complex information needs of an agent query (\eg, diverse, concise and authoritative documents). In this paper, we propose search-oriented rubrics that \textit{explicitly} define the requirements that high-quality document sets should satisfy for each agent query. Our search rubrics are organized into a hierarchical structure and synthesized using a powerful LLM. Based on these search rubrics, we further train a document reranker \textbf{RubricRanker} to select a high-quality subset from retrieved documents. We design a two-stage training framework that consists of rubrics-guided supervised fine-tuning and rubric-based reinforcement learning. Extensive experiments demonstrate that RubricRanker outperforms the strongest baseline by 2.6 points on four deep research benchmarks and generalizes well to five RAG benchmarks.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：深度研究（Deep Research）智能体通过多轮“规划—搜索—综合”的方式回答复杂的信息寻求型任务，其依赖文档检索系统提供证据支持。与传统单轮检索不同，深度研究智能体每次交互都会根据当前信息需求发出**智能体查询（agent query）**，检索系统返回的文档集合质量直接决定最终回答的可靠性。
- **核心问题**：现有文档检索器与重排器（如 BGE-Reranker、MonoT5、RankT5）**仅基于单篇文档与查询之间的相关性匹配**来选择 top-k 文档。但单个相关性良好的文档所拼凑成的集合，未必满足智能体查询的复杂信息需求——例如：
  - **多样性不足**：可能遗漏某类重要信息（如抑郁症治疗中的“自我调节”方式）；
  - **冗余**：多篇文档包含重复信息，浪费智能体的上下文预算；
  - **权威性缺失**：选中的文档可能来自不可靠来源（如个人博客），导致智能体生成不可靠建议。
- **核心洞察**：需要从“单文档相关性”转向“文档集合级质量”，显式定义高质量文档集合应满足的搜索准则（search rubrics），并用这些准则来训练重排器。

## 2. 论文提出的方法论

### 2.1 整体框架

论文提出 **RubricRanker**——一个基于搜索准则训练的文档重排器，由两大模块构成：
1. **搜索准则构建**（Search Rubrics Construction）：为每个查询生成查询特定的层次化准则；
2. **基于准则的重排器训练**（Rubric-Based Reranker Training）：利用准则通过两阶段训练范式优化重排器。

### 2.2 搜索准则构建

- **元准则设计（Meta Rubrics Design）**：为避免直接让 LLM 生成准则时出现覆盖面不足、维度混淆等问题，作者预先定义了一个**层次化元准则框架**，包括：
  - **集合级准则（Set-level）**：
    - *相关性（Relevance）*：文档集合是否覆盖查询所需的关键信息与多样化的答案方面；
    - *简洁性（Conciseness）*：集合中是否存在冗余、重复或无关内容；
    - *一致性（Consistency）*：文档间的关键事实、主张和结论是否相互兼容而非矛盾。
  - **文档级准则（Doc-level）**：
    - *来源权威性（Source Authority）*：文档是否来自权威可信来源（医学、法律、政策等高利害领域尤为重要）；
    - *时效性（Timeliness）*：文档是否满足查询的显式时间约束或对最新信息的需求。
- **训练查询收集**：从深度研究数据集（OpenScholar、SearchArena、GlaiveAI-Reasoning-v1-20M、WebWalker-Silver）中使用 Dr-Tulu-8B 智能体生成完整轨迹并提取智能体发出的子查询；同时从 RAG 数据集（HotpotQA、NQ）收集用户问题以增强多样性。
- **答案合成**：对深度研究场景的智能体子查询，使用 GPT-5.1（带网络搜索）生成高质量参考答案，作为信息需求蓝图；对 RAG 场景直接使用数据集提供的金标准答案。
- **查询特定准则生成**：基于元准则、查询和参考答案，使用 GPT-5.1 扩展生成查询特定的具体准则，每条准则包含自然语言描述和 1–5 的重要性权重。

### 2.3 基于准则的重排器训练

- **第一阶段：准则引导的有监督微调（Rubrics-Guided SFT）**
  - 使用 GPT-5.1 作为教师模型，根据查询特定准则从候选中选择最优文档子集，生成**银标签**用于冷启动训练。
  - 每个训练查询检索 10–40 篇变长候选文档，增强模型对不同输入规模的适应性。
  - 学生模型（Qwen3-8B）仅以查询和候选文档为输入，不接触准则，与推理阶段一致。
- **第二阶段：基于准则的强化学习（Rubric-Based RL）**
  - 核心思路：利用准则权重计算更精确的奖励信号，通过细粒度滚动比较优化重排器。
  - 使用 **GRPO 算法**优化模型。
  - **层次化奖励聚合**：最终奖励由集合级分数与文档级分数加权求和得到——
    \[
    P_r(D) = \frac{\sum_i sw_i \cdot S(sr_i, D) + \sum_j dw_j \cdot F(dr_j, D)}{\sum_i sw_i + \sum_j dw_j}
    \]
    其中 \(S(sr_i, D)\) 由 LLM 评估器对文档集合整体的准则满足度打分；文档级分数则逐篇打分后取平均：
    \[
    F(dr_j, D) = \frac{1}{|D|}\sum_{d \in D} S(dr_j, d)
    \]
  - **格式奖励**：输出必须是合法的文档 ID 序列（如 "[1] [3] [2]"），格式错误则奖励设为 −1。
- **推理阶段**：RubricRanker 直接根据查询从检索候选中选择高质量子集，**无需在推理时提供搜索准则**。

## 6. 论文的主要结论与发现

1. **RubricRanker 在深度研究基准上显著优于最强基线**：平均得分 60.1，比 Rank4Gen（57.5）高 **2.6 分**。
2. **在 RAG 基准上也表现最优**：平均 EM 得分 40.0，比 Rank4Gen（38.2）高约 **2 分**。
3. **面向生成的重排器不一定能泛化到深度研究任务**：Rank4Gen 在 RAG 上表现好，但在深度研究基准上增益几乎消失，说明基于封闭式任务的训练信号难以迁移到开放式深度研究场景。

## 7. 优点

1. **问题定义清晰且具有现实意义**：从集合级视角定义文档质量，突破了传统单文档相关性匹配的局限，切中深度研究智能体的真实需求。
2. **层次化元准则设计合理**：通过固定元准则框架引导查询特定准则生成，避免直接提示 LLM 生成准则时常见的覆盖不全、维度混淆等问题；准则同时涵盖集合级（相关性/简洁性/一致性）和文档级（权威性/时效性）。
3. **两阶段训练框架设计精巧**：SFT 提供冷启动稳定初始化，RL 基于准则权重进行精细化优化；格式奖励的设计保证了输出可解析性。
4. **推理阶段零额外成本**：模型在推理时不需要重新生成准则，直接输出文档 ID 序列，不增加推理负担。
5. **实验设计较全面**：同时覆盖深度研究和 RAG 两大场景，泛化性强；搜索调用分析补充了效率维度的证据。
6. **透明性**：提供完整的 prompt 模板（附录中展示了 17 个提示词），便于复现和后续研究。

## 8. 不足与局限

1. **成本高昂**：构建准则和计算奖励依赖 GPT-5.1 商业 API，扩展到大规模训练语料时成本很高（论文已指出未来计划训练专用奖励模型来解决）。
2. **深度研究基准采用抽样评估**：由于 LLM 评估成本高且深度研究智能体推理速度慢，仅采样 100–200 条查询进行评测，可能无法完整反映模型在完整基准集上的表现。
3. **评估指标受最终生成质量制约**：即使重排器选出了高质量的文档集，智能体在推理或生成阶段仍可能出错；论文承认需要开发更客观的评价指标来直接衡量文档集合质量。
4. **消融实验覆盖范围有限**：消融实验仅在 WebWalkerQA、HealthBench 和 HotpotQA 三个数据集上进行，未覆盖所有 9 个基准，泛化性的内部验证不够完整。
5. **RAG 场景未使用文档级准则**：从案例研究可以看出 RAG 场景的文档级准则为空列表，这说明文级别准则（权威性、时效性）的实际贡献在 RAG 场景中尚未得到充分验证。
6. **潜在偏差风险**：教师模型、准则生成器、奖励评估器均为 GPT-5.1，存在“同一模型自证”的偏差风险；深度研究智能体 Dr-Tulu-8B 既用于生成训练查询又用于评估，可能存在一定程度的循环依赖。
