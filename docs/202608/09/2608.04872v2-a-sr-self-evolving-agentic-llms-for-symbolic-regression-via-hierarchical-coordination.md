## 摘要
符号回归旨在从数据中发现闭合形式的方程，但现有的大语言模型（LLM）引导方法通常依赖于统一的提议循环，将异构的搜索失败压缩为标量分数和单一提示。我们提出了A-SR，一个自进化的智能体框架，它将控制单元从表达式编辑转移到角色条件下的证据视图。A-SR通过协调协议之间的路由、在线评估器-奖励角色策略以及状态路由的过程记忆来协调公式发现。在搜索过程中，评估器反馈表征可靠性和生产力，更新角色级效用，并将精英主题、失败痕迹和有效性诊断路由到不同的智能体。该框架在两个时间尺度上自进化：在单次运行内，它调整搜索过程而不更新LLM参数；在多次运行间，记录的轨迹可以被蒸馏到开源LLM中，作为角色条件下的提议先验。在LLM-SRBench的四个LSR-Synth科学领域上平均，A-SR在Acc@0.01上相对于基线从25.79%提高到48.30%（使用Llama3.1-8B），而A-SR-LoRA将相应的Qwen3-4B结果从24.58%提高到38.29%。在四个真实世界的科学发现任务中，A-SR在8个报告的指标中的7个上获得了最佳的分布内或分布外归一化均方误差。

## Abstract
Symbolic regression aims to discover closed-form equations from data, but existing LLM-guided methods often rely on a unified proposal loop that compresses heterogeneous search failures into a scalar score and a single prompt. We propose A-SR, a self-evolving agentic framework that shifts the control unit from expression edits to role-conditioned evidence views. A-SR coordinates formula discovery through routing among coordination protocols, an online evaluator-reward role policy, and state-routed process memory. During search, evaluator feedback characterizes reliability and productivity, updates role-level utilities, and routes elite motifs, failure traces, and validity diagnostics to different agents. The framework self-evolves at two timescales: within a run, it adapts the search process without updating LLM parameters; across runs, recorded trajectories can be distilled into open-source LLMs as role-conditioned proposal priors. Averaged over the four LSR-Synth scientific domains in LLM-SRBench, A-SR improves Acc@0.01 over baselines from 25.79% to 48.30% with Llama3.1-8B, while A-SR-LoRA improves the corresponding Qwen3-4B result from 24.58% to 38.29%. On four real-world scientific discovery tasks, A-SR obtains the best in-distribution or out-of-distribution normalized mean squared error on 7 of 8 reported metrics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 符号回归（Symbolic Regression, SR）的目标是从观测数据中发现符合科学规律的闭式数学表达式，它是科学发现、方程挖掘和可解释机器学习中的核心任务。
- 近年来，大语言模型（LLM）被引入符号回归，其思路是把方程表示为可执行程序，由 LLM 提出骨架、外部评估器拟合连续参数。然而，这类系统大多采用**统一提议-评估循环**：LLM 提出候选公式，评估器返回标量分数，随后提示模型继续改进。
- 论文指出这一范式的根本缺陷：**搜索中的失败模式异构且多源**，包括语法无效、参数拟合失败、表达式冗余、数值不稳定、外推风险等。统一标量分数和单一提示无法区分这些失败类型，导致下一个提案所接收的"证据"常常与当前主导失败模式不匹配。例如在表达式冗余占主导时仍在探索新结构，或在搜索停滞时仍继续做局部修复。
- A-SR 的核心主张是：**LLM 引导的符号回归应将控制单元从"对表达式施加何种编辑"转变为"哪个角色接收哪些证据"**。通过把评估器产生的结构化反馈转化为对协议、角色和记忆路由的协调决策，能够显著提升搜索可靠性与结果质量。

## 2. 论文提出的方法论

### 2.1 核心思想

- A-SR 构建了一个**层级协调框架**：底层是共享的 LLM 骨干网络，上层是协调器（Coordinator），负责协议选择、角色选择与记忆路由。
- 系统定义了四个角色——**Generator（生成器）**、**Analyst（分析师）**、**Simplifier（简化器）**、**Reviewer（审查器）**。它们共享同一个 LLM 骨干，但接收不同的角色指令、记忆片段和上下文证据，从而对搜索状态做出差异化反应。

### 2.2 关键技术细节

- **问题定义**：每个任务表示为 P = (Q, X, D_train, D_val, D_ood)，其中 Q 是任务描述，X 是允许变量集。候选方程是可执行程序。第 t 步协调器构造角色条件提示 C_t = Compose(P, r_t, M_t, e_{<t}, B_t)，评估器返回结构化反馈 e_t = (s_t, v_t, b_t, h_t, c_t)，其中 s_t 为分数、v_t 为有效性、b_t 是否改进当前最优、h_t 为失败/参数错误信息、c_t 为复杂度诊断。

- **早期画像（Early Profiling）**：在前 B₀=80 次评估中，角色按中性固定调度执行，收集可靠性画像 ρ_rel = (r_invalid, r_param, Δ_invalid, Δ_param) 和生产力画像 ρ_prod = (n_best, n_late, S_best, τ_stag)。

- **协议选择（Protocol Selection）**：根据画像选择四种协调协议之一：
  - π_EGC（探索引导协调）：鼓励 Generator/Analyst 探索；
  - π_RGC（可靠性引导协调）：在无效、参数失败或过度复杂时强调 Reviewer/Simplifier；
  - π_PGC（阶段引导协调）：从探索过渡到正则化；
  - π_SGC（稳定性引导协调）：停滞时增加探索、提议不可靠时趋于保守。

- **在线角色策略自适应**：定义评估器派生奖励 R_t = λ_v·I_valid + λ_b·I_best − λ_i·I_invalid − λ_p·I_param，通过指数平滑更新角色效用 U_t(r)，并在协议条件分数 S_t(r) = S_π⋆(r) + α_π⋆·g_π⋆,t(r)·U_t(r) 下选择角色。

- **状态路由记忆（State-Routed Memory）**：维护精英记忆 M_elite、失败记忆 M_fail 和主题记忆 M_motif。根据推断的搜索状态 z_t ∈ {invalid, productive, stagnant, complex, mixed} 将不同记忆块路由到不同角色：无效主导时给 Reviewer 失败痕迹和有效性诊断；停滞但有效时给 Generator/Analyst 精英和主题记忆；复杂但有效时给 Simplifier 压缩线索。

- **轨迹蒸馏（A-SR-LoRA）**：将完整搜索轨迹（任务、角色、状态、上下文、公式、反馈）蒸馏为角色条件监督数据，训练 Qwen3-4B 的 LoRA 模块（四个角色对应四个适配器），推理时复用 A-SR 的协调回路。

### 2.3 算法流程（A-SR 搜索过程）

1. 初始化过程记忆、角色效用和最优分数；
2. 在预算 B=400 次评估内迭代：
   - 前 B₀ 步使用中性角色调度；
   - 在 B₀+1 步构建画像并选择协议；
   - 按协议条件分数选择活动角色；
   - 推断搜索状态并路由记忆上下文；
   - LLM 生成候选公式，评估器执行并返回结构化反馈；
   - 更新过程记忆和（在线模式下）角色效用；
3. 返回最佳有效方程。

## 6. 论文的主要结论与发现

- **主要结论**：将 LLM 引导符号回归的控制单元从"统一提议循环"转向"角色-记忆视图对"的层级协调，可以显著提升科学公式发现的可靠性和成功率。
- **量化结果**：
  - 在 LLM-SRBench 四个 LSR-Synth 科学域上，A-SR 将平均 Acc@0.01 从 DE 的 25.79% 提升到 48.30%（Llama3.1-8B）；
  - A-SR-LoRA 将 Qwen3-4B 的 Acc@0.01 从 24.58% 提升到 38.29%；
  - 在四个真实世界任务上，A-SR 在 8 个报告的 ID/OOD NMSE 指标中取得 7 个最佳。
- **行为发现**：
  - A-SR-Static 在 LSR-Transform 的 NMSE 上最强，而在线 A-SR 在科学域 Acc@0.01 上最优，说明静态协调利于广谱表达式搜索，在线角色策略自适应利于搜索状态变化时的可靠性；
  - 搜索过程诊断表明，完整系统在保持高有效率的同时没有坍缩到单一角色——各角色的改进贡献是分布式而非集中式的；
  - 消融显示固定角色轮换远不如完整系统，说明仅暴露多个角色提示是不够的，角色、协议与路由记忆三者的交互才是关键。

## 7. 优点

- **视角创新**：将 LLM 引导 SR 重新定义为"角色-记忆视图"的协调问题，而不是"编辑操作"的选择问题，提供了一个新的控制层级抽象，对后续智能体搜索方法具有启发性。
- **自进化双时间尺度设计**：单次运行内的调节不更新 LLM 参数，跨运行的轨迹蒸馏可以将搜索经验固化到开源模型先验中，兼顾了部署灵活性和持续改进能力。
- **结构化反馈的利用充分**：有效性、改进、失败类型、复杂度等信号被显式编码为奖励和记忆路由依据，避免了标量分数丢失过程信息的缺陷。
- **透明性与可解释性**：协议选择、角色效用、过程记忆均为显式规则驱动，便于分析搜索过程中的决策依据，也便于与不同的 LLM 骨干组合。
- **实验设计严谨**：同时报告 NMSE 和 Acc@0.01、ID 和 OOD、聚合指标和过程诊断，考虑了 LLM 记忆污染问题并使用转换方程和合成基准降低背诵风险。
- **开源兼容性**：方法不依赖特定的 LLM 推理能力，可与开源模型（Llama、Qwen）配合使用，蒸馏路径进一步降低了对封闭模型 API 的依赖。

## 8. 不足与局限

- **未见量的算力报告**：论文没有给出 GPU 型号、数量、训练时长等硬件资源的量化信息，读者难以评估方法在实际部署中的计算成本。
- **显式规则而非学习控制器**：协议选择器依赖手工设计的画像映射规则，面对与训练分布差异很大的科学领域可能需要重新校准，不具备端到端学习的自适应性。
- **实验覆盖的不均衡**：消融实验只在混合子集和 Biology 子集上进行，未系统覆盖全部四个科学域；真实世界任务缺少与 DE 的对比（因 DE 未开源且未提供完整结果表），也缺少 GPT-3.5 以外的骨干模型验证。
- **统计稳健性受限**：未报告多次运行的标准差或置信区间，单次轨迹的可变性可能影响结论的可靠性。
- **外推可靠性的残余风险**：虽然通过代理信号（数值稳定性、复杂度等）控制 OOD 风险，但 OOD 表现仍然依赖具体发现的函数家族，个别任务的失效模式无法完全避免（如 Stress-Strain OOD 略逊于 LLM-SR）。
- **LoRA 蒸馏依赖教师模型**：A-SR-LoRA 的语料由 GPT-5.5 构造，这在不同模型间引入了一定的性能耦合；若教师模型质量下降或领域偏斜，蒸馏先验也会受到影响。
