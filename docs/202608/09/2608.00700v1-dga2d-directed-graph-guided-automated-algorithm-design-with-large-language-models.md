## 摘要
大语言模型（LLMs）的快速发展为求解NP难组合优化问题（COPs）的自动启发式设计（AHD）开辟了新途径。然而，现有的LLM驱动的AHD方法在很大程度上局限于固定的求解器模板，将搜索过程降级为孤立的模块调优。转向完全自主的系统级算法设计至关重要，但存在生成算子可靠性低、搜索空间极大以及信用分配无效等问题。为克服这些缺陷，本文提出了一种称为DGA$_2$D的有向图引导的自动化算法设计框架。它将开放式程序空间构建为有向图，其中每个节点代表一个功能算子，可通过多个候选代码实现之一进行实例化，而有向行走则构成完整的算法流程。引入了一种一阶路径相关的信用分配机制，以严格根据拓扑上下文评估代码变体。在从复杂调度到路由的12个不同COP上的大量实验表明，DGA$_2$D具有一致的实证优势。与最先进的LLM基线相比，它将平均归一化差距减少了高达10.96个百分点。

## Abstract
The rapid development of Large Language Models (LLMs) has opened new avenues for Automated Heuristic Design (AHD) for solving NP-hard combinatorial optimization problems (COPs). However, existing LLM-driven AHD methods are largely confined to rigid solver templates, relegating the search process to isolated module tuning. Transitioning to fully autonomous, system-level algorithm design is essential but fraught with low reliability of generated operators, extremely large search spaces, and ineffective credit assignment. To overcome these drawbacks, this paper proposes a Directed Graph-Guided Automated Algorithm Design framework, termed DGA$_2$D. It structures the open-ended program space as a directed graph, where each node represents a functional operator that can be instantiated using one of multiple candidate code implementations, while directed walks constitute complete algorithmic pipelines. A first-order path-dependent credit assignment mechanism is introduced to evaluate code variations strictly based on their topological context. Extensive experiments across 12 distinct COPs, ranging from complex scheduling to routing, demonstrate the consistent empirical advantages of DGA$_2$D. It reduces the average normalized gap by up to 10.96 percentage points compared to state-of-the-art LLM baselines.

### 一、核心问题与整体含义（研究动机和背景）

**研究背景：**
- 大量实际组合优化问题（COPs）属于NP难问题，在多项式时间内无法精确求解。实际应用中需要设计启发式算法在有限时间内求得高质量可行解。
- 无免费午餐定理表明：不存在通用最优的优化算法，激励研究者设计利用问题特定结构的算法。
- 然而，设计高效且可扩展的问题特定算法是困难且劳动密集型的。传统自动启发式设计（AHD）虽减少人工，但仍依赖人类专家设计的代码模块，人力和可扩展性受限。

**现有LLM驱动AHD的瓶颈：**
- 现有方法（如FunSearch、EoH）主要在预定义的刚性求解器模板内运行，把搜索过程降级为孤立模块调优，属于“半自主生成”范式，仍需要适度的人力投入，可扩展性与性能受限。
- 论文指出，自然的演进方向是让LLM同时担任“框架架构师”和“算子设计者”，实现完全自主的系统级算法设计。

**转向完全自主、系统级算法设计面临三大核心挑战：**
1. **低可靠性**：完整算法由长序列、相互依赖的算子组成，容易出现编译错误、接口不匹配和逻辑失败。
2. **搜索空间极大**：在开放式的程序空间中，有效且高性能的算法非常稀疏，高效探索困难。
3. **信用分配无效**：性能仅在评估完整算法后才能观测，难以判断局部修改对改进的贡献。

### 二、论文提出的方法论

**核心思想：**
提出DGA$_2$D框架，将有向图（Directed Graph）作为算法搜索空间的表示。节点代表功能算子，节点间的有向边连接形成算子流程，有向行走（Directed Walk）构成完整算法流水线。通过LLM驱动演进，同时优化算子实现和拓扑连接。

**整体框架四部分流程：**

1. **LLM驱动的初始化（LLM-based Initialization）**
   - 以目标问题的自然语言描述为输入，LLM构建初始超参数空间 H={K,τ,…} 和基础算子池 O={O₁,…,O_m}。
   - 算子池中的算子来自现有算法和领域文献的固定库，每个算子关联多个候选代码实现（图 2a）。

2. **图引导的算法构建（Graph-Guided Algorithm Construction）**
   - 在每代 t，搜索空间建模为有向图 Dₜ=(Oₜ,Eₜ)，边 (Oᵢ,Oⱼ) 表示 Oⱼ 在 Oᵢ 之后执行。
   - 算法结构通过“有界有向行走”采样：P_{t,j} = ⟨O_in, O_{t,j,1}, …, O_{t,j,L}, O_out⟩，其中 O_in、O_out 为哨兵节点。允许重复算子，以支持迭代算法结构，长度上限为 L_max。
   - 每条流水线由N个候选覆盖，每个算子从实现池 C^{(t)}_i 中按实现采样概率 pₜ 选择具体代码片段，形成候选算法序列（图 2b）。

3. **问题评估与信用分配（Problem Evaluation and Credit Assignment）**
   - **算法级评估**：在k个基准实例上评估，定义方向感知归一化差距 g_{t,j,b}，再据其得到适应度分数 S_{t,j}，并标准化为终端奖励 eR_{t,j}。
   - **流水线级信用**：标准化奖励用于更新流水线采样策略 π_pipe，通过策略梯度损失 L_pipe(θ) 提升正信用流水线的采样概率。
   - **代码实现级信用**：定义一阶实现转移 e=(c_{i-1},c_i)，用 Qₜ(e) 估计该转移的期望标准化终端奖励，用学习率 α 更新 Q_{t+1}(e)=(1-α)Qₜ(e)+α·eR_{t,j}。实现采样策略 π_code 基于对前驱条件的一阶Softmax分布（图 2c）。

4. **信用引导的双层级进化（Credit-Guided Dual-Level Evolution）**
   - **实现级进化**：聚合转移信用为算子内实现信用及算子信用，选择最低信用算子 O⋆。若其信用≥0且实现池>1，删除最低信用实现；若<0则新增或替换实现。
   - **拓扑级进化**：聚合边信用（算子对间），若最小边信用<0则替换该边为新边（需验证接口兼容和保留输入输出通路），否则保留（图 2d）。

**DGA₂D与其他方法的区别：** 除算子层演进（如FunSearch、EoH）外，还允许LLM重新设计算法框架（拓扑结构），扩展了设计空间，实现“自主生成”范式。

### 七、局限性与未来工作

尽管 DGA₂D 在实验上展现了显著优势，论文也坦诚指出了若干局限：

1. **计算开销仍然较高**：虽然相比 MCTS-AHD 有约 27% 的墙钟时间节省，但整体上 10 小时/域的总时间仍高于 EoH 等轻量级方法，在大规模实时部署场景下可能受限。
2. **对初始算子池质量的依赖**：LLM 生成的初始算法骨架和算子池若质量较低，后续进化可能需要更多轮次才能收敛，提示初始化的稳健性仍有提升空间。
3. **信用分配的简化假设**：当前一阶路径依赖假设忽略了更长跨度的算子交互，对具有复杂反馈依赖的算法（如涉及全局状态改变的搜索策略）可能不够精确；全路径方案又面临噪声问题，尚缺乏自适应平衡机制。
4. **拓扑编辑的约束**：接口兼容检查确保了可执行性，但在某些情况下可能限制了对算法结构的大胆重构，从而缩小了搜索空间的有效探索范围。

**未来工作方向**包括：设计更细粒度的信用传播机制以捕捉长程依赖；引入自适应的拓扑编辑强度；探索跨问题域的迁移学习和元学习初始化；以及将 DGA₂D 扩展到更多类型的优化问题（如多目标优化、带约束的非线性规划等）和更广泛的 LLM 骨干。

### 八、总结

DGA₂D 首次实现了由 LLM 全自主驱动的“系统级”启发式算法设计。通过将算法搜索空间显式建模为有向图，并用双层信用引导机制同时进化代码实现与拓扑结构，它有效克服了低可靠性、搜索空间庞大和信用分配失效三大挑战。在 12 个 NP 难组合优化问题上的系统评估表明，DGA₂D 在多种 LLM 骨干、多种评估预算和多种结构变体下均稳定地超越了现有 LLM 驱动 AHD 方法以及多种传统经典求解器，同时在不同类型的连续数值任务上也展现了良好的泛化能力。这一工作为自动化算法发现提供了一个可扩展、可靠且通用性强的全新范式，对启发式设计和计算智能领域具有重要的推动作用。
