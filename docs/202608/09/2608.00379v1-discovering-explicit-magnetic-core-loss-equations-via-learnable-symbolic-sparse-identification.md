## 摘要
具有简单表达式和物理可解释性的显式磁芯损耗方程是高频功率磁性元件设计中的重要工具。传统的对经验数据的拟合方法，如斯坦梅茨方程（SE），通常在精度上存在不足，而现代机器学习方法提高了精度，但偏离了物理原理。为填补这一空白，本文提出了一种可学习符号稀疏辨识（LSSI）框架，用于数据驱动的方程发现。具体而言，LSSI将正弦驱动下的磁芯损耗方程重新表述为一个直接由实验数据推导的符号回归问题。在SE的基础上，引入了一个扩展的候选函数库，并实现了一个稀疏辨识框架来选择主导函数。更重要的是，候选函数的指数和系数等关键参数被视为可学习参数，同时实现了方程的简洁性和底层分数幂定律的高表达能力。实验结果表明，LSSI通过一个仅包含4个有效项的紧凑显式方程，实现了卓越的精度，其R²达到最先进的0.9999，MAPE为1.04%。此外，它将神经网络方法中的参数数量从4417个大幅减少到15个，展示了卓越的紧凑性和效率。因此，LSSI框架提供了一种物理透明且高精度的解决方案，适用于复杂的现代磁特性表征与设计。

## Abstract
Explicit magnetic core loss equations with simple expressions and physical interpretability are significant tools in the design of high-frequency power magnetics. Traditional fits to empirical data like the Steinmetz Equation (SE) often struggle with accuracy, whereas modern machine learning approaches improve precision but deviate from physics. To fill this gap, this paper proposes a Learnable Symbolic Sparse Identification (LSSI) framework for data-driven equation discovery. Specifically, LSSI reformulates magnetic core loss equations for sinusoidal drives as a symbolic regression problem derived directly from experimental data. Building upon the SE, an expanded library of candidate functions are introduced and a sparse identification framework is implemented to select the dominant ones. More importantly, crucial parameters like exponents and coefficients of candidate functions are treated as learnable ones, simultaneously achieving equation simplicity and high expressiveness of the underlying fractional power laws. Experimental results demonstrate that LSSI achieves superior accuracy with a state-of-the-art $\mathbf{R^2}$ of $\mathbf{0.9999}$ and a MAPE of $\mathbf{1.04\%}$ through a highly compact explicit equation containing only $\mathbf{4}$ active terms. Furthermore, it drastically reduces the parameter count from $\mathbf{4417}$ in neural network methods to $\mathbf{15}$, showcasing exceptional compactness and efficiency. The LSSI framework thus provides a physically transparent and highly accurate solution suitable for complex modern magnetic characterization and design.

- **现有方法不足**：
  - 传统经验公式（如 Steinmetz 方程 SE 及其变体）结构固定、简单，但预测误差大。
  - 机器学习方法（随机森林 RF、前馈神经网络 FNN、物理信息神经网络 PINN 等）精度高，但属于黑箱模型，完全缺乏物理规律认知，无法提供解析表达式，损失了设计上的速度和直觉。
- **核心问题**：如何在保持高精度的同时，获得简洁、显式、物理可解释的磁芯损耗方程。
- **论文含义**：提出 **Learnable Symbolic Sparse Identification（LSSI）** 框架，将磁芯损耗建模重构为可学习的符号回归问题，融合机器学习精度与物理规律的透明性，以极紧凑的显式方程达到最先进的精度，为高频磁性设计提供工具。

## 2. 方法论

- **核心思想**：
  - 将磁芯损耗 \(P_v\) 表示为候选函数库的稀疏线性组合：
    \[
    P_v(f,B) = \Theta(f,B;\Lambda)\cdot \Xi
    \]
    其中 \(\Theta\) 为 \(M=10\) 个由电磁物理启发的候选函数，\(\Xi\) 为稀疏系数向量，\(\Lambda\) 为内部可学习的非线性参数（如指数）。
  - 通过联合优化稀疏系数 \(\Xi\) 和可学习参数 \(\Lambda\)，同时实现稀疏性和对分数幂律的表达能力。
- **候选函数库**（10 项，基于物理机制）：
  - 磁滞损耗项：\(\theta_1 = f^{\alpha_h} B^{\beta_h'}\)，其中 \(\beta_h' = \beta_h + \gamma_h \ln(B+\epsilon_h)\)，用于模拟接近饱和时的非线性结构变化。
  - 涡流损耗项：\(\theta_2 = f^{\alpha_e} B^{\beta_e}\)，理论值为 \(\alpha_e\approx2,\beta_e\approx2\)。
  - 异常损耗项：\(\theta_3 = f^{\alpha_a} B^{\beta_a}\)，典型分数指数约 1.5。
  - 磁饱和项：\(\theta_4 = f^{\alpha_s} B^{\beta_s}\)（自由幂律）、\(\theta_5 = f e^{\delta B}\)（指数饱和）。
  - 辅助项：\(\theta_6=fB\)、\(\theta_7=fB^2\)、\(\theta_8=f\)、\(\theta_9=B\)、\(\theta_{10}=1\)。
- **关键创新—可学习参数**：
  - 传统固定整数指数字典只能通过多个格点整数项的叠加逼近分数指数，导致支持集膨胀、稀疏性丧失、可解释性缺失且存在不可消除残差。
  - LSSI 将指数释放为连续可学习参数，初始化为物理先验种子，通过梯度优化在连续空间中迁移到真实分数指数（如 \(\alpha=1.20,\beta=2.68\)），每个机制由一个活跃项单独捕获。
  - 稀疏性与表达能力解耦：表达能力由连续参数提供，而非靠活跃项个数。
- **损失函数**：混合 Log-MAPE 损失，确保在多数量级跨度下均匀的百分比精度：
  \[
  L = w_{\log} \frac{1}{N}\sum_i \left(\ln(\hat P_{v,i}+\epsilon_p)-\ln(P_{v,i}+\epsilon_p)\right)^2 + w_{\text{mape}} \frac{1}{N}\sum_i \frac{|\hat P_{v,i}-P_{v,i}|}{P_{v,i}+\epsilon_p}
  \]
- **优化与稀疏化**：
  - 使用 AdamW 优化器，联合更新 \(\Xi\) 和 \(\Lambda\)。
  - 对 \(\Xi\) 应用解耦权重衰减（L2 惩罚）促进稀疏；\(\Lambda\) 不惩罚。
  - 约束 \(\Xi\succeq 0\)（保证物理耗散），\(\Lambda\) 被投影到物理可行域 \(\Omega_\Lambda\)。
  - 通过阈值剪枝（Heaviside 掩码）自动剔除无信息项，最终保留少量活跃项。
- **训练细节**：数据归一化至 [0,1]；可学习参数通过 logistic sigmoid 映射到物理边界内。
