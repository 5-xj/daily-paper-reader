## 摘要
非对称多路径TSP是非对称旅行商问题的推广：我们要寻找$k$条游走路径，每条具有指定的起点$s_i$和指定的终点$t_i$，使得每个顶点至少被其中一条游走路径访问。目标是最小化所有游走路径的总长度。一般而言，在多项式时间内找到该问题的任何近似都是NP难的（即使允许近似因子依赖于顶点数）。我们证明可以在$n^{O(k)}$时间内获得$O(k)$-近似，回答了Friggstad [2013]提出的一个开放问题。对于所有游走起点$s_i$相同且所有终点$t_i$相同的特殊情形，我们在多项式时间内获得$O(k)$-近似，以及一个$(O(\frac{1}ε), 1+ε)$-双标准近似。对于多仓库情形，即对所有$i$有$s_i=t_i$，我们在多项式时间内获得常数因子近似。最后，我们的结果蕴含了针对非对称后悔有界车辆路径问题和单位权重路径ATSP的改进常数因子近似算法。

## Abstract
Asymmetric Multi-Path TSP is the generalization of the Asymmetric Traveling Salesperson Problem where we are looking for $k$ walks, each with prescribed start $s_i$ and prescribed end $t_i$, such that every vertex is visited by at least one of the walks. The objective is to minimize the total length of all walks. In general, it is NP-hard to find any approximation for this problem in polynomial time (even if the approximation factor is allowed to depend on the number of vertices). We show that one can obtain an $O(k)$-approximation in time $n^{O(k)}$, answering an open question by Friggstad [2013].   For the special case where all tour start vertices $s_i$ are identical and all end vertices $t_i$ are identical, we obtain an $O(k)$-approximation in polynomial time, as well as an $(O(\frac{1}ε), 1+ε)$-bicriteria approximation. For the multi-depot setting, where $s_i =t_i$ for all $i$, we obtain a constant-factor approximation in polynomial time.   Finally, our results imply improved constant-factor approximation algorithms for Asymmetric Regret-Bounded Vehicle Routing and unit-weight Path ATSP.

- **问题地位**：它是 ATSP 与 Path ATSP 的自然推广。一般情形下，**即便允许近似因子依赖于顶点数 $n$，在多项式时间内获得任何近似也是 NP 难的**（连可行性判定都是 NP 难，Friggstad 2013）。
- **已有结果**：
  - 对称情形：目前最好为 $1+2\sqrt{e}\approx 2.2131$（BFMS25）；单位权重对称情形有 1.9304 近似（DLPV26）。

## 2. 方法论：核心思想与关键技术

### 2.1 常数个终端对的一般情形（定理 1.2：$n^{O(k)}$ 时间 $O(k)$-近似）

- **第一步（初始路径覆盖）**：用 SSSS 的双标准近似（定理 1.4）构造 $\ell\le 2k$ 条顶点不相交路径 $Q_1,\dots,Q_\ell$，覆盖 $V\setminus(S\cup T)$，总代价 $\le 51\cdot \mathrm{OPT}$（引理 2.1）。
- **第二步（保序解概念）**：定义 **precedence-preserving 解**——存在 $V\setminus(S\cup T)$ 上的线性序，与所有 $Q_j$ 及解路径 $P_i$ 的顶点顺序一致（定义 2.2）。这推广了 Feige–Singh 的 ATSP→Path ATSP 归约思路。
- **第三步（动态规划）**：状态为「每条 $Q_j$ 的已取前缀 + 每条 $P_i$ 的当前末端」，在 $n^{O(k+\ell)}=n^{O(k)}$ 时间内求最便宜的保序解（引理 2.3，附录 A）。
- **第四步（关键分析）**：证明存在代价 $\le O(k)\cdot\mathrm{OPT}$ 的保序解（引理 2.4）。构造辅助多重图 $H$（$P_i^*$ 与 $Q_j$ 的边并集），对每个强连通分量 $C$ 把各 $Q_j$ 在 $C$ 内的区间任意拼接成 $R_C$，按拓扑序分派给某条 $P_i^*$，利用三角不等式得 $c(R_C)\le \ell\cdot c(E(C))$，最终总代价 $\le (52\ell+105)\cdot\mathrm{OPT}=O(k)\cdot\mathrm{OPT}$。

### 2.2 单源单汇情形（定理 1.4 第一部分：$(O(1/\epsilon),1+\epsilon)$ 双标准近似）

- **LP 松弛**：$(SSSS\text{-}P)$ 为带流守恒（源出 $k$、汇入 $k$）与割约束 $x(\delta(U))\ge 2$ 的线性规划，对偶为 $(SSSS\text{-}D)$。
- **核心创新一：保度近似**。推广 ATSP 常数因子算法，使对给定最优 LP 解 $x$，输出解在每个仓库点 $t$ 的度数满足 $\lfloor x(\delta^-(t))\rfloor\le |\delta^-_F(t)|\le \lceil x(\delta^-(t))\rceil$（定义 3.1，定理 3.2，附录 B）。一般权重 $\alpha_{\mathrm{MD}}=12+2\sqrt{2}+\epsilon\approx 14.83$，单位权重 $\alpha_{\mathrm{MD}}=5+2\sqrt{2}+\epsilon\approx 7.83$。
- **核心创新二：避免合并路径的归约**。添加辅助顶点 $v^*$ 与边 $(t,v^*),(v^*,s)$（各赋值 $k$），把 SSSS 实例嵌入单仓库 Multi-Depot 实例；用对偶势 $a$ 重赋权使边权非负（引理 3.3），保度性质保证 $v^*$ 的出入度恰为 $k$，从而直接分解为 $k$ 条 $s$–$t$ 游走，**无需合并路径**，避免了传统方法中 $O(k^2)$ 的损失。
- **核心创新三：对偶 $y$ 变量控制**。引理 3.4 证明存在最优对偶解使 $\sum 2y_U\le (k+1)\cdot\mathrm{LP}$（紧，见图 2）；引理 3.5 进一步对 $k'=\lfloor(1+\epsilon)k\rfloor$ 的对偶解证明 $\sum 2y'_U\le \frac{(1+\epsilon)k}{\epsilon k-1}\cdot\mathrm{LP}$，从而在 $\epsilon\le \tau/k$ 与 $\epsilon>\tau/k$（$\tau=1+\sqrt{2}$）两种情形下分别放缩，得到 $O(1/\epsilon)$ 近似因子（定理 3.6，具体为 $51/\epsilon$）。
- **单位权重情形（定理 1.4 第二部分）**：构造 $L=\lceil 4\alpha_{\mathrm{MD}}/\epsilon\rceil$ 份 $G$ 的拷贝，首尾通过 $t_i=s_{i+1}$ 连接并加 $v^*$，应用定理 3.2 后取最便宜的一份拷贝，得到 $(5+2\sqrt{2}+\epsilon)$-近似（附录 C.2）。

### 2.3 多仓库情形（定理 1.6：$12+2\sqrt{2}+\epsilon$ 与 $5+2\sqrt{2}+\epsilon$）

- 在附录 B 中改造 ATSP 近似框架（[TV25; Vyg26]）：引入强层状实例（定义 B.1）、脊椎对（vertebrate pair，定义 B.3）、子回路覆盖（subtour cover，引理 B.6）。
- 关键点：子回路覆盖的**保度舍入**保持终端度数；最终迭代只添加 $E[V\setminus V(B)]$ 内的边，不影响终端度数；通过人工环 $C_T$ 连接所有仓库点作为骨干（backbone），把多仓库归约到简单脊椎对。
- 一般权重由定理 3.2（$\alpha_{\mathrm{MD}}=12+2\sqrt{2}+\epsilon$）直接推出，与 ATSP 已知最好界匹配。

### 2.4 应用：后悔有界 VRP（定理 1.8：23-近似）

- 利用 Friggstad–Swamy 黑盒归约（定理 C.2）：$(α,β)$ 双标准 ⇒ $(α+β)$ 近似。
- 简单 ATSP 归约基线为 $(4α+\epsilon)$（用 [HY26] 得 <50）；本文通过选取 $k'=(1+\delta)k$（$\delta=4$）并精细放缩，得到 23-近似（附录 C.4）。

## 6. 主要结论与发现

- **回答 Friggstad 公开问题**：存在 $O(k)$-近似、运行时间 $n^{O(k)}$ 的算法（定理 1.2），且 $f,g$ 均为线性。
- **SSSS 情形**：多项式时间 $(O(1/\epsilon),1+\epsilon)$ 双标准近似（定理 3.6，具体 $51/\epsilon$），消除了 Friggstad 结果中的 $\log n$ 因子；单位权重下得到 $(5+2\sqrt{2}+\epsilon)$-近似。
- **多仓库情形**：一般权重 $(12+2\sqrt{2}+\epsilon)$、单位权重 $(5+2\sqrt{2}+\epsilon)$ 的常数因子近似（定理 1.6），把 Friggstad 的 $O(\log n)$ 改进为常数。
- **推论**：
  - 单位权重 Path ATSP 改进到 $5+2\sqrt{2}+\epsilon$，并给出标准 LP 的整性间隙上界 $5+2\sqrt{2}$；

## 8. 局限与可改进之处

- **一般情形的复杂度仍随 $k$ 指数增长**：$n^{O(k)}$ 时间在 $k$ 较大时不可扩展，距离真正多项式时间或 FPT 算法仍有明显差距；近似因子 $O(k)$ 也随终端对数线性增长。
