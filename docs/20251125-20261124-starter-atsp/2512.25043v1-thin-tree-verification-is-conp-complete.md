## 摘要
图 $G$ 的一棵 $α$-薄树 $T$ 是一棵生成树，使得 $G$ 的每个割中至多有比例为 $α$ 的边位于 $T$ 中。薄树猜想提出，存在函数 $f$，使得对任意 $α>0$，每个 $f(α)$-边连通图都有一棵 $α$-薄树。除了其独立意义外，一个能够对给定的 $k$-边连通图高效构造 $O(1)/k$-薄树的算法，将直接导出非对称旅行商问题（ATSP）（arXiv:0909.2849）的 $O(1)$-近似算法。然而，甚至此前不知道是否可能高效验证给定树是 $α$-薄的。我们证明判定一棵树的薄性是 coNP-难的。

## Abstract
An $α$-thin tree $T$ of a graph $G$ is a spanning tree such that every cut of $G$ has at most an $α$ proportion of its edges in $T$. The Thin Tree Conjecture proposes that there exists a function $f$ such that for any $α> 0$, every $f(α)$-edge-connected graph has an $α$-thin tree. Aside from its independent interest, an algorithm which could efficiently construct an $O(1)/k$-thin tree for a given $k$-edge-connected graph would directly lead to an $O(1)$-approximation algorithm for the asymmetric travelling salesman problem (ATSP)(arXiv:0909.2849). However, it was not even known whether it is possible to efficiently verify that a given tree is $α$-thin. We prove that determining the thinness of a tree is coNP-hard.

## 1. 核心问题与研究动机

- **研究对象**：图 $G$ 的 $\alpha$-薄树（$\alpha$-thin tree）是一棵生成树 $T$，使得 $G$ 的任意割 $C=(A,B)$ 中，属于 $T$ 的边占该割边数的比例不超过 $\alpha$，即 $|\delta_T(A)|/|\delta_G(A)|\le \alpha$。
- **薄树猜想（Goddyn, 2004）**：存在函数 $f$，使得对任意 $\alpha>0$，每个 $f(\alpha)$-边连通图都存在一棵 $\alpha$-薄生成树。
- **算法动机**：若能对给定的 $k$-边连通图高效构造 $O(1)/k$-薄树，将直接导出非对称旅行商问题（ATSP）的 $O(1)$-近似算法；对"瓶颈"版 ATSP（最小化最大边权）则可改进当时已知最好算法。
- **空白点**：此前甚至不知道"验证一棵给定生成树是否为 $\alpha$-薄"能否在多项式时间内完成。文献中该问题曾被描述为"未知是否有多项式可检验证书"，或被无证明地称为 NP-难。
- **本文目标**：确定薄树验证问题（ThinTreeValid）的计算复杂度，证明其为 **coNP-完全**。

## 2. 方法论

### 2.1 核心思想

论文采用**多步归约链**，从经典 NP-难问题 MaxCut 出发，逐级归约到 ThinTreeValid 的补问题：

$$\text{MaxCut} \le_P^T \text{MaxAvgCutOpt} \le_P^T \text{MaxAvgCut} \le_P^m \text{ThinTreeValid}^C$$

由此得到 ThinTreeValid$^C$ 是 NP-难，故其补 ThinTreeValid 是 coNP-难；再结合其属于 coNP，得到 coNP-完全。

### 2.2 关键技术细节

- **coNP 成员性**：给定 $(G,T,\alpha)$，若存在割的 $T$-厚度（$|\delta_T(A)|/|\delta_G(A)|$）严格大于 $\alpha$，该割即为"NO"实例的多项式可检验证书。
- **第一步（定理 2）**：用 MaxAvgCutOpt 的谕示求解 MaxCut。算法迭代：按当前割 $C$ 赋权（$e\in C$ 为 $-1$，否则为 $+1$），调用 MaxAvgCutOpt 得到割 $C'$，令 $C\leftarrow C\oplus C'$；当割的平均权非正时停止。由于割空间对对称差封闭，且每次迭代 $|C|$ 严格增大，迭代次数至多 $|V(G)|^2$，从而只需多项式次谕示调用。
- **第二步（定理 3）**：用 MaxAvgCut 判定谕示求解 MaxAvgCutOpt。先穷举所有可能的平均权（形如 $p/q$，$|p|\le q\le n$，共 $O(n^2)$ 个）确定最优值 $k$；再反复尝试收缩顶点对 $(v,u)$，若收缩后仍存在平均权为 $k$ 的割则保留收缩，直至只剩两个顶点。每次收缩不降低最优平均割值，故算法正确且多项式时间终止。
- **第三步（定理 4，Karp 归约）**：构造"膨胀图" $G'$——对原图每个顶点 $v$ 造一个含 $24m$ 个顶点的团 $c_v$（$m=|E(G)|$），对每条原边 $e=(v,w)$ 在其两个团之间加 3 条互不共享端点的边 $d_e$。构造树 $T$：每个团内加一条路径；对每条边 $e$ 从 $d_e$ 中选 $w_e+2$ 条边（$w_e\in\{-1,1\}$，即选 1 或 3 条）；再反复删去环上的团内边直至得到生成树。
- **阈值设定**：取 $\alpha=(k+2)/3-\epsilon$。由割的对应关系可推出
  $$\frac{\sum_{e\in\delta(A)}w_e}{|\delta(A)|}=\frac{|\delta_T(A')|}{|\delta_{G'}(A')|/3}-2,$$
  即原图割平均权 $\ge k$ 当且仅当对应新割的 $T$-厚度 $\ge (k+2)/3$；取足够小的 $\epsilon$ 以避开 $T$-厚度落在 $((k+2)/3-\epsilon,(k+2)/3]$ 区间内的情形。
- **两条引理**：
  - 引理 1：平均权 $\ge k$ 的原图割与 $T$-厚度 $>\alpha$ 的"尊重团内边"的新图割一一对应。
  - 引理 2：任何分裂某个团的割，其 $T$-厚度严格小于 $1/3$（通过计数论证：单团贡献上界约 $1/8+1/(6m)$），因 $\alpha\ge 1/3-\epsilon$，此类割不可能是"厚"割。
- 结合两引理即得双向等价，归约正确。
