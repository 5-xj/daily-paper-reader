## 摘要
在多语言检索增强生成中，检索器可以检索出多种语言的相关文档，这些文档随后在答案生成前被重排序。然而，现有多语言重排序器在排序语义相关的候选项时是否考虑文档语言仍不清楚。我们的分析表明，当跨语言存在语义等价的文档时，这些重排序器并不一致地优先考虑与查询语言相同的文档，尽管文档语言会影响答案生成。我们发布了LAMAR，一个语言感知的多语言交叉编码器，旨在同时考虑语义相关性和语言一致性。LAMAR首先使用基于英语的锚定相关性蒸馏，以建立跨多语言输入的一致相关性评分，然后应用语言一致性的偏好对齐，鼓励与查询语言相同的文档获得更高排名，同时保留语义相关性。在评估语言一致性的受控实验中，LAMAR在整体和所有单独考察的语言上取得了最佳性能。LAMAR在现有的多语言重排序基准上也保持竞争力。在实际检索环境中，当对第一阶段检索到的候选项进行重排序时，LAMAR在所有报告的指标上均取得了最佳结果。这些结果表明，LAMAR在考虑语言一致性的同时，在通用多语言重排序基准上取得了强劲性能。

## Abstract
In multilingual retrieval augmented generation, a retriever can retrieve relevant documents written in multiple languages, which are subsequently reranked before answer generation. However, it remains unclear whether existing multilingual rerankers consider document language when ordering semantically relevant candidates. Our analysis shows that these rerankers do not consistently prioritize documents written in the same language as the query when semantically equivalent documents are available across languages, even though document language can affect answer generation. We release LAMAR, a language aware multilingual cross encoder trained to account for both semantic relevance and language coherence. LAMAR first uses English anchored relevance distillation to establish consistent relevance scoring across multilingual inputs and then applies preference alignment for language coherence to encourage documents written in the same language as the query to receive higher rankings while retaining semantic relevance. In a controlled experiment designed to assess language coherence, LAMAR achieves the best performance overall and across all languages examined individually. LAMAR also remains competitive on established multilingual reranking benchmarks. In practical retrieval settings, LAMAR achieves the best results across all reported metrics when reranking candidates retrieved in the first stage. These results demonstrate that LAMAR accounts for language coherence while achieving strong performance on general multilingual reranking benchmarks.

# 论文总结：LAMAR: 一个开放的语言感知多语言对齐重排序器

## 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：在多语言检索增强生成中，检索器可能返回多种语言的相关文档，但现有多语言重排序器主要关注语义相关性，忽略了文档语言对答案生成质量的影响。实验证明，与查询同语言的文档往往带来更高的生成F1分数（如XQuAD上Qwen2.5-32B和Llama-3.3-70B的对比），而现有重排序器（如jina-reranker-v3、Qwen3-Reranker-4B等）并不一致地将同语言文档排在首位，尤其对英语查询表现更差。
- **核心问题**：如何在保持强语义重排序能力的同时，使重排序器感知查询语言，优先排列语义等价但语言与查询一致的文档（即语言连贯性）。
- **整体含义**：语言连贯性应作为多语言重排序的一项独立能力得到建模，LAMAR首次提出了同时优化语义相关性和语言一致性的两阶段训练方案，并提供了公开模型。

## 2. 方法论
- **核心思想**：采用交叉编码器架构，分两阶段训练：
  - **第一阶段：英语锚定相关性蒸馏**  
    利用教师模型（Qwen3-Reranker-4B）对英语查询-文档对打分，学生模型对对应的多语言对打分，通过MSE损失使学生评分逼近教师的英语评分，实现跨语言一致的相关性标尺。  
    \[
    \mathcal{L}_{\text{distill}} = \left( S_\theta(q^{\ell_q}, d^{\ell_d}) - T(q^{\text{en}}, d^{\text{en}}) \right)^2
    \]
    训练数据来自MMARCO、MIRACL和RLHN，构造了6.7M个实例。
  - **第二阶段：语言一致性偏好对齐**  
    对每个源语言查询，构造包含同语言正例、目标语言正例、同语言负例、目标语言负例的四元组。损失函数由两部分组成：
    - **组排序损失**（ADR-MSE）：将正例标签设为1、负例为0，采用近似折扣排序MSE损失，保证正例排名高于负例，但不强制同语言对之间的顺序。
    - **语言一致性损失**：  
      \[
      \mathcal{L}_{\text{LC}} = \frac12 \left[ \text{softplus}(s_t^+ - s_s^+) + \text{softplus}(s_t^- - s_s^-) \right]
      \]
      鼓励同语言文档的得分高于异语言文档（无论正负例组）。
    最终对齐损失为 \(\mathcal{L}_{\text{align}} = \mathcal{L}_{\text{rank}} + \lambda \mathcal{L}_{\text{LC}}\)，\(\lambda=2\)。训练数据8.6K个实例，来源MIRACL三元组。

- **关键技术细节**：初始化自bge-m3-retromae，最大序列长度8192，各训练1个epoch。

## 3. 实验设计
- **数据集/场景**：
  - **语言连贯性评估**：XQuAD（12种语言）和BELEBELE（14种语言）的并行oracle子集，所有候选文档语义等价，仅同语言文档被认定为相关，指标为nDCG@1、nDCG@10、MRR@10。
  - **标准多语言重排序评估**：MIRACL（18种语言，多单语设置）、XGLUE（7种语言）、HUME（3种语言）、MLDR（13种语言）、Wikipedia（16种语言），来自MMTEB基准，指标nDCG@10。
  - **实际检索场景**：在XQuAD上，使用两个检索器（multilingual-MiniLM-L12-v2和bge-m3）返回top-20候选项，由LAMAR重排序，评估nDCG@1/10和MRR@10。
  - **消融实验**：对比Stage 1 alone、LAMAR、移除rank损失、移除LC损失四个变体，在XQuAD、BELEBELE、MIRACL、MLDR上测nDCG@10。

- LAMAR在语言连贯性评估中，在所有语言（12/14种）上均取得最高nDCG@1（XQuAD 96.89%，BELEBELE 94.66%），远超第二名（llama-nemotron约94-95%），尤其改善了英语查询的排名。

## 8. 不足与局限
