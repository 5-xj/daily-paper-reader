## 摘要
超大规模集成电路（VLSI）全局布线是一个NP难组合优化问题，需要在容量受限的三维网格上分配信号线网，同时最小化拥塞、线长和通孔过渡。由于传统启发式方法依赖静态惩罚调度，无法处理复杂拥塞拓扑，我们提出AlphaRoute：一种多目标自适应搜索框架，将拆线重布（R&R）重塑为动态优化系统。我们引入基于SHAP的溢出分解以隔离每个线网的拥塞，通过3D Dijkstra迷宫路由和自适应PathFinder策略驱动目标子图提取。关键地，AlphaRoute利用大语言模型（LLMs）作为语义策略优化器。在确定性知识图谱的约束下，LLMs解释拥塞指标以动态调整惩罚参数。在ISPD 2025基准测试中，AlphaRoute在MEMPOOL上将溢出减少98.6%。在受限的ARIANE设计上，我们实现了146,109的溢出（比现有最佳技术降低29.8倍），产生惩罚分数S_orig = 0.0538，而现有技术（SOTA）为1.780。这些结果表明，优越的算法搜索几何可以克服解释型Python实现的延迟。

## Abstract
Very Large Scale Integration (VLSI) global routing is an NP-hard combinatorial optimization problem requiring signal net assignment across capacity-constrained 3D grids while minimizing congestion, wirelength, and via transitions. Because traditional heuristics rely on static penalty schedules that fail on complex congestion topologies, we present AlphaRoute: a multi-objective adaptive search framework reformulating rip-up and reroute (R&R) into a dynamic optimization system. We introduce SHAP-based overflow decomposition to isolate per-net congestion, driving targeted subgraph extraction via 3D Dijkstra maze routing and an adaptive PathFinder policy. Crucially, AlphaRoute employs Large Language Models (LLMs) as semantic policy optimizers. Bounded by a deterministic knowledge graph, the LLMs interpret congestion metrics to dynamically adjust penalty parameters. Evaluated on ISPD 2025 benchmarks, AlphaRoute reduces overflow by 98.6% on MEMPOOL. On the constrained ARIANE design, we achieve an overflow of 146,109 (a 29.8x reduction in overflow over the state of the art), yielding a penalized score of S_orig = 0.0538 versus the State-of-the-art (SOTA) 1.780. These results demonstrate that superior algorithmic search geometry can overcome the latency of interpreted Python implementations.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究背景**：VLSI（超大规模集成电路）全局布线是物理设计的关键阶段，需要在容量受限的3D网格中为信号线网分配路径，同时最小化拥塞、线长和通孔数。这是一个NP难组合优化问题。
- **核心问题**：传统启发式方法（如PathFinder）依赖静态惩罚调度，无法适应复杂拥塞拓扑；拆线重布（R&R）候选选择缺乏对每个线网溢出贡献的细粒度分析；缺乏可解释的决策层。现代SoC包含数十万至数百万线网、十层以上金属层、超百万GCells，非局部拥塞交互使问题加剧。
- **意义**：提出AlphaRoute，将拆线重布重构为动态优化系统，结合SHAP分解、3D Dijkstra迷宫路由、自适应PathFinder策略，并创新性地将LLM作为语义政策优化器，在可解释性和安全性约束下动态调整参数，实现多目标优化。

## 2. 方法论（核心思想、关键技术细节、算法流程）

- **关键技术细节**：
  - **图构建**：基于GCell构建RustworkX图，边权重`W(e) = (10.0 - 3.0·σ_n) + (11 - c_{z,u}) + (11 - c_{z,v})`，其中σ_n为基于松弛的临界因子，c为剩余容量。
  - **线网排序**：先按包围盒面积（大线网优先），面积相同时按最负松弛（关键线网优先）。
  - **初始路由**：小面积(An≤2500)用Steiner树；大面积(An>2500)用Prim MST+Flex-L（评估水平优先和垂直优先两种L形，选拥塞小的），并动态选择层（水平/垂直段取剩余容量最大的层），减少初始溢出2.2倍。
  - **SHAP溢出分析器**：计算每个线网的溢出分数ψ_n（仅考虑其占用的GCell），层溢出占比λ_z，拥塞单元分数f_c，以及利用-溢出相关性r_uo。这些指标用于驱动自适应规则和LLM输入。
  - **自适应PathFinder策略**：历史惩罚`h^{(k+1)}(e) = h^{(k)}(e) + α^{(k)}·max(0, -c_e)`；重路由成本`cost(e) = W(e) + h^{(k)}(e) + p_f^{(k)}·max(0, -c_e)`；α每次迭代自动增长1.15倍；基于SHAP信号的三条规则（见表I）可覆盖默认参数。
  - **LLM政策提议**：向本地或API上的LLM（Llama 3.2/3.3/GPT-OSS）发送结构化指标（当前溢出、变化、拥塞分数、相关性、主导层百分比、当前α/pf/via成本），LLM返回JSON包含α/pf/via的动作和值及推理。提议经知识图谱验证后才应用，否则用SHAP规则。
  - **知识图谱**：记录模式（线网特征）、策略（算法与参数）、结果（溢出变化），确保决策可追溯并约束LLM输出。
  - **拆线与重路由**：选择溢出分数前20%的线网释放容量。根据线网面积选择重路由方法：中等面积(2500<An≤15000)用3D Dijkstra在局部子图搜索；小面积仍用Steiner；大面积用MST+Flex-L。

## 6. 主要结论与发现
- AlphaRoute在ARIANE上实现S_orig=0.0538（SOTA为1.780），降低了33.1倍；S_scaled=0.0589（SOTA 1.74），降低了29.5倍。MEMPOOL溢出减少98.6%。
- 大部分溢出降低来自：Flex-L路由（A2）、SHAP驱动的拆线重布（A3）、Dijkstra迷宫重路由（A4）。GNN和LLM层主要提供可解释性，对最终溢出几乎无进一步改善（甚至轻微上升）。

- LLM建议的参数调整在已接近最优的设计上可能会过度惩罚，导致轻微溢出增加，但总体不劣。
- 不同LLM家族（70B vs 120B）表现相似，策略层模型无关。

## 7. 优点（方法或实验设计亮点）
1. **创新性的SHAP溢出分解**：首次在全局路由中将SHAP思想用于逐线网溢出贡献分析，实现精准拆线候选选择（Top 20%溢出线网），替代传统粗粒度启发式。
2. **LLM作为语义优化器**：不直接作为评估器（避免偏见），而是接收结构化指标提出参数调整建议，配合知识图谱验证，融合了可解释性与安全性。
3. **自适应PathFinder策略**：结合SHAP驱动的三条硬规则和LLM动态调整，自动增长历史惩罚权重，灵活适应拥塞演变。
4. **灵活的初始路由**：根据线网面积选择不同路由方法（Steiner/MST+Flex-L），并动态选择金属层以减少初始溢出（2.2倍改进）。
5. **消融实验设计清晰**：逐步累积组件，有效隔离每种技术的贡献；覆盖4个规模和结构不同的基准，验证泛化能力。
6. **实现完全开源**：代码和评估脚本在GitHub公开，有利于复现和后续研究。
