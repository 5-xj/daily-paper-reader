## 摘要
多任务神经求解器旨在统一的模型中处理多种车辆路径问题（VRP）变体，避免为每种约束组合进行单独训练。然而，VRP变体在优化难度上存在差异，而现有方法缺乏对其训练状态的分阶段反馈，导致模型偏向某些特定变体。虽然元学习可以支持自适应训练，但通常需要双层优化和额外的梯度更新，增加了计算成本。为了解决这一局限，我们提出LaT（LLM-as-Trainer），一种即插即用的训练范式，使用预训练的大语言模型作为外部训练器。LaT定期分析跨任务验证指标以生成阶段性的指导向量。该向量与当前任务的约束向量结合，并注入每个编码器层，从而在后续策略优化中为神经求解器提供额外的训练信息。在16个VRP变体上的实验表明，LaT在已训练和未见过的变体上提高了多个最先进的多任务神经求解器的解质量，支持了所提训练范式的有效性和通用性。

## Abstract
Multi-task neural solvers aim to handle multiple Vehicle Routing Problem (VRP) variants within a unified model, avoiding separate training for each constraint combination. However, VRP variants differ in optimization difficulty, while existing methods lack stage-wise feedback on their training status, making the model biased to some specific variants. Although meta-learning can support adaptive training, it typically requires bi-level optimization and additional gradient updates, increasing computational cost. To address this limitation, we propose LLM-as-Trainer (LaT), a plug-and-play training paradigm that uses a pretrained large language model as an external trainer. LaT periodically analyzes cross-task validation metrics to generate a stage-wise guidance vector. This vector is combined with the current task's constraint vector and injected into each encoder layer, providing the neural solver with additional training information during subsequent policy optimization. Experiments on 16 VRP variants show that LaT improves the solution quality of several state-of-the-art multi-task neural solvers on both trained and unseen variants, supporting the effectiveness and generality of the proposed training paradigm.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：多任务车辆路径求解器（Multi-Task VRP Solvers）需要在统一模型中处理多种 VRP 变体（如带容量、时间窗、回程、开放式、路径长度限制等），避免为每种约束组合单独训练模型。但不同变体的优化难度差异很大（例如带时间窗和回程的变体比仅带容量的变体更难），现有训练方法缺乏分阶段的训练状态反馈，仅通过损失或梯度协调多任务，导致模型偏向某些简单变体，整体解质量受限。元学习虽可自适应训练，但需双层优化和额外梯度更新，计算成本高。
- **整体含义**：本文旨在引入一种轻量级、即插即用的训练范式，利用预训练大语言模型（LLM）作为外部“教练”，通过分析跨任务验证指标生成阶段性引导向量，动态调整后续训练，从而提升多任务 VRP 求解器的整体性能，同时保持较低的计算开销。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：LaT（LLM-as-Trainer）将一个冻结的预训练 LLM（文中使用 GLM-5.1）作为外部训练器，在训练过程中每隔固定周期（Tctrl=500 轮）对 16 个 VRP 变体进行交叉验证，获取每个变体相对于离线参考解（由 HGS 或 OR-Tools 生成）的相对参考间隙及其变化趋势，构建结构化的训练状态。LLM 根据该状态生成一个五维引导向量（对应五个基本约束：容量 C、开放式 O、回程 B、路径长度 L、时间窗 TW）。该引导向量与当前任务的约束向量拼接后，通过轻量级旁路分支注入每个编码器层（乘以可学习系数 α），从而影响后续编码器输出，最终通过解码器影响策略优化。
- **关键技术细节**：
  - **引导生成**：每 500 轮进行一次交叉验证，计算每个变体的相对参考间隙 η_{r,k} 和变化 Δη_{r,k}，保留最近 J=5 次记录，形成训练状态 I_r，通过固定提示模板查询 LLM 得到引导向量 γ_r ∈ R^5。
  - **编码器侧分支**：在每个编码器层 ℓ，将当前任务的约束向量 z_k 与当前引导向量 γ_r 拼接得 u_{r,k}=[z_k,γ_r]∈R^{10}，然后通过一个轻量级 MLP（ψ^ℓ）生成侧分支输出，与 backbone 输出 h_i^ℓ 相加：ẽ_i^ℓ = h_i^ℓ + α · ψ^ℓ(h_i^ℓ, u_{r,k})。α 是可学习系数，所有层共享。
  - **训练流程**：LLM 不参与梯度计算，仅在预定义间隔调用；其余时间正常使用 POMO 风格策略梯度更新 solver 参数和 α。训练完成后，固定最终引导向量，移除 LLM，保留侧分支用于推理，无额外 API 开销。

## 3. 实验设计：数据集、基准、对比方法

- **数据集与场景**：基于五个基本约束（C/O/B/L/TW）构建 16 种 VRP 变体。训练集针对 50 节点和 100 节点问题，各用 2000 万实例（5000 轮，每轮 128 批，每批 20000 实例）。验证集和测试集各 1000 个实例。参考解由 HGS（CVRP 和 VRPTW）或 OR-Tools（其余 14 种变体，200 秒/实例）生成。
- **基准方法**：
  - 传统求解器：HGS、LKH3、OR-Tools（含 ×10 时间版本）。
  - 单任务神经求解器：POMO。
  - 多任务神经求解器：POMO-MTL、MVMoE、MVMoE-L、RF-POMO、CaDA、ReLD、SPSM、CCL、MoSES-CaDA、PoMtVRS-CaDA 等。

- LaT 能显著提升多种多任务神经求解器（ReLD、CaDA、POMO-MTL、MVMoE、MVMoE-L）在已训练变体和未见变体上的解质量，平均间隙降低 0.1%~0.4% 左右。

## 7. 优点

- **创新性**：首次提出将 LLM 作为训练器（plug-and-play）用于多任务 VRP 求解器，不同于以往将 LLM 用于表示学习或启发式搜索。
- **轻量高效**：LLM 仅在少数控制轮次调用，无需梯度更新，训练开销极小；推理时无 LLM 依赖。
- **通用性**：可集成到多种不同架构的多任务求解器中（POMO-MTL、MVMoE、ReLD、CaDA 等），且均获得提升。
- **可解释性**：通过分析引导向量与验证间隙的相关性，验证了 LLM 生成策略的合理性。
- **实验充分**：涵盖 16 种变体、两种规模、多种消融和基准泛化，对比了多个 SOTA 方法。

## 8. 不足与局限

- **骨干依赖性**：LaT-ReLD 在未见变体上的改善不如 LaT-CaDA 一致，提示引导机制的效果可能因骨干而异，尚需更统一的设计。
