## 摘要
现有的工具使用基准测试报告了复杂多步骤任务的单一成功率。受认知科学思想的启发，我们将工具使用与工具发现区分开来，并将后者分解为好奇心（模型发现构建工具所需部件的能力）、识别（模型发现创建工具过程的能力）和效率（模型在创建后使用工具的能力）。我们展示了这一框架可应用于现有的发现任务，如Voyager。此外，我们提供了证据表明识别能力与模型规模呈反比关系，并引入并分析了一类展示此现象的博弈游戏。我们还在一个模拟真实世界任务的独立环境中进一步观察到了这种反比缩放关系。

## Abstract
Existing tool-use benchmarks report a single success rate for complex, multistep tasks. Inspired by ideas from cognitive science, we distinguish tool use from tool discovery and decompose the latter into curiosity (the model's ability to discover the parts needed to build the tool), recognition (the model's ability to discover the process of creating the tool), and efficiency (the model's use of the tool after creation). We show that this framework can be applied to existing discovery tasks, such as Voyager. In addition, we provide evidence that recognition inversely scales with model size, and we introduce and analyze a class of combinatorial games that demonstrates this. We further observe inverse scaling in a separate environment designed to emulate real-world tasks.

## 2. 方法论：核心思想、关键技术细节与公式
- **核心思想**：将工具发现分解为三个可观察事件：持有部件（hold）、构建工具（build）、用工具解决问题（win）。定义：
  - 好奇心 C = Pr(hold) —— 收集所需部件的概率
  - 识别 R = Pr(build | hold) —— 持有部件后决定构建的概率
  - 效率 E = Pr(win | build) —— 构建后成功解决问题的概率

- **技术细节**：
  - **Lomekwi环境**：组合式保险库游戏。agent面对n扇锁门，通过`examine`、`combine`、`use`、`pickup`动作收集碎片，组合特定碎片得到“机器”可一键开所有门。行动预算设为蛮力路径期望的1.2倍，使蛮力可行但有风险。每个潜在角色（门、钥匙、碎片、机器）每局随机单字母重标签，抑制预训练先验。

- **无传统算法流程**，而是定义观测/动作/奖励的交互式环境，通过LLM生成动作日志来统计C、R、E。

## 6. 主要结论与发现
- **识别逆缩放**：在Lomekwi中，构建率随模型增大而下降，分解后发现并非好奇心和效率下降，而是**识别（R）** 明显逆缩放。在Recognition MCP中同样观察到此现象，且更干净：Qwen3.5的识别概率从2B的0.29单调降至27B的0.02。
- **U型缩放**：当引入工具先验提示后，最大模型的识别恢复，形成U型曲线（如Qwen3.5 27B从0.02升至0.60）。解释：最小模型因能力不足而不得不探测工具；中等模型过度自信选择手动计算但常失败；最大模型能力强且会作为对冲探测工具。
- **整体成功可掩盖识别缺陷**：在Recognition MCP中，Qwen3.5整体成功率从2B的0.46升至27B的0.88，即便识别率趋近于零，说明单一成功指标无法反映工具发现能力。
- **认知科学类比**：LLM中工具发现能力与模型规模的解耦类似于人类儿童或脑损伤患者的分离现象。
