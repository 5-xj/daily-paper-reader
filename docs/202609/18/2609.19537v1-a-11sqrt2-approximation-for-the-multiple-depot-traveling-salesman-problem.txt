Abstract 

The metric traveling salesman problem (TSP) is a fundamental problem in combinatorial optimization that asks for a minimum-cost tour covering all clients in a metric graph. The metric multiple-depot TSP (MD-TSP) is a natural extension, where the graph contains depots and clients, and the objective is to compute a minimum-cost set of tours covering all clients, with each tour starting and ending at the same depot. When the number of depots is part of the input, an adaptation of the Christofides–Serdyukov heuristic yields an approximation ratio of 2. In this paper, we introduce a (1 + 1 /√2)-approximation algorithm. Like the Christofides–Serdyukov heuristic, our algorithm first computes a rooted spanning forest (RSF), then a matching to correct its odd degrees, and finally obtains a solution by shortcutting. However, instead of using a minimum-cost RSF, we construct an RSF by a primal-dual algorithm for a natural cut relaxation. The algorithm grows rootless components and the component containing all depots at different rates, adding an edge when its dual constraint becomes tight. Vertex labels record the times at which clients first become connected to a depot. The two-speed growth provides a joint bound on the forest cost and two label-dependent terms that also arise in bounding the parity-correction cost. Balancing the coefficients of these two terms by setting both to √2 − 1yields the claimed approximation ratio. 

# 1 Introduction 

The metric traveling salesman problem (TSP) is one of the most fundamental problems in combina-torial optimization (Gutin and Punnen, 2006). It asks for a minimum-cost tour visiting all vertices of a graph. The problem has been extensively studied since the classical work of Dantzig et al. (1954) and arises in applications ranging from transportation planning to the ordering of drilling operations on circuit boards (Applegate et al., 2006). In these applications, vertices represent locations or tasks, and edge costs represent the travel needed between them. The metric multiple-depot TSP (MD-TSP) extends this problem to multiple depots. An in-stance is a complete graph G = ( V, E, c ), where V = J ∪ D and J ∩ D = ∅. Here, J = {v1, . . . , v n}

c(x, z ) ≤ c(x, y ) + c(y, z ) for all x, y, z ∈ V . The goal is to find a minimum-cost set of tours covering all clients, with each tour starting and ending at the same depot. Depots may remain unused. The multiple-depot setting captures situations in which vehicles or service teams start from different locations and must collectively serve a set of clients. For example, in inspection planning, depots can represent vehicle bases and clients can represent inspection sites. Related multiple-depot ve-hicle routing models arise in task allocation for unmanned aerial vehicles (Rathinam et al., 2007; Montoya-Torres et al., 2015). The metric TSP is APX-hard even when all edge costs between distinct vertices are either one or two (Papadimitriou and Yannakakis, 1993). Since the metric MD-TSP contains the metric TSP as the case k = 1, it is also APX-hard. This motivates approximation algorithms that run in polynomial time and provide provable bounds on solution cost. Such algorithms have been extensively studied for metric TSPs (Traub and Vygen, 2024; Saller et al., 2025). Unless otherwise specified, in the following, we consider problems in the metric setting. For the TSP, the double-tree heuristic (Rosenkrantz et al., 1977) yields an approximation ratio of 2. Christofides (1976) and Serdyukov (1978) proposed the classical 3 /2-approximation algorithm, which first computes a minimum-cost spanning tree (MST), then a minimum-cost perfect matching on its odd-degree vertices, and finally obtains a solution by shortcutting. More recently, Karlin et al. (2021, 2023) improved the approximation ratio to 3 /2 − ε for some constant ε > 10 −36 .For the MD-TSP, adapting the double-tree heuristic yields a 2-approximation algorithm (Rathi-nam et al., 2007). By extending the Christofides–Serdyukov heuristic, Xu et al. (2011) improved this ratio to 2 − 1/k for k ≥ 2, with running time O(|V |3). Their algorithm replaces the MST with a minimum-cost rooted spanning forest (RSF), a spanning forest with one depot in each tree, and then applies parity correction and shortcutting. They also showed that the ratio 2 − 1/k is tight for this algorithm. Moreover, for a generalization in which only s of the k available depots may be selected to serve clients, Xu and Rodrigues (2017) proposed a (2 − 1/(2 s))-approximation algorithm. Although the best-known approximation ratio remains 2 in the general setting, better guarantees can be achieved by allowing the running time to depend on the number of depots k. Using edge exchanges, Xu and Rodrigues (2015) proposed a 3 /2-approximation algorithm with running time 

O(|V |k+2 |E|k−1). This running time is polynomial for any fixed k, so the algorithm belongs to slice-wise polynomial-time (XP) when parameterized by the number of depots (Cygan et al., 2015). Later, Traub et al. (2022) proposed the Φ-TSP framework for a class of TSP variants. For the MD-TSP, it yields an ( α+ε)-approximation algorithm with running time |V |Oε(k) for any constant ε > 0, where α < 3/2 is the best-known ratio for the TSP. Subsequently, Deppert et al. (2023) proposed a randomized fixed-parameter tractable (FPT) (3 /2 + ε)-approximation algorithm with running time (1 /ε )O(k log k)|V |O(1) . Their algorithm reduces the MD-TSP to the rural postman problem (RPP) and applies parameterized algorithms for the RPP (Gutin et al., 2017). Recently, Zhao et al. (2026) 2obtained an FPT ( α + ε)-approximation algorithm with running time 2 O(k/ε )|V |O(1) . These results provide stronger ratios when the number of depots is small. However, it remained open whether a polynomial-time algorithm could achieve a ratio better than 2 when k is part of the input. 

1.1 Our Results 

We propose an O(|V |3)-time (1 + 1 /√2)-approximation algorithm for the MD-TSP, breaking the 2-approximation barrier. Like the Christofides–Serdyukov-style (2 − 1/k )-approximation algorithm of Xu et al. (2011), our algorithm first constructs an RSF F, then corrects its odd degrees by a minimum-cost perfect matching M , and finally obtains a solution to the MD-TSP by shortcutting E(F) ⊎ M . (iii) Running time. The construction performs |V | − k merges. A simple implementation scans all edges after each merge, which takes O(|V |3) time. Candidate keys never decrease, and the key of an edge can increase at most once, when one endpoint first joins R0. Hence, keys can be updated lazily upon extraction: discard an edge whose endpoints are already in the same component, reinsert it if its key has increased, and otherwise select it. Since stored keys are lower bounds on their current values, the selected edge always has minimum current key. Thus, each edge incurs only O(1) heap operations and component queries, for a total of O(( |E| + |V |) log |V |) = O(|V |2 log |V |) time.

# 5 Conclusion 

In this paper, we proposed an O(|V |3)-time (1 + 1 /√2)-approximation algorithm for the MD-TSP, improving the previous approximation ratio of 2 when the number of depots is part of the input. Our algorithm uses a two-speed primal-dual approach to construct an RSF, together with vertex labels that connect the forest construction to the parity-correction analysis. By combining the bounds on the forest and matching costs and balancing the two growth rates, we obtain the claimed approximation ratio. It would be interesting to investigate whether the primal-dual approach developed in this paper can be extended to other multiple-depot routing problems.
