## 摘要
大语言模型（LLMs）通过推理和代码合成实现了自动化算法设计（AAD）。然而，现有大多数基于LLM的AAD方法将算法设计与目标优化分离，即使优化状态不断演化，仍部署固定的设计。传统自适应优化器能够响应此类变化，但其调整仍局限于预定义的参数、算子或策略。为解决这些局限，我们提出在线基于LLM的AAD，这是一种新的优化范式，将算法本身视为依赖于状态的决策变量。在每个阶段，LLM智能体根据当前优化状态合成具有新行为逻辑的算法。执行生成的算法可推进搜索，并为后续设计提供反馈，从而将算法设计与目标优化耦合起来，且无需单独的离线算法预训练阶段。为实现这一范式，我们提出OnDesign，一个多智能体框架，它协调相互竞争的设计视角以合成可执行算法，并利用执行反馈来改进后续设计中对运行时证据的解释方式。我们在三种场景下，针对两种主流黑盒优化范式评估OnDesign：贝叶斯优化、进化连续优化和进化混合变量优化。在六个基准测试套件和一个工程问题、多个问题维度上的大量实验表明，其总体性能优于传统优化器和离线基于LLM的AAD方法。

## Abstract
Large language models (LLMs) enable automated algorithm design (AAD) through reasoning and code synthesis. However, most existing LLM-based AAD methods separate algorithm design from target optimization, deploying a fixed design even as the optimization state evolves. Conventional adaptive optimizers can respond to such changes, but their adjustments remain confined to predefined parameters, operators, or strategies. To address these limitations, we introduce online LLM-based AAD, a novel optimization paradigm that treats the algorithm itself as a state-dependent decision variable. At each stage, LLM agents synthesize an algorithm with new behavior logic from the current optimization state. Executing the generated algorithm advances the search and provides feedback for subsequent designs, coupling algorithm design with target optimization without requiring a separate offline algorithm pretraining stage. To implement this paradigm, we propose OnDesign, a multi-agent framework that reconciles competing design perspectives to synthesize executable algorithms and uses execution feedback to refine how runtime evidence is interpreted for subsequent designs. We evaluate OnDesign across two mainstream black-box optimization paradigms on three scenarios: Bayesian optimization, evolutionary continuous optimization, and evolutionary mixed-variable optimization. Extensive experiments on six benchmark suites and one engineering problem across multiple problem dimensions demonstrate superior overall performance over conventional optimizers and offline LLM-based AAD methods.

## 1. 核心问题与研究动机

- **背景**：LLM 通过自然语言推理与代码合成，使自动化算法设计（AAD）成为可能（如 FunSearch、EoH、ReEvo 等）。
- **核心问题一（离线范式的割裂）**：现有 LLM-based AAD 大多采用**离线设计范式**——先在训练任务上生成、评估并选出算法，再将其固定部署到目标任务。这带来两个后果：
  - 候选评估需要额外的目标评估预算，在评估昂贵时成本显著；
  - 部署的算法在目标优化过程中**保持不变**，无法响应不断演化的优化状态。
- **核心问题二（传统自适应优化的局限）**：自适应优化器（如 CMA-ES、SHADE、算法组合/切换）虽能响应状态变化，但调整空间被限制在**预先定义的参数、算子或策略**之内，难以引入新的搜索机制。
- **整体含义**：作者提出 **Online LLM-based AAD**，把"算法本身"提升为**状态依赖的决策变量**，在目标优化运行过程中反复合成具有新行为逻辑的算法，从而将算法设计与目标优化耦合为同一闭环，且不需要单独的离线预训练阶段。

## 2. 方法论

### 2.1 核心思想与形式化

- **目标优化作为序贯决策过程**：状态 $s_t$ 汇总已评估解、近期进展、剩余预算等；算法 $\pi$ 产生搜索动作 $a_t=\text{Execute}(\pi,s_t)$；评估与更新产生 $s_{t+1}$，满足马尔可夫表示 $P(s_{t+1}\mid s_t,a_t)$。
- **元层算法设计过程**：$\pi_t \sim D_{\text{LLM}}(\cdot \mid z_t,\iota)$，其中设计状态 $z_t=(s_t,h_t)$ 由当前优化状态与算法设计历史构成；执行增益 $r_t=R(s_t,\pi_t,s_{t+1})$，历史更新为 $h_{t+1}=h_t\oplus(\pi_t,r_t)$。
- **闭环**：$z_t \to \pi_t \to a_t \to (s_{t+1},r_t) \to z_{t+1}$。设计决定搜索如何推进，优化反过来提供状态与反馈。核心转变可概括为：离线范式问"优化前应设计什么算法"，在线范式问"给定迄今搜索，下一步应生成什么算法"。

### 2.2 OnDesign 框架（三个模块）

- **模块 1：State Analysis（状态分析）**
  - 由 LLM 智能体 **State Analyst**（记为 $P$）依据当前 **State Analysis Guideline（SAG，$\phi_t$）** 将异构运行时观测 $o_t$ 整理为结构化、有证据支撑的**状态报告** $q_t=P(o_t;\phi_t)$。
  - SAG 指明应强调哪些信号（如进度、多样性、代理模型可靠性、采样几何等），但不直接给出设计建议。
- **模块 2：Multi-Agent Deliberation（多智能体审议）**
  - $K$ 个角色化的 **Proposer** $L_k$ 从同一状态报告与算法历史出发，输出三元组：**设计方向** $v_t^{(k)}$（Mild/Moderate/Aggressive 的探索或利用倾向）、**理由** $e_t^{(k)}$、**设计建议** $d_t^{(k)}$；典型角色为"探索导向"与"利用导向"，鼓励相互竞争的搜索优先级。
  - **Arbiter** $G$ 评估并调和各方提案，**综合**（而非简单挑选）为可执行算法 $\pi_t=G(q_t,H_t,\{p_t^{(k)}\};\iota)$。
- **模块 3：SAG Evolution（指南演化）**
  - 执行 $\pi_t$ 后，增益 $r_t$ 归因于指导生成 $q_t$ 的 $\phi_t$；每个 SAG 的得分是其所有归因增益的**算术平均**，形成 SAG–分数档案。
  - 每 $L_{\text{SAG}}$（默认 10）个设计阶段调用 **SAG Refiner** $E$ 更新指南：$\phi_{t+1}=E(H^{\text{SAG}}_{t+1})$，否则保留 $\phi_t$。其作用不是估计因果效应，而是提供性能代理，引导后续证据解释方式。
- **执行增益定义**：$r_t=\sqrt{\max\{b_t-b_{t+1},0\}/d_t}$，$d_t=|b_t|$（$b_t=0$ 时用 $\max\{|b_{t+1}|,10^{-20}\}$），即"非负相对改进的平方根"；未改进阶段增益为 0。
- **实例化方式**：
  - 贝叶斯优化：$\pi_t$ 为**采集函数**，输入 incumbent 值、GP 后验均值与标准差，输出候选点的采集效用；
  - 进化连续/混合变量优化：$\pi_t$ 为**子代生成算子**，输入父代种群及其适应度，输出新种群。

### 2.3 理论分析

- **性能差距界（Proposition 1）**：在与理想在线设计者共享初始历史、接口与预算的条件下，
  $$0 \le V^*_0 - V^{\text{OnDesign}}_0 \le \mathbb{E}^{\text{OnDesign}}\Big[\sum_{t=0}^{T-1}(\kappa_t+2\varepsilon_t+\eta_t)\Big],$$
  其中 $\kappa_t$ 为**设计空间误差**（可访问算法族的限制）、$\varepsilon_t$ 为**表示误差**（由报告与档案评估算法价值的偏差）、$\eta_t$ 为**合成误差**（实际生成程序与最佳可访问设计的差距）。三模块分别对应 $\varepsilon_t$、$\kappa_t/\eta_t$ 与后续 $\varepsilon_t$。
- **表示歧义（Proposition 2）**：若两个不同历史共享同一设计输入，则任何仅依赖该输入的评分函数必然在其中一个历史上产生至少 $\frac{1}{2}|Q^*_t(\xi,\pi)-Q^*_t(\xi',\pi)|$ 的误差，说明状态报告需保留能改变算法选择的信息。
- **受限类比较（Corollary 1）**：对任意受限设计类 $R$（如离线 AAD 类、预定义自适应类），$\Delta_R - E^{\text{OnDesign}} \le V^{\text{OnDesign}}_0 - V^R_0 \le \Delta_R$；当累积误差小于该类与理想设计的差距时，OnDesign 严格优于该类。
