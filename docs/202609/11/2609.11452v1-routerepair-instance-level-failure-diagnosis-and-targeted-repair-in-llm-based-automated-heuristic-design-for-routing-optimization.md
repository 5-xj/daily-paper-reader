## 摘要
高效路径优化对货运运输、城市物流和共享出行至关重要，在这些场景中通常需要在有限计算预算下获得高质量启发式方法。近期基于大语言模型（LLM）的自动启发式设计方法能够生成有效的路径规则，但聚合评估可能掩盖在特定实例结构上反复出现的失败。为解决这一局限，本研究提出RouteRepair，它从实例级性能中诊断父代特定的弱点，并对相应的启发式组件进行针对性修改，同时保护已表现良好的行为。将路径证据、求解器行为和程序上下文相结合，以定义有界修复目标，并通过匹配的父代-子代评估对失败恢复和附带退化进行验证。在旅行商问题（TSP）和带容量约束的车辆路径问题（CVRP）上的实验涵盖构造式搜索、引导局部搜索和蚁群优化。RouteRepair-GLS将TSP平均最优性差距从1.7476%降至0.7587%，而构造式CVRP启发式相对于节约启发式将平均路径成本降低1.91%；生成的ACO先验也优于匹配的人工设计先验。这些结果表明，失败感知且受证据约束的改进方法能够提升困难实例上的路径启发式性能，同时保持在已能很好求解的实例上的表现。

## Abstract
Efficient routing optimization is essential to freight transportation, urban logistics, and shared mobility, where high-quality heuristics are often required under limited computational budgets. Recent large language model (LLM)-based automated heuristic design methods can generate effective routing rules, but aggregate evaluation may mask recurrent failures on particular instance structures. To address this limitation, this study develops RouteRepair, which diagnoses parent-specific weaknesses from instance-level performance and applies targeted modifications to the corresponding heuristic components while protecting behavior that already performs well. Routing evidence, solver behavior, and program context are combined to define bounded repair objectives, and each intervention is validated through matched parent-child evaluation of failure recovery and collateral degradation. Experiments on the traveling salesman problem (TSP) and capacitated vehicle routing problem (CVRP) span constructive search, guided local search, and ant colony optimization. RouteRepair-GLS reduces the mean TSP optimality gap from 1.7476% to 0.7587%, while the constructive CVRP heuristic lowers average route cost by 1.91% relative to the savings heuristic; the generated ACO priors also outperform matched hand-designed priors. These results show that failure-aware, evidence-constrained refinement can improve routing heuristics on difficult instances while preserving performance on cases they already solve well.

- **背景**：路径优化（TSP、CVRP）是货运、城市物流、共享出行与自动配送的基础问题；在有限计算预算下，构造式启发式、局部搜索与群体元启发式仍不可替代。
- **趋势**：LLM 驱动的自动启发式设计（AHD，如 FunSearch、EoH、ReEvo）将启发式设计转为对可执行程序/规则的搜索，借助代码先验生成语义上有意义的变体。
- **核心痛点**：现有 LLM-AHD 方法普遍以**均值目标、平均最优性差距或标量适应度**排序候选。这种聚合评估会**掩盖实例级异质性**——一个启发式可能整体表现优异，却在某一类结构一致的实例子集（如狭长分布、稀疏布局、长边模式、容量压力大的需求结构）上反复失败。
- **现有工作缺口**：互补启发式集合、状态依赖选择、跨尺度训练等方法通过"换规则"应对异质性，但**没有解释一个本身有竞争力的启发式在特定实例上反复失败时应当如何修订其逻辑**。
- **论文含义**：提出 RouteRepair，将 LLM-AHD 从"平均适应度驱动的替换"转向"**实例级修复**"——在不丢弃整体有竞争力父代的前提下，纠正反复出现的路径失败，同时保护已表现良好的行为。

## 2. 方法论

### 2.1 核心思想

- **嵌套搜索框架**：
  - **外层循环**：常规进化搜索，生成可执行启发式、剔除非法程序、在固定 TSP/CVRP 求解器骨架上评估，按聚合路径质量选候选，但**保留完整实例级性能画像**。
  - **内层循环**：针对"整体强、局部弱"的父代，构造失败/强度/保护集，经诊断→冻结→定向修复→匹配验证，形成可验证的修复。
- **固定骨架表示（fixed-backbone）**：LLM 只改指定的启发式接口；可行性、状态转移、邻域操作、终止条件均由外部求解器控制。这保证父子对比有意义（求解器在修复期间不变）。

### 2.2 五个路由适配器与可编辑组件

| 适配器 | 固定骨架 | LLM 生成函数 |
|---|---|---|
| TSP-GLS | 引导局部搜索 | `score_edge_for_penalty(...)` 边惩罚评分 |
| Constructive TSP | 确定性构造器 | `score_next_node(...)` 下一城市评分 |
| Constructive CVRP | 容量可行构造器 | `score_next_customer(...)` 下一客户评分 |
| TSP-ACO | 固定 ACO | `score_tsp_aco_edges(distance_matrix)` 返回 n×n 边先验矩阵 |
| CVRP-ACO | 固定可行 ACO | `score_cvrp_aco_edges(...)` 返回 n×n 边先验矩阵 |

- 构造式：候选集由骨架提供，容量不可行的客户在评分前剔除，生成函数只影响偏好不影响可行性。
- GLS：只改变候选边的相对优先级，惩罚更新、邻域搜索、终止固定。
- ACO：生成非负期望矩阵并置对角为零，与信息素按标准 ACS 权重 $\tau_{ij}^{\alpha}\eta_{h,ij}^{\beta}$ 组合；信息素蒸发、精英沉积、蚂蚁数、迭代数、随机种子、CVRP 的访问状态与剩余容量均不可改。

### 2.3 实例级损失与父子画像

- 对实例 $x_i$、启发式 $h$、固定求解器 $S_k$，得到解 $y_i(h)$ 与目标 $z_i(h)$；归一化超额成本：
  $$r_i(h)=\frac{z_i(h)-z_i^{\text{ref}}}{\max(z_i^{\text{ref}},\epsilon)}$$
  $z_i^{\text{ref}}$ 为最优值、最佳已知值或协议固定值，$\epsilon>0$ 防除零；$r_i=0$ 表示达到参考值。
- **同时保留**实例级损失向量 $\mathbf{r}(h)=(r_1,\dots,r_N)$ 与均值 $\bar r(h)$：前者用于定位父代特定失败，后者用于种群排序。

### 2.4 父代特定案例构造

- 不采用全局困难实例列表，而是对**父代自身**结果按尺度组内归一化排名：$u_p(h)=\frac{\text{rank}_g(i;h)-1}{m_g-1}$，最差实例值最大。
- **失败集** $F(h_p)$：组内排名前 $q_f$ 分位的实例；**强度集** $S(h_p)$：排名后 $q_s$ 分位；**保护集** $A(h_p)=\mathcal{D}\setminus F(h_p)$（比展示给 LLM 的强度子集更宽，用于正式附带损伤评估）。
- 可选**对比证据**：如构造式 TSP 优先纳入父代输给最近邻的实例，再用高 gap 实例补足失败槽。
- **诊断证据包**（各适配器不同，均为确定性摘要）：
  - TSP：实例结构（规模、距离分布、最近邻间距、局部/全局间距比、密度、长宽比、节点分离度）+ 求解行为（tour gap、长边比例、交叉模式、边选择偏好、停滞趋势、评分/先验分布）。
  - CVRP：实例结构 + 需求结构（需求变异、需求-容量比、空间-需求相关性）+ 求解行为（路径成本 gap、车辆利用率、路径/载重方差、碎片化、晚客户模式等）。

### 2.5 双专家诊断-修复机制

- **Failure Diagnosis Expert**：接收父代函数、失败/强度案例、证据表、当前排名、基线对比。**不生成代码**，而是把反复出现的路径结果链接到可编辑组件，给出**有界修复目标**。
- **结构化诊断报告**（诊断与修复之间的契约）：`failure_evidence`、`weak_behavior`、`root_cause`、`repair_objective`、`repair_risk`，以及 1–3 个不同 `repair_families`（各自带目标失败模式与代码改动焦点）。
- **内部风险审查**：在同一专家内部完成（非第三个代码生成专家），核对证据、识别需保护行为与过拟合风险、去重修复方向，产出简洁 brief，并**冻结**，防止修复专家在看到候选改动后重新定义弱点。
- **Targeted Repair Expert**：接收冻结 brief、单一修复族、父代代码、紧凑案例摘要、精英上下文与少量相关记忆；必须保留函数签名，只做**局部或有界结构修改**，且与诊断机制绑定。
- **诊断被定位为"可检验的程序级假设"而非因果结论**，必须区分观察与推断；最终由匹配执行而非 LLM 自我评估判定成败。

### 2.6 强度保持的匹配验证与结果感知记忆

- 失败集上平均损失下降：$G_F(h_p,h_c)=\frac{1}{|F|}\sum_{x_i\in F}[r_i(h_p)-r_i(h_c)]$，正值表示改善。
- 恢复率：$R_F(h_p,h_c)=G_F\big/\max\big(\sum_{i\in F}r_i(h_p),|F|\epsilon\big)$，用于跨父代比较。
- 附带退化（单边，不互相抵消）：$C_A(h_p,h_c)=\frac{1}{|A|}\sum_{x_i\in A}\max(0,\,r_i(h_c)-r_i(h_p))$。
- **修复成功判据**：$Valid(h_c)=1 \iff R_F\ge\tau_F \;\wedge\; C_A\le\tau_A$。
- **验证成功与进入种群被刻意分离**：子代可能因聚合权衡仍对外层搜索有用，但不满足恢复/附带条件时**不计为已验证修复**。
- **结果感知记忆**：记录每次干预的诊断、修复策略、父子结果、恢复率、附带退化与验证结论；后续提示检索的是**实测结果**（含失败案例），而非未经验证的建议。
