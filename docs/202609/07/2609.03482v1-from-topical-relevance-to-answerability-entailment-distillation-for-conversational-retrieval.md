## 摘要
现有的对话检索器通常将主题相关性视为可回答性的代理。然而，与对话上下文紧密匹配的段落并不一定是支持正确答案的段落。我们将这种不匹配识别为系统性的可回答性鸿沟。为解决此问题，我们提出CLEAR框架，将对话检索从主题相关性转向可回答性。CLEAR的核心是蕴含蒸馏，它将答案-段落蕴含监督转移至交叉编码器重排序器，使得重排序器在推理时无需答案即可区分支持答案的段落与主题干扰项。CLEAR辅以段落中心的溯因召回模块，该模块通过使用大语言模型（LLM）从段落推断可回答查询，将低相似度但可回答的段落纳入候选池。在TopiOCQA、QReCC及域外TREC CAsT数据集上，CLEAR相较于强查询重写和密集检索基线，持续提升了前序排名精度，且在包含较重主题噪声的对话中提升最为显著。此外，将我们的重排序器应用于LLM驱动的查询重写器之上可获得进一步增益。

## Abstract
Existing conversational retrievers commonly treat topical relevance as a proxy for answerability. However, a passage that closely matches the dialogue context is not necessarily the one that supports the correct answer. We identify this mismatch as a systematic answerability gap. To address this issue, we propose CLEAR, a framework that shifts conversational retrieval from topical relevance to answerability. The core of CLEAR is entailment distillation, which transfers answer-passage entailment supervision into a cross-encoder reranker so that the reranker discriminates answer-supporting passages from topical distractors at inference time, without requiring answers. CLEAR is complemented by a passage-centric abductive recall module that brings low-similarity yet answerable passages into the candidate pool by inferring answerable queries from passages with an LLM. Across TopiOCQA, QReCC, and out-of-domain TREC CAsT datasets, CLEAR consistently improves top-ranked precision over strong query-rewriting and dense-retrieval baselines, with the largest gains observed in conversations involving heavier topical noise. Moreover, applying our reranker on top of an LLM-driven query rewriter yields further gains.

## 1. 核心问题与研究动机

- **核心问题（答案性鸿沟，Answerability Gap）**：现有对话检索系统普遍将"主题相关性（topical relevance）"当作"可回答性（answerability）"的代理指标。然而，与对话上下文高度相似的段落未必包含能回答当前问题答案的证据。
- **问题严重性**：论文通过定性与定量分析表明，这种"主题—答案"的不匹配是系统性的：在图1所示的 TopiOCQA 案例中，最强 CDR 基线（QRACDR）排名第1的段落仅是主题相关干扰项，而真正支持答案的段落排在27位。统计上，"语义陷阱率"（query 的 top-1 结果比任何 ground-truth 段落在主题上更相似的比例）随检索器能力增强而上升——TopiOCQA 上从 vanilla Dense 的 18.38% 升至 QRACDR 的 27.92%，QReCC 上亦从 8.27% 升至 9.31%。这表明**检索器越强，鸿沟反而越尖锐**。
- **深层原因**：双编码器通过单一相似度分数对齐"长而嘈杂的对话上下文"与"围绕答案跨度展开的段落"，点积由整体主题一致性主导，答案支持信号仅作为隐式弱信号存在，任意主题对齐的段落都可能满足该信号。

## 2. 方法论：CLEAR 框架

CLEAR（Conversational Learning for Entailment-Aware Reranking）从候选构造与重排序两端弥合答案性鸿沟。

### 2.1 任务形式化
给定对话历史 Hₜ₋₁ 与当前查询 qₜ，构建上下文 Cₜ，学习打分函数 f(Cₜ, p)。核心目标是：将支持答案的段落排在仅主题相似的干扰项之上，而非简单优化主题相似性。

### 2.2 双通道召回（Dual-Channel Recall）
由相似性通道与溯因通道构成，经倒数排名融合（RRF）合并结果。

- **密集检索通道**：采用标准对话密集检索器 ANCE，按共享嵌入空间内的内积对段落排序。
- **溯因查询生成（Abductive Query Generation）**：微调 LLaMA 3.1 8B（LoRA 参数高效微调）执行反向推理，输入段落内容、推断其可能回答的查询。每个段落用核采样生成 m 个多样候选查询，形成查询池 Q = {(qᵢ⁽ʲ⁾, pᵢ)}。
- **对称匹配**：将非对称的 query–passage 匹配转化为对称 query–query 对齐——用 ANCE 查询编码器分别编码对话上下文与生成查询，在查询空间中做最近邻搜索，段落分数取为其最佳匹配生成查询的分值。该通道使低表面相似度但对当前对话可回答的段落得以入池。
- **分数融合**：利用 RRF 合并两候选列表，截取 top-K=100 输入重排序器。

### 2.3 蕴含感知重排序（Entailment-Aware Reranking）
- **双头架构**：基于预训练交叉编码器编码 [Cₜ; p]，在其 [CLS] 表示上设置两个轻量打分头——上下文相关性头 s_ctx 与答案性头 s_ans（输出 [0,1]，估计 p 是否支持当前问题的答案）。
- **蕴含蒸馏（核心创新）**：使用冻结的 NLI 教师（DeBERTa-v3-large）计算**答案 aₜ 与段落 p 之间**的蕴含概率 Eₚ，而非查询与段落的蕴含——因为"判断段落是否蕴含特定答案"比"对开放式对话上下文判断蕴含"更直接、更具判别力。通过 KL 散度最小化两个 Bernoulli 分布，将教师信号蒸馏进答案性头：L_ans = KL(Ber(Eₚ) ‖ Ber(s_ans))。
- **自适应校准（Adaptive Calibration）**：针对 NLI 教师在对话答案上的域偏移问题（可能对负样本给出高于正样本的蕴含分数 Eₚ₊ < max Eₚᵢ⁻），引入段落相似度感知校准：仅当发生这种反转时，按段落相似性放大正样本分数、按与正样本的不相似度抑制负样本分数（公式6-7）。该设计具备两个性质：(a) 与正样本越相似的难负例被抑制越少，实现针对性去噪；(b) 按实例因子缩放保持负样本间相对顺序，保留"暗知识"。
- **联合训练目标**：L = L_rel + γ·L_ans，其中 L_rel 为相关性头的标准二元交叉熵。推理时 f(Cₜ, p) = β·σ(s_ctx) + (1−β)·s_ans。
- **关键操作约束**：答案仅在训练时用于形成蕴含目标；推理时 CLEAR 只看对话与候选段落，不依赖答案。

## 6. 主要结论与发现

- **答案性差距随检索器增强而扩大**，纯粹的相似度优化无法消除该问题，反而使其尖锐化。
- CLEAR 在 TopiOCQA 上 MRR 46.2/NDCG@3 45.6，较最强复现 CDR 基线 QRACDR（38.7/37.9）大幅提升；在 QReCC 上 MRR 69.3/NDCG@3 68.1，显著超越所有对比方法（p<0.01）。
- **增益集中在排名头部**（MRR、NDCG@3），R@100 接近相关性训练上限——符合重排器"重排池内而非重塑池"的本质定位。
- **答案性监督确实补充了相关性标签无法提供的信息**：即使在主题相似性已与答案性高度相关的 QReCC 上仍有可观增益。
- **消融证实能力来自蒸馏而非离线 NLI 模型本身**：冻结 NLI 教师直接在无答案设置下仅 24.5 MRR（TopiOCQA），而蒸馏后的学生（读 context-passage）达到 46.2，逼近给出金答案教师的上界 49.1。
- **与查询改写正交互补**：A-CE 叠加于 ConvSearch-R1 之上仍将 MRR 从 48.9 提升至 49.3，但 CLEAR 以约 4 倍更低的延迟取得了接近的头部质量（46.2 vs 49.3）。
- **校准机制有效**：去除校准后两个基准上排名精度均下降，说明其对域外 NLI 教师的误导信号有实质修正作用。

## 7. 方法亮点与优点

1. **问题定义有洞察力**：将"主题相关≠可回答"系统化为答案性鸿沟，并用统计证据（Trap Rate 随检索器增强而上升）证明该问题的非平凡性。
2. **蒸馏方向设计合理**：选择"答案→段落"蕴含而非"查询→段落"蕴含作为监督信号，更直接、更具判别力；同时通过蒸馏实现训练后免答案推理，兼顾信号强度与部署可行性。
3. **校准机制精巧**：相似度感知的自适应校准既修正了教师的反转监督，又通过保持负例相对顺序保留暗知识，处理域偏移的手段细致。
4. **双通道召回互补**：将 Doc2Query 式段落侧思想改造为检索时代、依赖实时对话条件的溯因通道，把非对称匹配转化为对称 query–query 匹配，有效扩大候选覆盖（在 dense-miss 切片上恢复率达 56–67%）。
5. **成本设计意识强**：LLM 与 NLI 教师均在离线完成，在线仅需 ANN 查找与固定规模交叉编码器；延迟仅为稀疏强基线 DiSCo 的约 1/3、LLM 改写基线的约 1/4。
6. **实验控制严格**：受控消融（表2）、冻结教师直接对比（表3）、跨结构检索器叠加（图3）共同排除了备择解释，逻辑链条完整。

## 8. 不足与局限

1. **离线成本高**：溯因查询生成需要在语料库上做大规模 LLM 推理（每百万段落约 208–455 GPU·小时）并维护额外 ANN 索引；语料刷新即需重算。
2. **NLI 教师域失配**：教师训练于通用陈述性蕴含数据，而对话答案常呈简短、抽取式或 yes/no 片段形式；校准只能局部修正反转，无法根治分布性失配。
3. **训练时依赖金答案**：方法假设训练语料提供标准答案以形成蕴含目标——并非所有语料都满足（作者建议后续可用 LLM 从（上下文，金段落）合成伪答案，但尚未验证）。
4. **召回上限受限于密集检索**：CLEAR 的 R@100 在两个基准上均低于稀疏检索器 DiSCo（如 TopiOCQA 上 80.9 vs 84.3），溯因通道虽拓宽覆盖但无法匹敌 posting-list 扫描对稀有词查询的词汇覆盖——密集侧管线固有的结构性短板。
5. **在线重排成本仍显著**：虽然整体延迟大幅低于 LLM 改写基线，但交叉编码器仍是唯一的"大块"在线组件（约 160 ms/查询），在超大规模低延迟场景下仍有优化空间。
6. **对 m 等超参数存在敏感性**：每段落生成的溯因查询数 m 需要权衡（性能约在 m=5–9 达峰，过量查询会注入噪声、稀释精度），需按语料调优。
