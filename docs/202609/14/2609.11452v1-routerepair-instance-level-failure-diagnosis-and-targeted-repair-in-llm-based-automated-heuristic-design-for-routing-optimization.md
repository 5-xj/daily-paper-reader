## 摘要
高效路径优化对货运、城市物流和共享出行至关重要，这些场景通常需要在有限计算预算下获得高质量启发式方法。近期基于大语言模型（LLM）的自动化启发式设计方法能够生成有效的路径规则，但聚合评估可能掩盖在特定实例结构上反复出现的失败。为解决这一局限，本研究提出RouteRepair，它从实例级性能中诊断父代特定的弱点，并对相应启发式组件进行定向修改，同时保护已经表现良好的行为。该工作结合路径证据、求解器行为和程序上下文来定义有界修复目标，并通过匹配的父代-子代评估对失败恢复与附带退化进行验证。在旅行商问题（TSP）和带容量约束的车辆路径问题（CVRP）上的实验涵盖构造式搜索、引导局部搜索和蚁群优化。RouteRepair-GLS将TSP平均最优性差距从1.7476%降至0.7587%，而构造式CVRP启发式相对于节约启发式将平均路径成本降低1.91%；生成的ACO先验也优于匹配的人工设计先验。这些结果表明，失败感知且证据约束的细化能够提升困难实例上的路径启发式性能，同时保持在已能较好求解的案例上的表现。

## Abstract
Efficient routing optimization is essential to freight transportation, urban logistics, and shared mobility, where high-quality heuristics are often required under limited computational budgets. Recent large language model (LLM)-based automated heuristic design methods can generate effective routing rules, but aggregate evaluation may mask recurrent failures on particular instance structures. To address this limitation, this study develops RouteRepair, which diagnoses parent-specific weaknesses from instance-level performance and applies targeted modifications to the corresponding heuristic components while protecting behavior that already performs well. Routing evidence, solver behavior, and program context are combined to define bounded repair objectives, and each intervention is validated through matched parent-child evaluation of failure recovery and collateral degradation. Experiments on the traveling salesman problem (TSP) and capacitated vehicle routing problem (CVRP) span constructive search, guided local search, and ant colony optimization. RouteRepair-GLS reduces the mean TSP optimality gap from 1.7476% to 0.7587%, while the constructive CVRP heuristic lowers average route cost by 1.91% relative to the savings heuristic; the generated ACO priors also outperform matched hand-designed priors. These results show that failure-aware, evidence-constrained refinement can improve routing heuristics on difficult instances while preserving performance on cases they already solve well.

## 1. 核心问题与研究动机

- **背景**：路径优化（TSP、CVRP）是货运配送、城市物流、共享出行与自动配送的核心问题。精确算法随规模与约束增长而迅速失效，因此在有限计算预算下，构造式启发式、局部搜索与群体式元启发式仍不可替代。
- **现有做法**：基于 LLM 的自动化启发式设计（AHD，如 FunSearch、EoH、ReEvo）把"设计启发式"转化为对规则/算子/可执行程序的搜索，利用代码大模型的程序先验进行语义级变异，配合执行、评估、进化选择与反馈。
- **关键缺口**：绝大多数 LLM-AHD 方法仍用**平均目标值 / 平均最优性差距**等标量适应度排序候选。这种聚合会掩盖一个重要事实——某启发式可能在大多数实例上都不错，却在一小类**结构上同质**的实例（如狭长客户分布、稀疏节点、长边模式、容量紧张的需求结构）上反复失败。
- **已有工作的不足**：互补启发式集（EoH-S）、状态依赖选择（HeurAgenix）、跨尺度训练、鲁棒性基准（Sim et al. 2025）等缓解了实例异质性，但没有回答"当一个有竞争力的路由启发式在特定模式上反复失败时，应如何修改其逻辑"。
- **RouteRepair 的定位**：保留外层进化搜索做广域发现，另加一层**内层"诊断—修复"**过程：保留父代的实例级性能画像，构造失败集/优势集/保护集，把路由证据转化为**有界修复目标**，并只对指定组件做定向修改。

## 2. 方法论

### 2.1 核心思想
- **从"平均适应度驱动的替换"转向"实例级修复"**：不丢弃整体有竞争力的父代，而是定位其反复失败的路由模式并做局部修正。
- **嵌套搜索框架**：外层进化循环负责生成、过滤、评估可执行启发式；内层针对"整体好但局部不稳定"的父代做诊断与定向修复。
- **固定骨干（fixed-backbone）表示**：求解器负责可行性、状态转移、邻域操作与终止；LLM 只改写一个指定接口，因此父子比较是有意义的（求解器不变）。

### 2.2 问题形式化与损失
- 每个适配器绑定一个固定求解器骨架 $S_k$，对第 $i$ 个实例 $x_i$ 生成解 $y_i$ 与目标值 $z_i(h)=f_k(x_i,y_i(h))$。
- 归一化实例级损失：$r_i(h)=\dfrac{z_i(h)-z_i^{ref}}{\max(z_i^{ref},\varepsilon)}$，其中 $z_i^{ref}$ 为最优值/已知最好值/协议固定值，$\varepsilon>0$ 防除零；目标均为最小化，$r_i=0$ 表示达到参考值。
- 保留**完整实例级损失向量** $\mathbf{r}(h)=(r_1,\dots,r_N)$ 用于定位失败，同时保留均值 $\bar r(h)$ 用于种群排序。

### 2.3 五个路由适配器（LLM 只改一个函数）
- TSP-GLS：`score_edge_for_penalty(...)`——为当前 tour 中已有边打分，决定惩罚优先级；惩罚更新、邻域搜索、终止保持固定。
