## 摘要
符号回归（SR）旨在发现简洁的数学表达式以表示数据中的基本关系，其可解释性和科学理解性超越了黑盒模型。然而，遗传规划等传统方法面临可扩展性挑战且对噪声高度敏感，而SINDy等稀疏回归技术则严重依赖预定的特征库。在本工作中，我们提出了一种神经符号回归（NSR）框架，将神经网络用作符号发现的函数预处理器。我们的方法采用解耦流水线：首先，神经网络在与交互感知的非线性特征空间中学习目标函数的平滑、对噪声鲁棒的近似；然后应用LASSO提取稀疏、可解释的闭式表达式。为提升预测精度和符号保真度，我们结合了使用Ray Tune和ASHA调度的分布式超参数优化。在Nguyen基准测试集上的实验表明，我们的方法在RMSE、噪声鲁棒性和分布外泛化方面持续优于SINDy和非调参的神经基线。消融研究证实了特征交互、神经深度和调参策略的重要性。总体而言，本研究提出了一种可扩展且可理解的神经符号框架，为科学机器学习中的神经近似与稀疏方程发现之间建立了坚实的桥梁。

## Abstract
Symbolic Regression (SR) seeks to find succinct mathematical expressions that represent the fundamental relationships within data, providing interpretability and scientific understanding that exceeds that of black-box models. Nevertheless, traditional methods like Genetic Programming face challenges with scalability and are highly sensitive to noise, while sparse regression techniques such as SINDy rely significantly on predetermined feature libraries. In this work, we present a Neural Symbolic Regression (NSR) framework that treats neural networks as functional preconditioners for symbolic discovery. Our approach uses a decoupled pipeline: a neural network first learns a smooth, noise-robust approximation of the target function in an interaction- aware nonlinear feature space. LASSO is then applied to extract sparse, interpretable closed-form expressions. To improve predictive accuracy and symbolic fidelity by integrating distributed hyperparameter optimization with Ray Tune and ASHA scheduling. Experiments on the Nguyen benchmark suite show that our approach consistently outperforms SINDy and non-tuned neural baselines in RMSE, noise robustness, and out-of-distribution generalization. Ablation studies confirm the significance of feature interactions, neural depth, and tuning strategies. In general, this study presents a scalable and understandable neural-symbolic framework, creating a solid link between neural approximation and the discovery of sparse equations for scientific machine learning.

## 2. 论文提出的方法论：核心思想、技术细节与算法流程

### 2.1 问题形式化
给定数据集 $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{n}$，$\mathbf{x}_i \in \mathbb{R}^d$，$y_i \in \mathbb{R}$，目标是寻找一个既极小化预测误差又受复杂度惩罚的分析表达式：
\[
f^* = \arg\min_{f \in \mathcal{F}} \frac{1}{n}\sum_{i=1}^{n} (f(\mathbf{x}_i) - y_i)^2 + \Omega(f)
\]
其中 $\Omega(f)$ 为复杂度惩罚项。

### 2.2 非线性特征库构造（Interaction-Aware Feature Library）
- 基础变换函数集合：
  \[
  F = \{\text{id}, \sin, \cos, \exp, \log(1+x), x^2, x^3, \tanh\}
  \]
- 对每个输入维度应用上述基础变换，构成原始特征矩阵 $\Phi(X)$。
- 为捕获跨维度的交互关系，加入**二阶成对交互项**：
  \[
  \Phi^{(2)}(X) = \{f_p(x_a) f_q(x_b) \mid a \neq b,\ f_p, f_q \in F\}
  \]
- 完整特征库：
  \[
  \Phi_{\text{full}}(X) = \Phi(X) \cup \Phi^{(2)}(X)
  \]
  总维度为：$|\Phi_{\text{full}}| = O(kd + k^2 \binom{d}{2})$。
- 特征库构建使用 Joblib 并行化加速。

### 2.3 神经逼近网络（Neural Approximation）
- 采用多层感知机（MLP），输入为扩充后的特征 $\Phi_{\text{full}}(X)$，输出为预测 $\hat{y}$。
- 结构要素：
  - 隐藏层数 $L \in \{1,2,3\}$，宽度 $H \in \{32,64,128\}$；
  - ReLU/GELU 激活函数；
  - Dropout 与权重衰减正则化；
  - AdamW 优化器。
- 训练目标：
  \[
  \mathcal{L}_{\text{NN}}(\theta) = \frac{1}{n}\sum_{i=1}^{n} \left( f_\theta(\Phi(\mathbf{x}_i)) - y_i \right)^2 + \alpha \|\theta\|_2^2
  \]
- 利用 CUDA（NVIDIA GPU）或 Apple MPS 后端进行 GPU 加速。

### 2.4 基于 LASSO 的稀疏符号提取
- 神经网络训练完成后，符号结构通过 LASSO 稀疏回归恢复：
  \[
  \beta^* = \arg\min_{\beta} \left\{ \|\Phi_{\text{full}}(X)\beta - y\|_2^2 + \lambda \|\beta\|_1 \right\}
  \]
- 非零系数对应激活的符号项，使用 SymPy 将其重建为解析表达式。
- 理论动机引用了压缩感知中的 RIP（受限等距性质）：若 $\Phi_{\text{full}}$ 满足 RIP 条件，$\beta^*$ 可被精确恢复。

### 2.5 超参数优化（Ray Tune + ASHA）
- 使用 Ray Tune 自动搜索神经与稀疏模型的超参数，搜索空间涵盖：
  - 学习率 $\eta \sim \text{LogUniform}(10^{-4}, 10^{-2})$
  - 隐藏层宽度 $H \in \{32,64,128\}$，深度 $L \in \{1,2,3\}$
  - LASSO 正则化强度 $\lambda \in \{10^{-4},10^{-3},10^{-2}\}$
  - Batch size $\in \{32,64,128\}$
- ASHA 调度器通过提前中止无效 trial 加速搜索，判定依据为 $m_i < \gamma \cdot \text{median}(m)$，目标为最小化验证集 RMSE。

### 2.6 NSR 算法流程（Algorithm 1）
1. 输入数据集 $(X, y)$；
2. 使用非线性变换构造特征库 $\Phi(X)$；
3. 构建二阶交互特征 $\Phi^{(2)}(X)$；
4. 形成完整特征矩阵 $\Phi_{\text{full}}$；
5. 训练 MLP：$f_\theta: \Phi_{\text{full}} \to y$；
6. 使用 LASSO 提取符号系数 $\beta$；
7. 使用 SymPy 将激活系数转换为闭式表达式；
8. 输出符号函数 $f^*(x)$。
