## 摘要
在非对称旅行商问题（Asymmetric TSP）中，给定 n 个顶点之间的距离，这些距离满足三角不等式但不必对称，目标是寻找经过所有顶点的最短巡回。在其路径版本——非对称路径 TSP（Asymmetric Path TSP）中，指定两个顶点 s 和 t，目标是寻找从 s 到 t 且经过所有顶点的最短路径。这两个问题都等价于有向图上边费用任意非负的版本，其中顶点可以访问多次。我们证明，对于所有常数 α≥1 和 ε>0，任何非对称 TSP 的 α-近似算法都可产生非对称路径 TSP 的 (α+ε)-近似算法。此前同类归约的最佳结果由 Feige 和 Singh 给出，可得到 α(2+ε)-近似算法。我们的结果回答了 Traub 和 Vygen 的一个开放问题。因此，非对称 TSP 的每个常数因子近似保证都可推广到非对称路径 TSP，最多相差任意小的加性误差。

## Abstract
In the Asymmetric Traveling Salesman Problem (Asymmetric TSP), we are given distances between $n$ vertices that satisfy the triangle inequality but need not be symmetric, and we seek a shortest tour through all vertices. In its path version, Asymmetric Path TSP, two vertices $s$ and $t$ are prescribed, and we seek a shortest path from $s$ to $t$ through all vertices. Both problems are equivalent to their versions with arbitrary nonnegative edge costs on a directed graph, in which vertices may be visited more than once. We show that for all constants $α\ge1$ and $\varepsilon>0$, any $α$-approximation algorithm for Asymmetric TSP yields an $(α+\varepsilon)$-approximation algorithm for Asymmetric Path TSP. The best previous reduction of this kind, due to Feige and Singh, yields an $α(2+\varepsilon)$-approximation algorithm. Our result answers an open question of Traub and Vygen. Consequently, every constant-factor approximation guarantee for Asymmetric TSP carries over to Asymmetric Path TSP up to an arbitrarily small additive error.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题对象**：非对称旅行商问题（Asymmetric TSP）要求找一条经过所有顶点、满足三角不等式（但不要求对称）的最短巡回；其路径版本 **Asymmetric Path TSP** 额外指定起点 `s` 与终点 `t`，要求找一条从 `s` 到 `t`、经过所有顶点的最短哈密顿路径。
- **核心痛点**：非对称 TSP 的近似算法已取得长足进步（如 12+2√2+ε、R*≈12.26+ε），但路径版本的近似比长期明显落后。历史上，Feige–Singh 归约只能把 α-近似 ATSP 转成 **α(2+ε)**-近似 Path TSP，即路径版本要额外损失接近一倍的因子。
- **本文目标**：回答 Traub–Vygen 专著 [16] 中的开放问题 16.30：能否把非对称路径 TSP **几乎无损**地归约到非对称 TSP？
- **整体含义**：作者证明，对任意常数 α≥1、ε>0，任何 α-近似 ATSP 算法都可转化为 **(α+ε)**-近似 Path TSP 算法。这意味着路径版本的近似难度本质上不高于巡回版本（最多差一个任意小的加性误差），未来 ATSP 的任何改进都能自动移植到路径版本。这延续了对称情形下 Traub–Vygen–Zenklusen 的 “Path TSP 归约到 TSP” 思路，但首次在非对称（有向）设定下实现。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体思路（黑盒归约 + 动态规划）

- 给定一个 α-近似 ATSP **预言机（oracle）**，算法不依赖其内部结构，只把它当作黑盒调用。
- 算法本身是一个**多项式规模子集族上的动态规划**，枚举可能出现在某个“精细化树（refinement tree）”中的顶点子集、边界端口（entries/exits）以及端口的连通分量划分。
- 分析中使用一条**最优路径 P\***（算法不知道）和一条**辅助参考路径 Q**（由 Feige–Singh 归约得到，成本 ≤ β·OPT，默认 β=3α），二者合称“参考路径”，总成本 ≤ (1+β)OPT。

### 2.2 关键概念

- **片段（fragment）与宽度**：对集合 X，`r(X)` 为 P* 在 X 中的极大子路径数，`q(X)` 为 Q 的片段数，宽度 `w(X)=r(X)+q(X)`。
- **端口（ports）**：片段的起点（entries）与终点（exits），动态规划需要猜测它们。
- **局部解（local solution）**：边多重集 F 满足 `div F = 1_S − 1_T`，且每个连通分量含一个端口。
- **局部候选构造**：在集合 U 上调用预言机得到哈密顿回路 C_U，再任意配对 entries 与 exits 加入边集 J，得到连通局部解，成本满足
  `c(F) ≤ α·c(P*[U]) + (α+1)·r(U)·d_U`，其中 `d_U` 为 U 的（有序对）直径。
- **混合巡回（hybrid tour）**：保留 P* 跨部分的边，部分内部用局部候选替换，得到 s-t-tour，成本
  `c(P̃) ≤ α·OPT − (α−1)c(K) + (α+1)Σ_U r(U)d_U`。
- 因此分析目标转化为：**找一个划分 U，使 Σ_U r(U)·d_U ≤ ε/(α+1)·OPT**。

### 2.3 精细化过程（仅用于分析）

- 沿**高度函数** `f_U(v)=c(a_U, v)`（a_U 为直径端点）的水平集划分集合。
- 定义**向上穿越数** `up^g_F(θ)`；由三角不等式可得 `∫ up dθ ≤ c(F)`（Lemma 4.2），且向上穿越数控制划分后片段数（Lemma 4.3、Corollary 4.4）。
- 两种划分操作：
  - **自由分裂（free split）**：若某层无参考路径向上穿越，直接在该层划分，宽度不增。
  - **桶分裂（bucket split）**：把所有层按向上穿越次数分桶（2 的幂），选总长度最大的桶统一划分；被切边为预算增长付费。
- **预算 B 与势函数**：用双对数势 `Φ(B)=ln(1+ln(AB))`，其中 `A=⌈4(α+1)(1+β)/ε⌉`；每轮预算增长由被切边支付（R3），每条边最多被切一次，最终证明 `B < B* = 3^{3A}`，且 `B* = exp(exp(O(α²/ε)))`。

### 2.4 动态规划（算法主体，Algorithm 1）

- 集合族 R：Q 的顶点序列上**至多 B\* 个区间之并**的所有非空集合，规模为 `(n+1)^{O(B*)}`。
- 状态 `(U, S, T, Π)`：U 为集合，`(S,T)` 为 profile，Π 为端口连通分量划分。
- 两类候选：
  - **局部候选**：对每个 U 调用一次预言机，得到回路后加配对边；
  - **合并候选**：对 `U = U₁ ⊎ U₂`，枚举边界边集 L（≤2B* 条有向边，代表 P* 的跨边猜测），由 (13) 式确定子 profile，拼接两个子解并检查连通性。
- 最终从根状态 `(V, {s}, {t}, {{s,t}})` 出发，经 shortcutting 得到哈密顿 s-t-路径。

### 2.5 主要理论结果

- **Theorem 1.1**：α-近似 ATSP ⇒ (α+ε)-近似 Path TSP。
- 预言机调用次数 `O(n^κ)`，`κ = exp(exp(O(α²/ε)))`；对固定 α、ε 为多项式时间。
- 对称情形下（Remark 8.1），用 Zenklusen 算法取 Q，可得到另一条 Path TSP 到 metric TSP 的归约，保证与 [17] 相同。
