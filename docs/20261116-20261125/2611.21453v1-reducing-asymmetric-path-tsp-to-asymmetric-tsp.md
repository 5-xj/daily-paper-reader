## 摘要
在非对称旅行商问题（Asymmetric TSP）中，给定 n 个顶点之间满足三角不等式但不必对称的距离，要求寻找一条经过所有顶点的最短巡回路线。在其路径版本——非对称路径 TSP 中，指定两个顶点 s 和 t，要求寻找一条从 s 到 t 且经过所有顶点的最短路径。这两个问题都等价于在有向图上边费用可为任意非负值、且顶点可被多次访问的版本。我们证明：对所有常数 α≥1 和 ε>0，任意非对称 TSP 的 α-近似算法都可导出非对称路径 TSP 的 (α+ε)-近似算法。此前同类归约中最好的结果由 Feige 和 Singh 给出，可得到 α(2+ε)-近似算法。我们的结果回答了 Traub 和 Vygen 的一个开放问题。因此，非对称 TSP 的每个常数因子近似保证都可转移到非对称路径 TSP，仅相差任意小的加性误差。

## Abstract
In the Asymmetric Traveling Salesman Problem (Asymmetric TSP), we are given distances between $n$ vertices that satisfy the triangle inequality but need not be symmetric, and we seek a shortest tour through all vertices. In its path version, Asymmetric Path TSP, two vertices $s$ and $t$ are prescribed, and we seek a shortest path from $s$ to $t$ through all vertices. Both problems are equivalent to their versions with arbitrary nonnegative edge costs on a directed graph, in which vertices may be visited more than once. We show that for all constants $α\ge1$ and $\varepsilon>0$, any $α$-approximation algorithm for Asymmetric TSP yields an $(α+\varepsilon)$-approximation algorithm for Asymmetric Path TSP. The best previous reduction of this kind, due to Feige and Singh, yields an $α(2+\varepsilon)$-approximation algorithm. Our result answers an open question of Traub and Vygen. Consequently, every constant-factor approximation guarantee for Asymmetric TSP carries over to Asymmetric Path TSP up to an arbitrarily small additive error.

## 1. 核心问题与研究动机

- **研究对象**：非对称旅行商问题（Asymmetric TSP）与其路径版本（Asymmetric Path TSP）。前者要求经过所有顶点的最短哈密顿回路，后者给定 $s,t$，要求最短哈密顿 $s$–$t$ 路径；两者均在满足三角不等式、但 $c(u,v)\neq c(v,u)$ 的有向度量下讨论。
- **核心问题**：能否把非对称 TSP 的近似算法“黑箱式”地转化为非对称路径 TSP 的近似算法，且**不损失常数因子**？

## 2. 方法论

### 2.1 总体框架
- 用**边多重集**语言刻画解：$s$–$t$-tour 定义为连通且 $\mathrm{div}\,F = \mathbf{1}_s-\mathbf{1}_t$ 的边多重集；由欧拉定理可遍历为 $s$–$t$ 游走，再用三角不等式**短路化（shortcutting）**得到哈密顿路径且费用不增（Lemma 2.1）。
- 算法只做三件事：计算一条参考路径 $Q$；填一张动态规划表；对根状态解短路化输出。分析则依赖一条未知的最优路径 $P^*$（仅用于证明）。

### 2.2 关键构件一：局部候选与混合游走
- 对集合 $U$，定义**直径** $d_U=\max_{a,b\in U}c(a,b)$（对有序对取最大，故双向都受控）、**片段数** $r(U)$（$P^*$ 在 $U$ 内的极大子路径数）、**端口**（片段的起点/终点）。
- **局部候选构造**：在 $U$ 上调用 oracle 得到哈密顿回路 $C_U$；再任意配对入口与出口，加入边集 $J$，得到 $F=C_U\sqcup J$。连通性由 $C_U$ 提供，$J$ 只负责修正散度。
- **费用界**（Lemma 3.2）：$c(F)\le \alpha\,c(P^*[U])+(\alpha+1)\,r(U)\,d_U$。证明用两次“直径界”：闭合片段成回路（界 oracle 回路）、加入入口→出口边。
- **混合游走**（Lemma 3.3）：给定 $V$ 的划分 $\mathcal{U}$，保留 $P^*$ 跨部件的边 $K$，部件内部替换为局部候选，得到 $s$–$t$-tour，费用
  $$c(\tilde P)\le \alpha\,\mathrm{OPT}-(\alpha-1)c(K)+(\alpha+1)\sum_{U\in\mathcal{U}} r(U)\,d_U .$$
- 因此分析目标化为：**寻找划分使 $\sum_U r(U)d_U \le \frac{\varepsilon}{\alpha+1}\mathrm{OPT}$，且细化过程中所有集合的“宽度”有界**。

### 2.3 关键构件二：高度函数、向上穿越与分割
- 引入**宽度** $w(X)=r(X)+q(X)$，其中 $q(X)$ 是第二条参考路径 $Q$（费用 $\le\beta\,\mathrm{OPT}$，默认由 Feige–Singh 归约取 $\beta=3\alpha$）的片段数；$q(X)\le k$ 等价于 $X$ 是 $Q$ 顶点序中 $\le k$ 个区间的并。
- 对部件 $U$ 取直径对 $(a_U,b_U)$，定义高度 $f_U(v)=c(a_U,v)$；则每个 $0\le\theta<d_U$ 的水平集都分离 $a_U$ 与 $b_U$，可在此分割。
- **两个引理**：
  - Lemma 4.2：$\int_{\mathbb{R}}\mathrm{up}^g_F(\theta)\,d\theta\le c(F)$（边上升幅度不超过其费用，有向单侧版本）。
  - Lemma 4.3：切片内片段数 $\le k+\mathrm{up}(\theta^-)+\mathrm{up}(\theta^+)$（每次离开切片必有一次向上穿越）。
- **两类分割**：
  - **自由分割（free split）**：若某部件存在向上穿越次数为 0 的水平，直接在此分割，宽度不增、预算不变。
  - **桶分割（bucket split）**：否则把各部件所有水平按穿越次数 $[h,2h)$ 分桶，忽略穿越次数 $>AB$ 的水平（总长度小），选总长度最大的桶，在各部件内沿该桶水平切成“cell 链”，记录为**二叉细分树**；预算 $B\to B+4h$。每个新集合宽度 $<B+4h$。
- **预算支付的势函数**：$\Phi(B)=\ln(1+\ln(AB))$，$A=\lceil 4(\alpha+1)(1+\beta)/\varepsilon\rceil$。每轮预算增长由**被切开的参考路径边**支付（每条边至多被切一次），得 $\Phi$ 总增量 $\le 2A$，最终 $B<B^*=3^{33^A}=\exp(\exp(O(\alpha^2/\varepsilon)))$。

### 2.4 关键构件三：动态规划
- 集合族 $\mathcal{R}$ = $Q$ 顶点序中至多 $B^*$ 个区间的并（多项式规模）。
- **状态** $(U,S,T,\Pi)$：轮廓（入口集/出口集）+ **端口划分** $\Pi$（记录哪些端口在同一连通分量），表中存该状态最便宜的局部解。
- **转移两类**：
  1. **局部候选**：对每个 $U$ 调用一次 oracle，对所有轮廓复用同一回路 $C_U$，端口划分为单块。
  2. **合并两个子集**：枚举 $U=U_1\sqcup U_2$ 与**边界集** $L$（$\le 2B^*$ 条 $U_1$–$U_2$ 间的有向边，模拟 $P^*$ 的跨边猜测），由 $L$ 推出子轮廓（式 (13)），并拒绝非法 $L$（重头/重尾、$|S_i|\neq|T_i|$、规模越界等）。
- **正确性**：Lemma 7.1 证明“端口划分足够”——同状态的两个局部解在任意外部拼接下诱导相同的连通结构，故可安全丢弃更贵者；Lemma 7.2（可靠性）与 Lemma 7.3（完备性，沿细化树归纳，用参考轮廓逐层比较）共同保证根状态费用 $\le(\alpha+\varepsilon)\mathrm{OPT}$。
- **复杂度**：oracle 调用 $O(n^{\kappa})$ 次，$\kappa=\exp(\exp(O(\alpha^2/\varepsilon)))$，对固定 $\alpha,\varepsilon$ 为常数，故多项式时间。

## 6. 主要结论与发现

- **主定理**：对任意常数 $\alpha\ge1,\varepsilon>0$，若存在 ATSP 的 $\alpha$-近似算法，则存在 Asymmetric Path TSP 的 $(\alpha+\varepsilon)$-近似算法；oracle 调用次数 $O(n^{\kappa})$，$\kappa=\exp(\exp(O(\alpha^2/\varepsilon)))$。
- 归约为**黑箱式**：不依赖 oracle 的内部结构，只在其限制到顶点子集上的实例上调用（子集封闭的实例类均适用，见 Remark 8.1）。
- 由此，ATSP 的每个常数因子保证都可（至多差任意小加性 $\varepsilon$）转移到路径版本；对称情形下同样给出 Path TSP → metric TSP 的新归约，保证与 Traub–Vygen–Zenklusen 相同。
- **遗留开放问题**：ATSP 与 Asymmetric Path TSP 自然 LP 松弛的整性间隙是否相同仍未知（Traub–Vygen 开放问题 9.25）；已知最好关系为 $\rho\mapsto 4\rho-3$（Köhne–Traub–Vygen）。

## 7. 优点

- **问题定位清晰且有价值**：直接消除 Feige–Singh 归约中近 2 倍的损失，回答文献中明确列出的开放问题。
- **技术路线简洁**：不需要辅助问题（如 $\Phi$-TSP）也不需要迭代 boosting，仅“一次”动态规划即达 $\alpha+\varepsilon$，与对称情形 Traub–Vygen–Zenklusen 的复杂机制形成对比。
- **处理非对称性的巧思**：识别出“开回路便宜、闭路径昂贵”（$c(s,t)$ 与 $c(t,s)$ 可严重不对称）是主要障碍，转而**在划分的部件内部**使用直径界，使双向距离同时受控（Example 1.2 与 Figure 1/2 说明清楚）。
- **宽度控制机制优雅**：以“向上穿越次数”为桥梁，用参考路径被切边支付预算增长，配以双对数势函数使常数收敛到 $B^*$。
- **工程化的 DP 设计**：仅记录端口划分即可保证可组合性（Lemma 7.1），并复用单个 oracle 回路服务所有轮廓，避免指数级猜测配对。
- **适用面更广**：Remark 8.1 说明结论可推广到子集封闭的实例类，并顺带给出对称情形的新归约。

- **常数极大，纯理论**：$\kappa=\exp(\exp(O(\alpha^2/\varepsilon)))$、$B^*=3^{33^A}$，运行时间与 oracle 调用次数在实践中完全不可行；论文亦未给出任何 tightened 常数或实现尝试。
- **无实验验证**：没有任何数值或实现层面的证据（哪怕小规模），对算法实际行为、常数影响、DP 表规模增长缺乏直观支撑。
- **oracle 调用范围强**：需在所有“$\le B^*$ 个 $Q$-区间并”的子集上调用 oracle（数量 $\sim(n+1)^{2B^*}$），远超仅调用一次的归约；对只能处理完整实例的 oracle 不友好。
- **依赖额外参考路径 $Q$**：默认用 Feige–Singh 得 $\beta=3\alpha$，把 $\alpha$ 以平方形式带入 $\kappa$；虽可用其他算法降低 $\beta$（如 Vygen 的 $\beta=15$），但会削弱“纯黑箱”性质。
- **加性误差而非乘性**：结论为 $\alpha+\varepsilon$ 而非 $\alpha(1+\varepsilon)$；当 OPT 很小时加性形式相对更弱（虽然 $\varepsilon$ 可任意小）。
