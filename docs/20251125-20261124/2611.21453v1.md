## 摘要
在非对称旅行商问题（非对称TSP）中，给定$n$个顶点之间的距离，这些距离满足三角不等式但不必对称，目标是寻找一条经过所有顶点的最短巡回路线。在其路径版本——非对称路径TSP中，指定两个顶点$s$和$t$，目标是寻找一条从$s$到$t$且经过所有顶点的最短路径。这两个问题均等价于在有向图上边代价任意非负的版本，其中顶点可被多次访问。我们证明，对于所有常数$α\ge1$和$\varepsilon>0$，任何非对称TSP的$α$-近似算法都可导出非对称路径TSP的$(α+\varepsilon)$-近似算法。此前同类归约的最佳结果由Feige和Singh给出，得到的是$α(2+\varepsilon)$-近似算法。我们的结果回答了Traub和Vygen提出的一个开放问题。因此，非对称TSP的每个常数因子近似保证都可推广到非对称路径TSP，仅增加任意小的加性误差。

## Abstract
In the Asymmetric Traveling Salesman Problem (Asymmetric TSP), we are given distances between $n$ vertices that satisfy the triangle inequality but need not be symmetric, and we seek a shortest tour through all vertices. In its path version, Asymmetric Path TSP, two vertices $s$ and $t$ are prescribed, and we seek a shortest path from $s$ to $t$ through all vertices. Both problems are equivalent to their versions with arbitrary nonnegative edge costs on a directed graph, in which vertices may be visited more than once. We show that for all constants $α\ge1$ and $\varepsilon>0$, any $α$-approximation algorithm for Asymmetric TSP yields an $(α+\varepsilon)$-approximation algorithm for Asymmetric Path TSP. The best previous reduction of this kind, due to Feige and Singh, yields an $α(2+\varepsilon)$-approximation algorithm. Our result answers an open question of Traub and Vygen. Consequently, every constant-factor approximation guarantee for Asymmetric TSP carries over to Asymmetric Path TSP up to an arbitrarily small additive error.

## 1. 核心问题与研究动机

- **问题背景**：非对称旅行商问题（Asymmetric TSP）要求在有向度量（满足三角不等式但不必对称）下寻找经过所有顶点的最短哈密顿回路；其路径版本（Asymmetric Path TSP）则指定起点 $s$ 与终点 $t$，要求寻找从 $s$ 到 $t$ 的最短哈密顿路径。
- **核心痛点**：在对称情形下，Traub–Vygen–Zenklusen 已证明任意 $\alpha$-近似 TSP 算法可导出 $(\alpha+\varepsilon)$-近似的 Path TSP 算法；但在非对称情形，此前最好的归约（Feige–Singh）只能得到 $\alpha(2+\varepsilon)$，即损失了约 2 倍的因子。原因在于有向度量中"打开回路"（加边 $(s,t)$）与"闭合路径"（加边 $(t,s)$）的代价不对称，$c(t,s)$ 可能远大于 OPT。
- **研究目标**：消除这一 2 倍损失，证明非对称路径 TSP 在近似意义上与 ATSP 同样容易，从而回答 Traub 与 Vygen 专著中的开放问题 16.30。
- **整体含义**：一旦成立，ATSP 领域所有常数因子近似改进（如 Vygen 的 $12+2\sqrt{2}+\varepsilon$、Hajiaghayi–Yun 的 $R^*+\varepsilon\approx 12.26$）都可几乎无损地迁移到路径版本。

## 2. 方法论

### 2.1 核心思想

- **分而治之 + 局部替换**：将顶点集划分为若干部分，部分之间保留最优路径 $P^*$ 的边，部分内部用 ATSP oracle 生成的"连通局部解"替换 $P^*$ 的片段（fragments）。所得边多重集称为**混合巡回（hybrid tour）**，其代价上界为
  $$\alpha\,\mathrm{OPT} + (\alpha+1)\sum_{U} r(U)\,d_U,$$
  其中 $r(U)$ 为 $P^*$ 在 $U$ 中的片段数，$d_U$ 为 $U$ 的有向直径。因此只需找到满足 $\sum_U r(U)d_U \le \frac{\varepsilon}{\alpha+1}\mathrm{OPT}$ 的划分。
- **局部候选构造**：对集合 $U$，调用 oracle 得到哈密顿回路 $C_U$（连通且平衡），再任意配对入口与出口并加入边集 $J$ 以匹配 $P^*$ 片段在端口处的净流量（散度），得到连通局部解，代价 $\le \alpha c(P^*[U]) + (\alpha+1)r(U)d_U$。关键点：无需保持"哪个入口接哪个出口"，只需连通性与端口散度。

### 2.2 关键技术细节

- **高度函数与向上穿越**：在每个部分 $U$ 中取直径对 $(a_U,b_U)$，定义高度 $f_U(v)=c(a_U,v)$。由三角不等式，任意边上升幅度不超过其代价，故 $\int \mathrm{up}_F(\theta)\,d\theta \le c(F)$（Lemma 4.2）。向上穿越次数还控制划分后片段的增加量：slab 中片段数 $\le$ 原片段数 + 两个边界层的向上穿越数（Lemma 4.3）。
- **两类划分操作**：
  - **自由分裂（free split）**：若存在某层无任何参考路径边向上穿越，直接在该层划分，宽度不增。
  - **桶分裂（bucket split）**：否则按向上穿越次数 $[h,2h)$ 分桶，选总长度最大的桶，在所有部分按该桶的层集划分；宽度增至 $B+4h$，但被切边代价 $\ge h \times$ 桶总长度，用于"支付"宽度增长。
- **双参考路径**：算法先用 Feige–Singh 归约计算一条 $s$-$t$ 路径 $Q$（$c(Q)\le 3\alpha\,\mathrm{OPT}$），作为第二条参考路径。划分需同时保持 $P^*$ 与 $Q$ 的片段数有界，从而所有集合都是 $Q$ 顶点序上至多 $B^*$ 个区间的并，构成多项式大小的集合族 $\mathcal{R}$。
- **双对数势函数**：$\Phi(B)=\ln(1+\ln(AB))$，$A=\lceil 4(\alpha+1)(1+\beta)/\varepsilon\rceil$。每轮势增 $\le 2A\cdot c(E)/((1+\beta)\mathrm{OPT})$，每条边至多被切一次，故总势增有界，导出宽度上界 $B^* = 3^{3^{3A}}$，即 $\exp(\exp(O(\alpha^2/\varepsilon)))$。
- **动态规划**：在集合族 $\mathcal{R}$ 上按基数递增填表，状态为 $(U,S,T,\Pi)$——集合、入口集、出口集、端口连通分量划分。候选来源有二：(a) oracle 局部候选（对应精化树叶子）；(b) 合并两个子集并猜测 $P^*$ 跨边集 $L$（$|L|\le 2B^*$，对应内部节点）。核心引理（Lemma 7.1）证明端口划分足以保证替换的等价性。最终对根状态解做 shortcutting 得到哈密顿路径。

### 2.3 算法流程（Algorithm 1 概要）

1. 计算 $Q$（Feige–Singh 归约，$\beta=3\alpha$）；若 $c(Q)=0$ 直接返回。
2. 构造集合族 $\mathcal{R}$（$Q$ 序上 $\le B^*$ 个区间的并）。
3. 按基数递增遍历 $U\in\mathcal{R}$：单点初始化；否则调用 oracle 生成局部候选，并枚举所有二分子集、父 profile、边界集 $L$ 与子表项进行合并，记录满足连通性检查的最便宜解。
4. 对 $Z[V,\{s\},\{t\},\{\{s,t\}\}]$ 做 shortcutting 输出。

## 6. 主要结论与发现

- **主定理（Theorem 1.1）**：对任意常数 $\alpha\ge1$、$\varepsilon>0$，若 ATSP 存在 $\alpha$-近似算法，则 Asymmetric Path TSP 存在 $(\alpha+\varepsilon)$-近似算法。这消除了 Feige–Singh 归约中 2 倍因子的损失，回答了 Traub–Vygen 开放问题 16.30。
- **推论**：ATSP 的每个常数因子近似保证都以任意小加性误差迁移到路径版本；例如结合 Vygen 的算法可得 $12+2\sqrt{2}+\varepsilon$ 的路径版本保证。
- **副产品（Remark 8.1）**：同一构造在对称度量下给出 Path TSP 到 metric TSP 的另一种 $(\alpha+\varepsilon)$ 归约，与 Traub–Vygen–Zenklusen 的结果等价，且无需辅助问题 $\Phi$-TSP 或迭代 boosting。
- **遗留开放问题**：ATSP 与 Asymmetric Path TSP 的自然 LP 松弛是否具有相同整性间隙仍未解决（开放问题 9.25）；已知最好关系为 Köhne–Traub–Vygen 的 $4\rho-3$。
