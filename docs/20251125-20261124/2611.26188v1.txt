# Approximation Algorithms for Asymmetric Multi-Path TSP 

Manuel Christalla ∗ Vera Traub †

Abstract 

Asymmetric Multi-Path TSP is the generalization of the Asymmetric Traveling Salesperson Problem where we are looking for k walks, each with prescribed start si and prescribed end ti,such that every vertex is visited by at least one of the walks. The objective is to minimize the total length of all walks. In general, it is NP-hard to find any approximation for this problem in polynomial time (even if the approximation factor is allowed to depend on the number of vertices). We show that one can obtain an O(k)-approximation in time nO(k), answering an open question by Friggstad [2013]. For the special case where all tour start vertices si are identical and all end vertices ti are identical, we obtain an O(k)-approximation in polynomial time, as well as an ( O( 1 

> ϵ

), 1 + ϵ)-bicriteria approximation. For the multi-depot setting, where si = ti for all i, we obtain a constant-factor approximation in polynomial time. Finally, our results imply improved constant-factor approximation algorithms for Asymmet-ric Regret-Bounded Vehicle Routing and unit-weight Path ATSP. 

# 1 Introduction 

Path TSP is the general version of the (metric) Traveling Salesperson Problem, where we are looking for a shortest tour from a given start vertex s to a given end vertex t that visits all other vertices in between. In the symmetric case, this problem was first studied by Hoogeveen [Hoo91], and a long line of work [AKS15; Seb13; Vyg16; GV18; Sv19; TV19; Zen19] culminated in a reduction from Path TSP to the classical TSP (i.e., the special case s = t) with an arbitrarily small loss in the approximation factor [TVZ22]. In the asymmetric case, Feige and Singh [FS07] gave an analogous reduction, which, however, loses a factor of 2 + ϵ in the approximation guarantee (for an arbitrary constant ϵ > 0). For ATSP, Vygen [Vyg26] obtained an approximation factor 12 + 2 √2 + ϵ ≈ 14 .83 for general weights and 3 + 2 √2 + ϵ ≈ 5.83 for unit weights. For the path version, the techniques of [Vyg26; TV25] yield a (15 + ϵ)-approximation. In very recent work, Hajiaghayi and Yun [HY26] report an improved approximation factor of 6+ √2+ p15 + 6 √2+ ϵ ≈ 12 .2604 for both ATSP and Path ATSP, and Li [Li26] reports a reduction from Path ATSP to ATSP with an arbitrarily small loss in the approximation factor. The results of [HY26] and [Li26] were obtained in independent work parallel to ours. Combining their techniques with ours might lead to further improvements of some of the constants in our results, which we do not yet consider in the current version of this paper.

Problem 1.1 (Asymmetric Multi-Path TSP) . An instance of Asymmetric Multi-Path TSP consists of a digraph G = ( V, E ) with edge costs c : E → R≥0 and terminal pairs ( s1, t 1), . . . , (sk, t k) with 

si, t i ∈ V for all i ∈ [k]. The task is to find si-ti-walks Pi for each i ∈ [k] such that V = Ski=1 V (Pi) and the total cost 

Pki=1 c(Pi) is minimized, or to decide that no such collection of walks exists. For the symmetric special case (where G is undirected) the currently best approximation factor is 1 + 2√e ≈ 2.2131 due to B¨ ohm, Friggstad, M¨ omke, and Spoerhase [BFMS25]. If the number k

of walks is a constant, then in the symmetric setting one can reduce the problem to TSP at an arbitrarily small loss in the approximation factor as shown in [TV25], building on [TVZ22]. For the symmetric unit-weight case ( G undirected and c ≡ 1), Alimi, Dahlmeier, M¨ omke, Pabst, and Vargas Koch [ADMPV26] recently gave a 2-approximation, which was subsequently improved to a 1.9304-approximation in [DLPV26]. In the general asymmetric setting, however, it is already NP-hard to decide if any feasible solution exists [Fri13]. For the special case k = 2, Friggstad [Fri13] gave an O(log n)-approximation, where n = |V |. Moreover, he asked whether one can obtain an approximation factor of f (k) · log n

in time ng(k) for some functions f and g. After Friggstad asked this question, the first constant-factor approximations for ATSP were achieved [STV20; TV22] and thus it is now natural to ask for an f (k)-approximation in time ng(k). We answer this question positively, even for f and g being linear functions. 

Theorem 1.2. There is an algorithm that computes, for every Asymmetric Multi-Path TSP in-stance with n vertices and k terminal pairs, an O(k)-approximation in time nO(k).

Our proof of this result has two main ingredients. First, we build on techniques from the existing constant-factor approximations for ATSP to obtain a bicriteria approximation for the special case where all start vertices si are identical and all end vertices ti are identical. Second, we provide a dynamic programming algorithm to reduce to this special case. While this algorithm is a simple extension of the dynamic program from [FS07], our analysis is different. For details, we refer to Section 2. As deciding whether a feasible Multi-Path solution exists is NP-hard [Fri13], we cannot hope for a polynomial-time approximation algorithm for arbitrary k, unless P = NP. Thus, in the following we consider special cases that admit polynomial-time approximation algorithms even when k is arbitrarily large. 

1.1 The Single-Source/Single-Sink Case 

A natural special case of the Asymmetric Multi-Path TSP is when all start vertices si are identical and all end vertices ti are identical. 

Problem 1.3 (Asymmetric Single-Source/Single-Sink Multi-Path TSP) . An instance of Asymmet-ric Single-Source/Single-Sink Multi-Path TSP (Asymmetric SSSS Multi-Path TSP) consists of a digraph G = ( V, E ) with edge costs c : E → R≥0 and two distinct vertices s, t ∈ V , as well as an integer k ≥ 1. The task is to find s-t-walks P1, . . . , P k such that V = Ski=1 V (Pi) and Pki=1 c(Pi) is minimized, or to decide that no such collection of walks exists. 2To decide feasibility of a given instance in polynomial time, we may contract all strongly con-nected components and then ask for an integral s-t-flow of value k that covers every component. We therefore focus on approximation guarantees and may always assume that instances are feasible. A related variant, already studied by Friggstad [Fri13], is the Asymmetric Multiple-Source/ Multiple-Sink Multi-Path TSP, where the instance contains terminal sets S = {s1, . . . , s k} , T =

{t1, . . . , t k} ⊆ V such that S ∩ T = ∅ and |S| = |T | = k ≥ 1. The task is then to find a permutation π : [ k] → [k] and si-tπ(i)-walks Pi for all i ∈ [k] such that V = Ski=1 V (Pi) and 

Pki=1 c(Pi) is minimized, or to decide that no such collection of walks exists. However, from the perspective of approximation algorithms this problem is essentially equivalent to the Single-Source/Single-Sink variant (see Appendix C.1). Thus, in the following we will focus on the Single-Source/Single-Sink case. Friggstad [Fri13] gave an algorithm to compute a ( O( log nϵ ), 1 + ϵ)-bicriteria approximation in polynomial time. For α, β ≥ 1, an ( α, β )-bicriteria approximation for Asymmetric SSSS Multi-Path TSP is a solution consisting of at least k and at most βk walks, whose total cost is at most α

times the cost of an optimal solution using exactly k walks. We improve on Friggstad’s bicriteria approximation by showing that the factor of log n in the approximation guarantee is not necessary. Moreover, we show that in the unit-weight special case ( c ≡ 1), we can even obtain a constant-factor approximation.

Combining [KTV20] with [Vyg26] gives an approximation guarantee of 5 + 4 √2 + ϵ for unit-weight Path ATSP. Since we analyze the cost of our solution relative to the LP optimum, this also implies an improved upper bound of 5+2 √2 on the integrality gap of the standard LP relaxation for unit-weight Path ATSP. We highlight that Friggstad’s bicriteria approximation does not use an approximation algo-rithm for ATSP as a black box and we cannot simply combine his approach with the improved approximation algorithms for ATSP to prove the first part of Theorem 1.4. First, we show that the existing constant-factor approximation algorithms for ATSP can be modified to additionally guarantee the following. For a given optimal LP solution x and a given vertex v, we can ensure that the degree of v in the computed tour is preserved, i.e., the out-degree of v will be between ⌊x(δ+(v)) ⌋ and ⌈x(δ+(v)) ⌉, while the cost of the computed tour remains O(c(x)). Second, 3to obtain our bicriteria approximation, we prove a key lemma about optimal dual solutions to the relaxed linear programming relaxation (where we allow (1 + ϵ)k paths); see Lemma 3.5. Here, the idea is to view the optimal dual solution for the relaxed LP as a (feasible) dual solution to the original LP. For details on the bicriteria approximation we refer to Section 3. The second part of Theorem 1.4 will be proved in Appendix C.2. 

1.2 Asymmetric Multi-Depot TSP 

Another natural special case of the Asymmetric Multi-Path TSP is the multi-depot case, where we have si = ti for all i ∈ [k]. 

Problem 1.5 (Asymmetric Multi-Depot TSP) . An instance of Asymmetric Multi-Depot TSP consists of a digraph G = ( V, E ) with edge costs c : E → R≥0 and a set T = {t1, . . . , t k} ⊆ V of terminals. The task is to find an Eulerian multi-subset F ⊆ E of edges such that each strongly connected component of ( V, F ) contains at least one terminal ti ∈ T and the total cost c(F ) is minimized, or to decide that no such multi-set of edges exists. Note that there exists a feasible solution if and only if every strongly connected component of G

contains a terminal. Hence, this can be decided in polynomial time, and we may therefore always assume that instances are feasible. For the symmetric special case (where G is undirected), a (1 + 1√2 )-approximation was recently given by Zhao, Liu and Xiao [ZLX26]. For the symmetric unit-weight case, Dahlmeier, Luqu´ e, Pabst, and Vargas Koch [DLPV26] gave a 32 -approximation. In the asymmetric setting, Friggstad [Fri13] obtained an O(log n)-approximation algorithm by adapting the cycle cover algorithm of Frieze, Galbiati, and Maffioli [FGM82] for ATSP. We improve the approximation factor to a constant. 

Theorem 1.6. There is a (12 + 2 √2 + ϵ)-approximation algorithm for Asymmetric Multi-Depot TSP for any ϵ > 0.For the unit-weight special case of Asymmetric Multi-Depot TSP, there is a (5 + 2 √2 + ϵ)-approximation algorithm for any ϵ > 0.

Note that, for general weights, our approximation guarantee matches the 12 + 2 √2 + ϵ bound of [Vyg26] for ATSP. Theorem 1.6 will be proved in Appendix B. 

1.3 Asymmetric Regret-Bounded Vehicle Routing 

Finally, our bicriteria approximation for Asymmetric SSSS Multi-Path TSP leads to an improved constant-factor approximation for the Asymmetric Regret-Bounded Vehicle Routing Problem. 

Problem 1.7 (Asymmetric Regret-Bounded Vehicle Routing Problem) . An instance of the Asym-metric Regret-Bounded Vehicle Routing Problem consists of a complete digraph G = ( V, E ) with a root vertex r ∈ V , edge costs c : E → R≥0 satisfying the triangle inequality, and a regret bound R ∈ R≥0.The task is to find a minimum number of r-rooted paths P1, . . . , P k such that every vertex is covered and each path Pi has regret at most R, that is, regret( Pi) := c(Pi) − c(r, v i) ≤ R, 

where vi is the endpoint of Pi.4For the symmetric variant of this problem (i.e., c(v, w ) = c(w, v ) for all v, w ∈ V ), the first constant-factor approximation algorithm was given by Friggstad and Swamy [FS14], and subse-quently improved in [FS17] and [BTV23], culminating in a 10-approximation. Friggstad and Swamy [FS14] observed that any ( α, β )-bicriteria approximation algorithm for the Asymmetric SSSS Multi-Path TSP yields an ( α + β)-approximation algorithm for the Asymmetric Regret-Bounded Vehicle Routing Problem. Combining this reduction with the results of [Fri13; FSS13] yields an O(log n)-approximation. We observe that any α-approximation algorithm for ATSP directly yields a (2 α+ϵ, 2α)-bicriteria approximation algorithm for Asymmetric SSSS Multi-Path TSP. Via the reduction from [FS14] and the approximation algorithm of [HY26] for ATSP, this yields an approximation guarantee less than 50 for Asymmetric Regret-Bounded Vehicle Routing. Our bicriteria result for Asymmetric SSSS Multi-Path TSP implies an improvement: 

Theorem 1.8. There is a 23 -approximation algorithm for the Asymmetric Regret-Bounded Vehicle Routing Problem. 

For details, we refer to Appendix C.4.

7In prior work on Path ATSP [FS07; KTV20] the common approach is to add an artificial back-ward edge ( t, s ) (or some other path from t to s) and then apply a constant-factor approximation to the resulting instance of ATSP. In a second step one removes all copies of the edge ( t, s ) from the tour, which results in a collection of s-t walks. However, this approach does not provide any control of the number of resulting s-t walks. If we have too few walks, this can be easily addressed by adding a sufficient number of shortest s-t paths. If we have too many walks, the situation is more tricky and some of the s-t walks need to be merged into a single one. To account for the cost of this merging step, the cost of the artificial backward edge ( t, s ) is typically chosen as the merging cost required to reduce the number of s-t walks by one. However, in our multi-path setting merging becomes more difficult and it is not clear how to reduce the number of paths by one at a cost of less than some constant factor times k ·LP or k ·OPT (and already this is not obvious). Moreover, in order to turn an optimal solution to (SSSS-P) into a feasible solution to the ATSP LP, we would need to give the backward edge ( t, s ) an LP value of k. # 4 Open Questions 

For the Asymmetric Multi-Path TSP, we showed that there is an f (k)-approximation algorithm with running time ng(k) for f = O(k) and g = O(k), where n is the number of vertices and k is the number of terminal pairs (Theorem 1.2). Since determining whether a feasible solution exists is NP-hard for this problem [Fri13], we cannot hope for such an algorithm with running time polynomial in n and k, unless P = NP. However, it remains open whether the approximation guarantee can be improved and made independent of k.11 Open Question 4.1. Is there a ρ-approximation algorithm for the Asymmetric Multi-Path TSP in time ng(k) for some function g and some constant ρ ≥ 1, which is independent of the number k

of terminal pairs? Moreover, it remains open whether a true constant-factor approximation for the Single-Source/ Single-Sink Multi-Path TSP exists. Our algorithm substantially exploits the standard LP relax-ation (SSSS-P). An upper bound on its integrality gap of O(k) follows from Lemmas 3.3 and 3.4. (Here k is again the number of walks from the source to the sink.) 

Open Question 4.2. Is the integrality gap of the standard LP relaxation (SSSS-P) for the Single-Source/Single-Sink Multi-Path TSP bounded by a constant?

# A Dynamic Program for Precedence-Preserving Solutions 

In this section, we prove Lemma 2.3, which we restate here for convenience: 

Lemma 2.3. Given ℓ ≤ 2k vertex-disjoint paths Q1, . . . , Q ℓ covering V \ (S ∪ T ), we can compute a cheapest precedence-preserving solution in time nO(k).Proof. We generalize the dynamic program of Feige and Singh [FS07] to our setting. The dynamic program constructs the paths P1, . . . , P k simultaneously. A state consists of 

• for every j ∈ [ℓ], a prefix Rj of Qj , and 

• for every i ∈ [k], the current last vertex of Pi.The dynamic program maintains the invariant that the set of vertices covered by the partial paths Pi

is precisely S ∪Sℓj=1 V (Rj ). For every state, we compute a minimum-cost collection of partial paths realizing this state. Initially, we consider the state where all prefixes Rj are empty and each Pi

consists of just the single vertex si.To transition to a successor state, we choose indices i ∈ [k] and j ∈ [ℓ] with Rj̸ = Qj . Let v be the first vertex of Qj not contained in Rj . We append v to Pi and extend Rj by v, updating the cost accordingly. We process all states in increasing order of Pℓj=1 |V (Rj )|.After all states have been processed, we enumerate all final states (where Rj = Qj for all j). If 

vi is the current last vertex of Pi in this state, we append the edge ( vi, t i) for every i ∈ [k]. Among all solutions we obtain from the final states, we return a cheapest one. The order in which we added vertices to obtain the returned solution is a linear order that is consistent with each Qj and each constructed path Pi. Hence, we indeed obtain a precedence-preserving solution. Conversely, consider any precedence-preserving solution and its witnessing linear order. By the triangle inequality, we may assume that every non-terminal vertex appears at most once among the walks, and that no terminal appears as an internal vertex. Consider the vertices according to the linear order and append each vertex to the path Pi containing it in the given solution. Whenever a vertex of Qj is considered, the consistency of the linear order with 

Qj implies that it is the first vertex following the already considered prefix Rj of Qj . Hence, a straightforward induction shows that the dynamic program constructs a solution which is not more expensive than this solution. Finally, there are nO(k+ℓ) different states and each state has O(kℓ ) successor states. Because 

ℓ ≤ 2k, the overall running time is nO(k).

B.2 Vertebrate Pairs 

The next step is to reduce the problem to vertebrate pairs .In the constant-factor approximation for Asymmetric TSP, a strongly laminar instance is solved by first contracting each maximal non-singleton set L ∈ L to a single vertex. The resulting con-tracted instance is node-weighted and can be solved by Svensson’s algorithm [Sve15; TV25]. All contracted sets are then uncontracted and handled recursively. However, a direct application of this approach does not prevent the same set L ∈ L from being charged at multiple levels of the recursion. To avoid this, the algorithm further adds a connected Eulerian multi-graph, called the backbone . Laminar sets visited by the backbone need not be contracted and processed recursively.
