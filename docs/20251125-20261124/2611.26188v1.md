## 摘要
非对称多路径旅行商问题是非对称旅行商问题的推广，其中我们要寻找 k 条路径，每条路径具有指定的起点 s_i 和指定的终点 t_i，使得每个顶点至少被其中一条路径访问。目标是最小化所有路径的总长度。一般而言，在多项式时间内找到该问题的任何近似都是 NP 难的（即使允许近似因子依赖于顶点数）。我们证明可以在 n^{O(k)} 时间内获得 O(k)-近似，回答了 Friggstad [2013] 提出的一个开放问题。对于所有路径起点 s_i 相同且所有终点 t_i 相同的特殊情况，我们在多项式时间内获得 O(k)-近似，以及一个 (O(1/ε), 1+ε)-双标准近似。对于多仓库设置，即对所有 i 有 s_i = t_i，我们在多项式时间内获得常数因子近似。最后，我们的结果蕴含了非对称后悔有界车辆路径问题和单位权重路径 ATSP 的改进常数因子近似算法。

## Abstract
Asymmetric Multi-Path TSP is the generalization of the Asymmetric Traveling Salesperson Problem where we are looking for $k$ walks, each with prescribed start $s_i$ and prescribed end $t_i$, such that every vertex is visited by at least one of the walks. The objective is to minimize the total length of all walks. In general, it is NP-hard to find any approximation for this problem in polynomial time (even if the approximation factor is allowed to depend on the number of vertices). We show that one can obtain an $O(k)$-approximation in time $n^{O(k)}$, answering an open question by Friggstad [2013].   For the special case where all tour start vertices $s_i$ are identical and all end vertices $t_i$ are identical, we obtain an $O(k)$-approximation in polynomial time, as well as an $(O(\frac{1}ε), 1+ε)$-bicriteria approximation. For the multi-depot setting, where $s_i =t_i$ for all $i$, we obtain a constant-factor approximation in polynomial time.   Finally, our results imply improved constant-factor approximation algorithms for Asymmetric Regret-Bounded Vehicle Routing and unit-weight Path ATSP.

## 一、核心问题与研究动机

- **问题定义**：非对称多路径旅行商问题（Asymmetric Multi-Path TSP）是 ATSP 的推广：给定有向图 G=(V,E)、边费用 c、k 个终端对 (s_i,t_i)，要求找 k 条 s_i→t_i 的游走，使所有顶点至少被一条游走覆盖，最小化总费用。
- **背景与难点**：一般情形下，该问题连“判定是否存在可行解”都是 NP 难的（Friggstad 2013），因此多项式时间内不可能有任意（甚至依赖 n 的）近似比，除非 P=NP。Friggstad 提出开放问题：能否在 n^{g(k)} 时间内得到 f(k)·log n 或 f(k) 近似？
- **研究定位**：本文正面回答该问题，给出 f、g 均为线性的结果（O(k) 近似、n^{O(k)} 时间），并针对三个可多项式求解的特殊情形（单源单汇、多仓库、单位权重）给出更强保证，进而改进 Regret-Bounded VRP 与单位权重 Path ATSP 的常数因子。
- **整体含义**：在 ATSP 常数因子近似（Svensson–Tarnawski–Végh、Traub–Vygen、Vygen 等）已成熟的背景下，本文把这一进展系统性地推广到“多路径/多终端”结构，明确了时间–近似权衡的边界。

## 二、方法论

### 2.1 总体框架（定理 1.2：O(k) 近似，n^{O(k)} 时间）

- **第一步：构造初始路径集合**（引理 2.1）。通过单源单汇双准则近似（定理 1.4，取 ε=1）构造 ℓ≤2k 条顶点不相交路径 Q_1,…,Q_ℓ，覆盖 V\(S∪T)，总费用 ≤ 51·OPT。
- **第二步：定义“保序解”**（定义 2.2）。要求存在 V\(S∪T) 上的线性序 ≼，使得在 Q_j 与 P_i 上“先于”关系都与 ≼ 一致（推广 Feige–Singh 的路径归约思想）。
- **第三步：动态规划求最便宜保序解**（引理 2.3）。状态为“每条 Q_j 的前缀 R_j + 每条 P_i 的当前末端”，按已覆盖顶点数递增转移，状态数 n^{O(k+ℓ)}，因 ℓ≤2k 故总时间 n^{O(k)}。
- **第四步：证明存在廉价保序解**（引理 2.4）。取最优解 P*_i 与 Q_j 的并图 H，按强连通分量 K 分解；每个 Q_j 与分量 C 的交是连续子路径，将这些子路径任意拼接成 R_C，费用满足 c(R_C) ≤ ℓ·c(E(C))（三角不等式）；再按拓扑序把分量分配给某条 P*_i 并连接，得到总费用 ≤ (ℓ+2)(Σc(Q_j)+OPT)+OPT = O(k)·OPT，且构造天然给出满足一致性的线性序。

### 2.2 单源单汇双准则近似（定理 1.4 前半）

- **LP 与对偶**：使用标准割约束 LP（SSSS-P）及其对偶（SSSS-D），对偶目标为 k(a_t−a_s)+Σ 2y_U。
- **关键障碍**：传统“加反向边 (t,s) 化为 ATSP”的做法无法控制产生的 s-t 游走条数，强行合并会带来 k² 量级损失。
- **关键技术一：保度近似**（定义 3.1、定理 3.2）。改造 ATSP 常数因子算法，使仓库点度数满足 ⌊x(δ⁻(t))⌋ ≤ |δ⁻_F(t)| ≤ ⌈x(δ⁻(t))⌉；多仓库情形 α_MD ≤ 12+2√2+ε（单位权重 5+2√2+ε）。
- **关键技术二：辅助图与对偶势**（引理 3.3）。加新点 v* 与边 (t,v*)、(v*,s)（各取 LP 值 k），用对偶势 a 把费用平移为非负 c′(v,w)=c(v,w)+a_v−a_w；对 (G′,{v*},c′) 应用保度近似，v* 度数恰为 k，删去两条新边即分解为 k 条 s-t 游走，费用 ≤ k(a_t−a_s)+α_MD·Σ2y_U。
- **关键技术三：对偶和式界**（引理 3.4）。在最优原始 LP 支撑图上，可选取最优对偶使 Σ2y_U ≤ (k+1)·LP（推广 Köhne–Traub–Vygen 的论证，用 Menger 型论证构造 k+1 条路径；文中给出紧例）。
- **双准则化**（引理 3.5）。对 k′=⌊(1+ε)k⌋ 求对偶解（对 k 仍可行），证明 Σ2y′_U ≤ ((1+ε)k/(εk−1))·LP；分 ε≤τ/k 与 ε>τ/k（τ=1+√2）两种情形，最终得到 (O(1/ε), 1+ε) 双准则，常数约 51/ε。

### 2.3 多仓库常数因子（定理 1.6）

- 复用 ATSP 框架（强层状实例、脊椎对 vertebrate pairs、子游覆盖 subtour cover、Svensson 算法），新增两点改造：
  - 用“经过所有仓库点的虚拟环”作 backbone，把多仓库归约到简单脊椎对；
  - 证明子游覆盖的舍入可保持终端度数界（引理 B.6），从而得到保度的 (1, 4+2√2+ε)-算法（定理 B.7），最终 α_MD ≤ 12+2√2+ε（单位权重 5+2√2+ε）。

### 2.4 单位权重单源单汇（定理 1.4 后半）

- 取 L=⌈4α_MD/ε⌉ 份 G 的拷贝串联（t_i 与 s_{i+1} 合并），加 v* 与两条边，构造单位权重多仓库实例；保度解中 v* 度数为 k，每份拷贝的边集 F_i 都诱导一个可行 SSSS 解，取最便宜者，费用 ≤ α_MD·c(x*)+2α_MD·c(x*)/L ≤ (5+2√2+ε)·c(x*)。同时给出单位权重 Path ATSP 整数间隙 ≤ 5+2√2 的新上界。

### 2.5 应用：Regret-Bounded VRP（定理 1.8）

- 用 Friggstad–Swamy 归约（(α,β)-双准则 ⇒ (α+β)-近似），取 δ=4 的松弛对偶分析，得到约 22.3（文中表述为 23）近似；并给出“任意 α-近似 ATSP ⇒ (4α+ε)-近似”的基线（此前为 O(log n)）。

## 六、主要结论与发现

- **主结果**：一般非对称多路径 TSP 可在 n^{O(k)} 时间内得到 O(k) 近似（定理 1.2），正面回答 Friggstad 的开放问题，且 f、g 均为线性。
- **单源单汇**：多项式时间 (O(1/ε), 1+ε)-双准则近似（定理 3.6），取 ε=1/(k+1) 即得 O(k) 近似；单位权重下 (5+2√2+ε)-近似，并改进单位权重 Path ATSP 的近似比与 LP 整数间隙上界（≤5+2√2）。
- **多仓库**：多项式时间 (12+2√2+ε)-近似（单位权重 5+2√2+ε），把 Friggstad 的 O(log n) 提升为常数，且与 ATSP 最佳一般权重界持平。
- **应用**：Regret-Bounded VRP 得到 23-近似（此前 O(log n)，黑盒基线约 50–60）。
- **遗留开放问题**：能否在 n^{g(k)} 时间内做到与 k 无关的常数近似（问题 4.1）；SSSS 多路径 LP 的整数间隙是否有常数上界（问题 4.2，本文仅证 O(k)）。
